### 一、输入模式（Input Modes）

输入模式下，输出驱动器的 P-MOS 和 N-MOS 均处于关闭状态，引脚信号通过保护二极管和内部滤波电路送入内部总线。

- **浮空输入（GPIO_Mode_IN_FLOATING）**
    - **硬件结构**：内部上拉和下拉电阻均断开，TTL 施密特触发器开启。
    - **电气特性**：引脚处于高阻态，输入电平完全由外部电路决定。若外部引脚悬空，受电磁噪声干扰极易在 0 和 1 之间无规则跳变。
    - **典型场景**：外部已有确定驱动电平的信号源、USART 的 RX 引脚、外部已带有硬件上下拉的按键电路。
        
- **上拉输入（GPIO_Mode_IPU）**
    - **硬件结构**：内部弱上拉电阻（阻值通常约为 30kΩ~50kΩ）导通至 $V_{DD}$，施密特触发器开启。
    - **电气特性**：外部无输入或悬空时，引脚默认稳定为高电平。
    - **典型场景**：低电平有效的按键输入（按键按下接地）、需要默认高电平的中断触发引脚。
- **下拉输入（GPIO_Mode_IPD）**
    - **硬件结构**：内部弱下拉电阻导通至 $V_{SS}$（GND），施密特触发器开启。
    - **电气特性**：外部无输入或悬空时，引脚默认稳定为低电平。
    - **典型场景**：高电平有效的按键或传感器信号（触发时接入高电平）。
- **模拟输入（GPIO_Mode_AIN）**
    - **硬件结构**：施密特触发器关闭，内部上下拉电阻全部断开，引脚信号绕过数字输入寄存器，直接连通内部模拟外设。
    - **电气特性**：切断数字开关以消除翻转毛刺和静态功耗，输入阻抗极高。
    - **典型场景**：ADC 模数转换采样、DAC 模拟输出引脚、芯片处于极低功耗模式下的引脚配置。

### 二、输出模式（Output Modes）

输出模式由 CPU 直接读写 GPIO 的数据输出寄存器（ODR）或置位/复位寄存器（BSRR）控制。

- **开漏输出（GPIO_Mode_Out_OD）**
    - **硬件结构**：内部 P-MOS 始终截止不工作，仅保留 N-MOS。输出 0 时，N-MOS 导通拉低到 $V_{SS}$；输出 1 时，N-MOS 截止，引脚处于高阻浮空态。
    - **电气特性**：自身只能主动输出低电平，无法直接输出高电平。必须依赖外部上拉电阻才能拉至高电平。支持多设备“线与”逻辑，且容易匹配不同电平系统（如 3.3V 驱动 5V 设备）。
    - **典型场景**：I2C 通信引脚（SCL/SDA）、单总线协议（如 DS18B20）、多设备共用一条报警/中断线。
- **推挽输出（GPIO_Mode_Out_PP）**
    
    - **硬件结构**：P-MOS 和 N-MOS 构成互补对称结构。输出 1 时，P-MOS 导通、N-MOS 截止，主动拉高至 $V_{DD}$；输出 0 时，N-MOS 导通、P-MOS 截止，主动拉低至 $V_{SS}$。
    - **电气特性**：具备对称的双向驱动能力（拉电流和灌电流均较强），高低电平切换响应快、信号沿陡峭。
    - **典型场景**：驱动 LED、蜂鸣器控制、普通数字高低电平开关量、SPI 的片选（CS）控制。

### 三、复用功能模式（Alternate Function Modes）

引脚的控制权脱离 CPU 的通用输出数据寄存器，直接移交给芯片内部片上硬件外设（如 SPI、USART、TIM 等）。

- **复用推挽输出（GPIO_Mode_AF_PP）**
    - **硬件结构**：输出级仍为推挽结构（P-MOS 与 N-MOS 互补），但控制信号直接来自硬件外设控制器。
    - **电气特性**：具备推挽输出的高驱动力与高速切换特性。
    - **典型场景**：USART TX 发送引脚、SPI 的 SCK 与 MOSI 引脚、定时器输出的 PWM 波形。
- **复用开漏输出（GPIO_Mode_AF_OD）**
    - **硬件结构**：输出级仍为开漏结构（仅 N-MOS 动作），由片内外设驱动，需要外部上拉电阻。
    - **电气特性**：兼具开漏的线与能力与硬件外设的自动化协议时序控制。
    - **典型场景**：硬件 I2C 接口控制器驱动的 SCL 和 SDA 引脚。
