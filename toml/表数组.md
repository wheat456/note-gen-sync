与\[]的区别，\[]类似
```json
{

  "products": {

    "name": "Product A",

    "price": 10,

    "description": "This is a product."

  }

}
```
而\[\[]]是
```json
{

  "products": [

    {

      "name": "Product A",

      "price": 10

    },

    {

      "name": "Product B",

      "price": 20

    },

    {

      "name": "Product C",

      "price": 15

    }

  ]

}
```
