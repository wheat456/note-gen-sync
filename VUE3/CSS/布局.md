## **Grid（网格布局**）


**inline-flex**：默认的flex会在当前标签的下一个标签换行，如果使用了这个，下一个标签就会紧贴当前标签
**block**：独占一行
**inline-block**：不换行了，但可以设置宽高，inline不能设置宽高
下面的内容都是给子元素使用的，在父元素上定义flex,子元素来定义下面的内容
**flex-1**：填满剩余的空间，flex-2所占的空间是flex-1的两倍
**flex-none**：**完全死板**，既不变大也不变小。
**flex-auto**：**能占满空间就占满**，不够了就缩小。
**flex-initial**：**只占自己内容的宽度**，绝不变大，但空间不够时会缩小。
**flex-grow**：当父容器有剩余空间时，这个元素会努力去**占满**这些空间。
**flex-grow-0**：不管父容器有多少剩余空间，这个元素都**只占自己内容那么大**，绝不多占。
**box-border**： 设置宽高是会包含border的宽度，比如设置的是100实际上内容只占80，不包含margin，但包含padding
**solid**：指的是实线

| 参数 | 作用 | 简单理解 |
| :--- | :--- | :--- |
| **`static`** (默认) | **普通文档流**，不能使用 `top`/`left` 等定位。 | **老实排队**，怎么写怎么排，不搞特殊。 |
| **`relative`** (相对定位) | **相对于自己原来的位置**进行偏移。 | **在原位基础上挪一下**，但不占坑（后面元素当它还在原位）。 |
| **`absolute`** (绝对定位) | **相对于最近的非 `static` 祖先元素**进行定位。 | **脱离文档流**，飘起来，随便找“有地位的”祖先当参照物。 |
| **`fixed`** (固定定位) | **相对于浏览器窗口**进行定位，滚动时不随页面移动。 | **钉在屏幕上**，像“回到顶部”按钮，怎么滚都在那。 |
| **`sticky`** (粘性定位) | 基于用户的滚动位置在 `relative` 和 `fixed` 之间切换。 | **滑到某个位置就吸住**，比如表头、导航栏。 |
