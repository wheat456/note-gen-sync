## Props

### 基本用法

Props 是父组件向子组件传递数据的一种方式。它们是单向的，从父组件流向子组件。

在父组件中使用子组件时，通过属性传递数据：
```vue
<ChildComponent :message="parentMessage" />
```

在子组件中使用 **defineProps** 定义接收的 props：
```javascript
import { defineProps } from 'vue'

// 定义 props
const props = defineProps(['message'])
// 或者带类型定义
const props = defineProps({
  message: String
})
```

### 类型验证

Vue 允许你为 props 指定类型，当传入的值类型不匹配时会在控制台发出警告。

使用 defineProps 进行类型验证：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型检查
  propA: Number,
  // 多种可能的类型
  propB: [String, Number],
  // 必填的字符串
  propC: {
    type: String,
    required: true
  },
  // 带有默认值的数字
  propD: {
    type: Number,
    default: 100
  },
  // 带有默认值的对象
  propE: {
    type: Object,
    default() {
      return { message: 'hello' }
    }
  },
  // 自定义验证函数
  propF: {
    validator(value) {
      return ['success', 'warning', 'danger'].includes(value)
    }
  }
})
```

### 默认值设置

为 props 设置默认值可以提高组件的健壮性：

使用 defineProps 设置默认值：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型默认值
  title: {
    type: String,
    default: '默认标题'
  },
  // 对象类型默认值
  options: {
    type: Object,
    default() {
      return {
        size: 'medium',
        visible: false
      }
    }
  },
  // 数组类型默认值
  items: {
    type: Array,
    default() {
      return []
    }
  }
})
```
