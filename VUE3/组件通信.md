# 组件通信

## 1. 父子组件通信

### 1.1 父向子传递数据 (Props)

#### 基本用法

Props 是父组件向子组件传递数据的一种方式。它们是单向的，从父组件流向子组件。

在父组件中使用子组件时，通过属性传递数据：
```vue
<ChildComponent :message="parentMessage" /> //加了冒号就视为变量
```

在子组件中使用 **defineProps** 定义接收的 props：
```javascript
import { defineProps } from 'vue'

// 定义 props
const props = defineProps(['message'])
// 或者带类型定义
const props = defineProps({
  message: String
})
```

#### 类型验证

Vue 允许你为 props 指定类型，当传入的值类型不匹配时会在控制台发出警告。

使用 defineProps 进行类型验证：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型检查
  propA: Number,
  // 多种可能的类型
  propB: [String, Number],
  // 必填的字符串
  propC: {
    type: String,
    required: true
  },
  // 带有默认值的数字
  propD: {
    type: Number,
    default: 100
  },
  // 带有默认值的对象
  propE: {
    type: Object,
    default() {
      return { message: 'hello' }
    }
  },
  // 自定义验证函数
  propF: {
    validator(value) {
      return ['success', 'warning', 'danger'].includes(value)
    }
  }
})
```

#### 默认值设置

为 props 设置默认值可以提高组件的健壮性：

使用 defineProps 设置默认值：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型默认值
  title: {
    type: String,
    default: '默认标题'
  },
  // 对象类型默认值
  options: {
    type: Object,
    default() {
      return {
        size: 'medium',
        visible: false
      }
    }
  },
  // 数组类型默认值
  items: {
    type: Array,
    default() {
      return []
    }
  }
})
```

### 1.2 子向父传递数据 (Emit) /自定义事件

子组件向父组件传递数据通常使用事件发射 (emit) 机制。

### 自定义 v-model

Vue 3 中可以自定义组件的 v-model，实现双向数据绑定。

### 1.3 透传 Attributes (Attrs)

透传 Attributes 是 Vue 3 中一个重要的特性，允许父组件向子组件传递未被声明为 props 的属性。
使用v-bind="$attr"向下传递
#### 基本用法

在父组件中传递属性给子组件：
```vue
<!-- 父组件 -->
<ChildComponent :class="myClass" :style="myStyle" id="my-id" data-test="test" />
```

在子组件中使用 **useAttrs** 获取透传的属性：
```javascript
import { useAttrs } from 'vue'

export default {
  setup() {
    const attrs = useAttrs()
    
    // attrs 包含所有未被声明为 props 的属性
    console.log(attrs) // { class: 'my-class', style: 'color: red;', id: 'my-id', 'data-test': 'test' }
    
    return {
      attrs
    }
  }
}
```

在模板中使用透传的属性：
```vue
<template>
  <!-- 将 attrs 应用到根元素 -->
  <div v-bind="attrs">
    子组件内容
  </div>
  
  <!-- 或者选择性地应用某些属性 -->
  <div :class="attrs.class" :id="attrs.id">
    子组件内容
  </div>
</template>
```

#### inheritAttrs 属性

通过设置 `inheritAttrs` 选项可以控制是否自动将透传的属性应用到根元素：

```javascript
import { useAttrs } from 'vue'

export default {
  inheritAttrs: false, // 禁用自动继承 attrs
  setup() {
    const attrs = useAttrs()
    
    return {
      attrs
    }
  }
}
```

禁用自动继承后，需要手动决定将哪些属性应用到元素上：

```vue
<template>
  <!-- 不会自动应用 attrs -->
  <div>
    <!-- 手动选择要应用的属性 -->
    <div v-bind="attrs">内容</div>
    <!-- 或者只应用特定属性 -->
    <p :class="attrs.class">{{ attrs.title }}</p>
  </div>
</template>
```

使用场景：
1. 需要将属性应用到非根元素上
2. 需要对透传属性进行处理后再应用
3. 多根节点组件（Vue 3 支持多个根节点）

#### 基本用法

默认情况下，v-model 在组件上使用时等价于传递 `modelValue` prop 和监听 `update:modelValue` 事件：

```vue
<!-- 父组件 -->
<ChildComponent v-model="parentData" />

<!-- 等价于 -->
<ChildComponent :modelValue="parentData" @update:modelValue="parentData = $event" />
```

在子组件中实现 v-model：

```javascript
// 子组件
import { defineProps, defineEmits } from 'vue'

// 定义接收的 props
const props = defineProps({
  modelValue: String // 默认使用 modelValue 作为 prop 名称
})

// 定义可发射的事件
const emit = defineEmits(['update:modelValue'])

// 更新数据的方法
const updateValue = (newValue) => {
  emit('update:modelValue', newValue)
}
```

在子组件模板中使用：

```vue
<template>
  <input :value="modelValue" @input="updateValue($event.target.value)" />
</template>
```

#### 基本用法

在子组件中使用 **defineEmits** 定义可发射的事件，并使用返回的 emit 函数发射事件：

```javascript
import { defineEmits } from 'vue'

// 定义可发射的事件
const emit = defineEmits(['update', 'delete'])

// 发射事件
const onUpdate = () => {
  emit('update', { id: 1, name: 'updated item' })
}

const onDelete = () => {
  emit('delete', 1)
}
```

在父组件中监听子组件发射的事件：

```vue
<ChildComponent @update="handleUpdate" @delete="handleDelete" />
```

在父组件的处理函数中接收子组件传递的数据：

```javascript
const handleUpdate = (data) => {
  console.log('接收到更新数据:', data)
}

const handleDelete = (id) => {
  console.log('接收到删除ID:', id)
}
```

#### 类型定义

为 emit 事件添加类型定义可以提供更好的开发体验和类型检查：

```javascript
import { defineEmits } from 'vue'

// 带类型定义的 emit
const emit = defineEmits<{
  (e: 'update', data: { id: number; name: string }): void
  (e: 'delete', id: number): void
}>()

// 或者使用对象形式
const emit = defineEmits({
  update: ({ id, name }: { id: number; name: string }) => {
    return id > 0 && name.length > 0
  },
  delete: (id: number) => {
    return id > 0
  }
})
```

## 2. 跨组件通信 (Mitt)

### 2.1 Mitt 简介与基本用法

Mitt 是一个轻量级的事件总线库，用于在 Vue 3 应用中实现跨组件通信，特别适用于非父子关系的组件之间通信。

首先安装 Mitt：
```bash
npm install mitt
```

创建事件总线实例：
```javascript
// utils/eventBus.js
import mitt from 'mitt'

export const eventBus = mitt()
```

### 2.2 Mitt 事件监听与发射
在组件中使用 Mitt 进行事件通信：
```javascript
// 在需要发送事件的组件中
import { eventBus } from '@/utils/eventBus'

// 发射事件
const sendData = () => {
  eventBus.emit('data-updated', { message: 'Hello from component A' })
}
```

```javascript
// 在需要接收事件的组件中
import { eventBus } from '@/utils/eventBus'
import { onMounted, onUnmounted } from 'vue'

// 监听事件
const handleDataUpdated = (data) => {
  console.log('接收到数据:', data)
}

onMounted(() => {
  eventBus.on('data-updated', handleDataUpdated)
})

// 记得在组件销毁前移除事件监听
onUnmounted(() => {
  eventBus.off('data-updated', handleDataUpdated)
})
```

Mitt 常用 API：
- `emit(eventName, data)`: 发射事件
- `on(eventName, handler)`: 监听事件
- `off(eventName, handler)`: 移除事件监听
- `all`: 包含所有事件的 Map 对象
