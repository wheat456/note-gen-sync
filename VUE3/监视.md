```ts
const stopwatch=watch(谁？,(新的值，旧的值)=>{}){
}
stopwatch() //结束监视
```
如果监视对象，则监视的是对象地址
```js
const person = {
	name:"nihao",
	age:18
}
watch(person,(new,old)=>{
	
})
```
当整个person 变化时，才会触发监视，如果需要监控字段，则
```js
watch(...,{deep:true，immediate:true})
```
deep:深度监视，字段变化会触发监视
immediate:启动时直接执行一次

> [!warning] Title
> 被reactive包裹的对象不可整体修改

监视**reactive**对象时，里面的任何一个数据变化都会被监视到
- 如果想要监视**reactive**中的一个值，则
```js
watch(()=>{return xxx},()=>{})
```
- 如果要监视**reactive**中的一个对象
```js
watch(()=>{return person.car},()=>{}) //car是一个对象
// 这里只是监视了对象的地址值，如果想要监视对象中的值，就要开启deep:true
```

# 监视多个值
```js 
watch([()=>{},person.car],()=>{})
```
