### 1. External Clock Mode 1（外部时钟模式 1）

* **核心功能**：定时器的**计数时钟由外部触发输入（TRGI）的上升沿驱动**（触发源可来自定时器通道引脚、异或输入或内部触发 ITRx）。
* **特点**：此时内部时钟（`Clock Source`）会被自动禁用，计数完全由外部信号控制。
* **典型场景**：对外部脉冲事件计数（如编码器信号、外部传感器脉冲）、用一个定时器作为另一个定时器的 “预分频器”（通过内部触发 ITRx 级联）。

### 2. Reset Mode（复位模式）

* **核心功能**：定时器使用**内部时钟**计数，但当检测到指定触发源（需在 `Trigger Source` 中选择）的上升沿时，**计数器会被强制清零**。
* **典型场景**：让定时器周期与外部事件同步（如用另一定时器的 TRGO 信号作为触发源，实现主从定时器 “同步复位”）、周期性重置计数器以生成固定占空比的 PWM。

### 3. Gated Mode（门控模式）

* **核心功能**：定时器使用**内部时钟**，但仅当外部触发信号（TRGI）为 “有效电平”（如高电平）时，计数才会进行；触发信号无效时计数暂停。
* **典型场景**：由外部信号控制计数的 “开启 / 关闭”（如用传感器电平控制计时窗口、外部使能信号控制定时器运行时间）。

### 4. Trigger Mode（触发模式）

* **核心功能**：当检测到触发源（TRGI）的上升沿时，**启动定时器计数**（之后由内部时钟自主运行，直到定时器溢出或被停止）。
* **典型场景**：用外部事件触发定时器 “启动”（如按键触发一次定时、外部传感器脉冲启动延时）



# 触发源

### 1. Disable

禁用触发源，此时定时器**不响应外部 / 内部触发信号**，从模式相关功能（如复位、启动、门控计数等）失效。

### 2. ITR0 \~ ITR3（Internal Trigger 0\~3）

「内部触发」，是 STM32 **内部其他定时器输出的触发信号（TRGO，Timer Refresh Output）**。

* 不同型号芯片的 `ITR0~ITR3` 对应关系不同（需参考芯片手册），通常用于**定时器级联同步**（如用 `TIM1` 的 TRGO 触发 `TIM2` 计数、复位等）。

### 3. ETR1（External Trigger Input 1）

「外部触发输入」，触发信号来自芯片的**外部引脚（ETR 引脚）**。

* 外部硬件信号（如传感器脉冲、外部时钟）可通过该引脚输入，直接触发定时器的从模式动作（如启动计数、复位计数器等）。

### 4. TI1\_ED（Timer Input 1 Edge Detector）

「定时器输入通道 1 的边沿检测」，触发信号来自**定时器通道 TI1 引脚的边沿变化**（上升沿 / 下降沿）。

* 无需滤波，直接检测引脚边沿，常用于对外部脉冲的 “原始边沿” 敏感的场景（如编码器信号捕获）。

### 5. TI1FP1（Timer Input 1 Filtered and Polarity-selected）

「定时器输入通道 1 经滤波和极性选择后的信号」。

* TI1 引脚的信号会先经过**输入滤波器（滤除噪声）**和**极性配置（选择上升沿 / 下降沿触发）**，再作为触发源。
* 相比 `TI1_ED`，更适合**噪声较大的外部信号**，或需要指定触发边沿的场景。




# 时钟源

### 1. Disable

禁用时钟源，定时器**完全停止计数**（无任何时钟驱动计数器运行）。

### 2. Internal Clock（内部时钟）

使用 STM32 **芯片内部的系统时钟**作为定时器的计数时钟（通常来自 APB 总线时钟，再经定时器预分频器等配置后生成计数脉冲）。
这是最常用的模式，适合**自主定时、生成 PWM、内部计时**等场景（定时器由芯片内部系统时钟驱动，独立运行）。

### 3. ETR2（External Trigger Input 2，外部触发输入 2）

使用**外部引脚输入的信号**作为定时器的计数时钟。
外部引脚（对应 `ETR2` 的硬件引脚）上的脉冲（如外部时钟、传感器输出的脉冲）会直接驱动定时器计数器递增 / 递减。
适合**对外部事件脉冲计数**的场景（如测量外部信号频率、累计外部脉冲数量等）。
