| **类别**    | **常用函数**                     | **核心用途**           | **典型语法 / 示例**                                   |
| --------- | ---------------------------- | ------------------ | ----------------------------------------------- |
| **查找引用**  | **`XLOOKUP`**                | 新一代万能查找（支持逆向、默认容错） | `=XLOOKUP(查找值, 查找区域, 返回区域)`                     |
|           | **`VLOOKUP`**                | 经典垂直查找             | `=VLOOKUP(查找值, 数据表, 返回列序号, 0)`                  |
|           | **`INDEX` + `MATCH`**        | 灵活的双向/多条件查找组合      | `=INDEX(返回列, MATCH(查找值, 查找列, 0))`               |
| **条件与统计** | **`SUMIFS`**                 | 多条件求和              | `=SUMIFS(求和区域, 条件区域1, 条件1, ...)`                |
|           | **`COUNTIFS`**               | 多条件计数              | `=COUNTIFS(条件区域1, 条件1, ...)`                    |
|           | **`AVERAGEIFS`**             | 多条件计算平均值           | `=AVERAGEIFS(均值区域, 条件区域1, 条件1)`                 |
| **逻辑与容错** | **`IF`**                     | 单/多分支条件判断          | `=IF(A2>=60, "及格", "不及格")`                      |
|           | **`IFS`**                    | 扁平化多条件判断（免去多层嵌套）   | `=IFS(A2>=90, "优秀", A2>=60, "及格", TRUE, "不及格")` |
|           | **`IFERROR`**                | 公式报错时显示自定义内容       | `=IFERROR(公式, "未查到")`                           |
| **文本处理**  | **`TEXTJOIN`**               | 带分隔符批量合并文本         | `=TEXTJOIN(",", TRUE, A2:A10)`                  |
|           | **`LEFT` / `MID` / `RIGHT`** | 按位置截取字符            | `=MID(身份证号, 7, 8)` （提取出生日期）                     |
|           | **`SUBSTITUTE`**             | 替换指定文本内容           | `=SUBSTITUTE(A2, "-", "")`                      |
| **日期时间**  | **`DATEDIF`**                | 计算两个日期间隔（工龄/年龄）    | `=DATEDIF(入职日期, TODAY(), "Y")`                  |
|           | **`TODAY` / `NOW`**          | 动态获取当天日期 / 当前时间    | `=TODAY()`                                      |
