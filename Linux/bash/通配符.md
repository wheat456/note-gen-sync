## 单小括号()
- **命令组** :括号中的命令将会新开一个==子shell==顺序执行，所以括号中的变量不能够被脚本余下的部分使用。括号中多个命令之间用分号隔开，最后一个命令可以没有分号，各命令和括号之间不必有空格。`(cmd1;cmd2;com3)`
- **命令替换** : `$(cmd)`执行cmd并得到返回结果
- **用于初始化数组**。如：array=(a b c d)
## 双小括号(())
- **整数扩展:** `((exp))` exp为表达式
- **运算：** `$((exp))` 其中的exp符合C语言运算规则，甚至3目运算符。运算结果自动转十进制。例如$((16#5f)),结果为95，16为十六进制
- `((a++))`
- `(())`的值可以是C语言的语法例如`for((i=0;i<5;i++))`和if((i<5))
## 方括号\[]
- 字符范围。用作正则表达式的一部分，描述一个匹配的字符范围。
- **比较：** \[ ]中用于比较字符串的运算符只有`==` or `!=`,整数比较用`-eq`和`-gt`等
## 双中括号\[\[ ]]
- **条件判断：** \[\[ ]]中 可以像C语言一样进行判断。例如\[\[$a != 1 && $a != 2]]
- **字符串匹配:** 例如\[\[ hello == hell? ]] 等式右边为通配符或者字符串

## 花括号 {}
- **大括号拓展：**  `touch {a..d}.txt` 和  `touch {a,b}.txt`
-  **代码块：** { cmd1;cmd2;}大括号内的命令不会新开一个子shell运行，即脚本余下部分仍可使用括号内变量。括号内的命令间用分号隔开，最后一个也必须有分号。{}的第一个命令和左括号之间必须要有一个空格
- **特殊替换**
```shell
${var:-string} # if var=空，则${var:-string}=$string,var!=空，则${var:-string}=$var
${var:=string} # 与上相同规则下，var=空时，将var=string
${var:+string} # 与上相反，但不赋值
${var:?string} # var!=空， ${var:-string}=var，var=空， 输出string到标准错误
```
-  **字符串提取和替换:** 
```shell
${var:num} #num为正，从左向右取num到末尾的字符。num为负，从右向左取num个字符
# var=/home/centos  | 
#echo ${var:5}      | #echo ${var: -6}
#/centos            | #centos
---
${var:num1:num2}
# num1是位置，num2是长度。不能为复数
---
${var/pattern/pattern}
# 表示将var字符串的第一个匹配的pattern替换为另一个pattern。
#echo ${var/o/h}
#/hhme/centos
---
${var//pattern/pattern}
# echo ${var//o/h}
# /hhme/cenths
```
