## 变量名规则
- **书写规则**：量名和等号之间不能有空格
- **命名规则：** 
	- 只包含字母、数字和下划线
	- 不能以数字开头
	- 使用大写字母表示常量
## 使用
- `$variable`定义变量
- `"this is test ${variable} text"`用于规定界限
- 赋值不用加$
- `readonly variable`只读变量不可修改
- `unset variable`删除变量，不能删除只读变量
- `declare`关键字，声明变量及属性
```shell
declare [+/-][rxi][变量名称＝设置值]
- +/- 　"-"可用来指定变量的属性，"+"则是取消变量所设的属性。
- r 　将变量设置为只读。
- x 　指定的变量会成为环境变量，可供shell以外的程序来使用。
- i 　[设置值]可以是数值，字符串或运算式。
```
- **特殊变量：** `$0`表示脚本的名称, `$1 $2`脚本参数，`$#`脚本参数数量，`$#`上一个命令的退出状态
`$$`脚本运行的当前进程ID号,`$*`显示所有向脚本传递的参数,格式为`"$1 $2...."`,
- **字符串：** 推荐双引号`""`,双引号的内容可以转义和引用其他变量
	- **方法：** 
		- 获取字符串长度`${#string}=${#string[0]}`
		- 提取字符串`${string:1:4}`字符串索引从0开始，索引为4不算
- **数组：** 
	- **限制：** 无多维数组
	- **写法与用法：**
```shell
array_name=(value0 value1 value2 value3)

array_name=(
value0
value1
value2
value3
)
array_name[0] # 赋值
valuen=${array_name[n]} # ${数组名[下标]}
${array_name[@]} #@获取所有元素
${#array_name[@]} # 获取数组长度

关联数组
declare -A site=(["google"]="www.google.com" ["runoob"]="www.runoob.com" ["taobao"]="www.taobao.com")
```
* **多行注释：** 
```shell
:<<EOF
注释类容
EOF

EOF字可自定义
```
