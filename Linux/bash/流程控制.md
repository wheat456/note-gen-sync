## if
```shell
if condition1
then
	command1
	.......
elif condition2
then
	command2
else

fi
```
```shell
								 example
if [ $a -gt $b] #[]中用 -gt or -eq
then
	command
fi
-----------------------------------------------------------------------------------
if (($a > $b)) # > or <
```
## for
```shell
for var in item1 item2 item3
do
	command1
done
```
## while
```shell
while condition #当condtion为：时，无限循环 为ture 无限循环
do
	command
done
```
## until
```shell
循环执行一系列命令直至条件为 true 时停止
until condition
do
    command
done

```
case
```shell
case 值 in
mode1)
	command1
	;;
mode2)
	command2
	;;
esac
```
