- 原理：数据类型~={red}实现了`IntoIterator`=~，即可作为迭代器迭代。迭代器~={red}实现了=~`Iterator`,`for`循环就是不断调用`next`方法，取得Option<>包装的元素
```rust
pub trait Iterator {
    type Item;

    fn next(&mut self) -> Option<Self::Item>;

    // 省略其余有默认实现的方法
}
```
- 在迭代器初始化时，不会产生影响。只有使用时才会有影响
- 手动迭代
```rust
let mut arr_iter = arr.into_iter();
assert_eq!(arr_iter.next(), Some(1));
//依顺序迭代
//手动迭代需要使用mut,会消耗元素
```
# 3种迭代器
- `into_iter`夺走~={cyan}所有权=~
- `iter`~={cyan}不可变借用=~
	- 调用`next()`方法，返回的是`Some(&T)`
- `iter_mut`是可变借用
	- 调用`next()`方法，返回的是`Some(&mut T)`
- `iterator`和`intoiterator`的区别
	- `Iterator`是迭代器特征,只有实现了该`trait`才能调用`next()`方法
	- `IntoIterator`强调实现了该`trait`才能通过`into_iter`和`iter`变成一个迭代器
- 消费者
	- 将~={orange}迭代器适配器=~消费掉，依赖`next`来消费元素，返回值，比如~={pink}vec=~等
	- **注意**：~={cyan}消费性迭代器=~通常与一些方法结合使用，比如 `sum()`、`collect()`、`for_each()` 等。这些方法会~={red}消耗迭代器，导致原始集合失效。=~
	- 要在迭代后~={green}继续使用原始数据=~，可以考虑使用~={cyan}引用迭代器=~（如 `iter()`）
	- 消费者适配器：某个方法 `A` 在其内部调用了 `next` 方法，那么 `A` 就被称为消费性适配器`sum`
- 迭代器适配器
	- 接受~={cyan}迭代器=~，处理了返回~={cyan}迭代器=~，例如~={pink}map=~,~={pink}filter=~
	- **作用**：消费掉迭代器，返回一个新的迭代器，需要一个消费者适配器来返回值

| ---------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `size_hint()`          | 返回迭代器中剩余元素数量的下界和上界。                    | `let iter = (1..10).into_iter(); println!("{:?}", iter.size_hint());`                                                                                                                        |

| `all()`                | 如果迭代器中的所有元素都满足某个条件，返回 `true`。          | `let all_positive = (1..=5).into_iter().all(\|x\| x > 0);`                                                                                                                                   |
| `any()`                | 如果迭代器中的至少一个元素满足某个条件，返回 `true`。         | `let any_negative = (1..5).into_iter().any(\|x\| x < 0);`                                                                                                                                    |
| `find()`               | 返回迭代器中第一个满足某个条件的元素。                    | `let first_even = (1..10).into_iter().find(\|x\| x % 2 == 0);`                                                                                                                               |

# ControlFlow
- `ControlFlow` 枚举有两个变体：
- `Continue(B)`: 表示操作应继续进行，且可以携带一些数据（类型为 `B`）。
- `Break(A)`: 表示操作应中断，并可携带一些数据（类型为 `A`）作为中断的结果。
