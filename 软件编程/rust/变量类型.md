# 标量类型
- **标量**：整型、浮点型、布尔型和字符
## 整数类型

| 数字字面量         | 示例            |
| ------------- | ------------- |
| 十进制           | `98_222`      |
| 十六进制          | `0xff`        |
| 八进制           | `0o77`        |
| 二进制           | `0b1111_0000` |
| 字节 (仅限于 `u8`) | `b'A'`        |
## 浮点数
- 类型：f32,f64

## 字符
- ~={red}字符=~使用单引号，~={green}字符串=~双引号
- 大小4个字节，unicode标量值
