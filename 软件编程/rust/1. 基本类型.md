## 常量(const)
- 关键字是`const`而不是`let`
- 定义常量必须指明类型（例如` i32`）不能省略，且不可变其值在编译时已经确定
- 定义常量时变量的命名规则一般是全部**大写**
- 可以在局部中定义，遵循作用域，也就是有生命周期
```rust
const MAX_ID: usize =  usize::MAX / 2; // 常量必须表明类型,这里是usize
fn main() {
   println!("用户ID允许的最大值是{}",MAX_ID);
}
```

## 静态变量(static)
- 程序启动时初始化，在全局数据区中
- 类似C中的全局变量
- 必须使用`unsafe`语句块才能访问和修改`static`变量
```rust
static mut REQUEST_RECV: usize = 0;
fn main() {
   unsafe {//使用unsafe来修改
        REQUEST_RECV += 1;
        assert_eq!(REQUEST_RECV, 1);
   }
}
```
# 数组
- 固定长度，元素类型相同，值可以修改，但是不可以变长
- 使用方法 
  ```rust
  let s = [1,2,3];
  let s = [0;500]; //连续赋值
  ```
- 切片
```rust
  &s[2..5]//借用数组234索引的值
```

# 元组
- 元组的**长度是固定的**,但是可以**修改值**，不能**修改类型**
- 可以拥有不同类型
- 使用`x.0`的方式访问
```rust
let tup = (500, 6.4, "hello", true); 
let tup: (i32, f64, &str, bool) = (500, 6.4, "hello", true);
```

# Enum
- 如果想要获得值就需要通过`match`  `if let`  等方式解构
```rust
enum WebEvent {
    // 1. 类似单元结构体（Unit-like）：不带任何数据
    PageLoad,
    PageUnload,

    // 2. 类似元组结构体（Tuple-like）：包含未命名的数据字段
    KeyPress(char),
    Paste(String),
    Click(i64, i64), // 可以包含多个值

    // 3. 类似经典结构体（Struct-like）：包含具名字段
    ChangeColor { red: u8, green: u8, blue: u8 },
}

/* 实例化
*/
let load = WebEvent::PageLoad; 
let press = WebEvent::KeyPress('q');
let click = WebEvent::Click(100, 250);
let color = WebEvent::ChangeColor { red: 255, green: 128, blue: 0 };
```

# 类型总表

| **类别**       | **类型**                                     | **说明与示例**                                           |
| ------------ | ------------------------------------------ | --------------------------------------------------- |
| **有符号整数**    | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | `i32` 为默认整型；`isize` 视目标系统指针架构而定（32/64位）             |
| **无符号整数**    | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | `u8` 常用于字节处理；`usize` 常用于数组索引和集合长度                   |
| **浮点数**      | `f32`, `f64`                               | 符合 IEEE 754 规范；`f64` 为默认浮点类型                        |
| **布尔类型**     | `bool`                                     | 取值为 `true` 或 `false`，占 1 字节                         |
| **字符类型**     | `char`                                     | 代表 Unicode 标量值，固定占用 **4 字节**，如 `'a'`, `'中'`, `'🦀'` |
| **元组**       | `(T, U, ...)`                              | 固定长度、异构集合，如 `(1, "hello", true)`；`()` 为单元类型（Unit）   |
| **数组**       | `[T; N]`                                   | 固定长度、同构且直接分配在栈上的集合，如 `[1, 2, 3]`                    |
| **切片**       | `[T]`, `&[T]`, `&str`                      | 连续内存块的动态大小视图（DST），通常借用使用如 `&[i32]` 或 `&str`         |
| **原生指针**     | `*const T`, `*mut T`                       | 裸指针，不受借用检查器约束，解引用必须在 `unsafe` 块中                    |
| **函数指针**     | `fn(T) -> U`                               | 指向显式函数的指针类型                                         |
| **Never 类型** | `!`                                        | 表示永远不会返回结果的计算（如 `panic!` 或无限 `loop`）                |
