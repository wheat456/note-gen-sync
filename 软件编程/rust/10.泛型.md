

> [!NOTE] Tip
> 对于任何类型的泛型都是在名字后面加上泛型，例如 `exp\<A,B,C>`等。在对齐实现方法时，`impl`需要`impl <A,B,C>` ,这里的`A,B,C`可以添加约束。同理，实现trait也是这样，`impl<A,B,C> trait01<A,B> for struct<C> `

## 结构体
```rust
struct Point<T> { x: T, y: T, } //只有一种类型

struct Point<T,U> { x: T, y: U, }//两种不同类型
```
### 方法中的泛型
```rust

	}
}

// ---------------------------------------------
//没有限制
struct GenericVal<T,U>(T,U);
impl <T,U>GenericVal<T,U>{
	fn temp(&self,x:T){
	
	}

## trait 的泛型
```rust
trait DoubleDrop<T> {
    // 定义一个调用者的方法，接受一个额外的参数 `T`，但不对它做任何事。
    fn double_drop(self, _: T);
}

impl<T, U> DoubleDrop<T> for U { //为U实现trait
    // 此方法获得两个传入参数的所有权，并释放它们。
    fn double_drop(self, _: T) {}
}
```
### 为外部类型实现trait
- 要为类型 `A` 实现特征 `T`，那么 `A` 或者 `T` 必须至少有一个在当前的作用范围内。
```rust
```rust
use std::fmt;
/*
初始化一个结构体元组，包装需要实现trait的数据类型，例如Vec<String>
对结构体元组实现trait,使用时将数据包装进元组，初始化元组

*/
struct Wrapper(Vec<String>);//创捷结构体元组

impl fmt::Display for Wrapper {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "[{}]", self.0.join(", "))
    }
}

fn main() {
    let w = Wrapper(vec![String::from("hello"), String::from("world")]);//使用元组包装数据
    println!("w = {}", w);
}

## 约束(bound)
- 约束只能是 `trait` 或者是生命周期
```rust
struct A<T=i32>{}// 使用=代表着默认类型是i32

//多重约束
struct A<T:Debug+Display>{}//同时使用2个特征
struct A<T:Debug,U:Display>{}//分别实现特征

// 生命周期
struct RefHolder<'a, T: 'a> { val: &'a T, }
```
## 卫语句 
```rust
//当多重约束
struct A<T,U>where T:Debug+Display,U:Trait{}

## 关联项
Rust 中的关联项主要分为三类：**关联类型**、**关联常量** 和 **关联函数**。
```rust
trait Task {
    // 1. 关联类型（由具体实现者决定具体类型）
    type Output;

    // 2. 关联常量（由具体实现者提供常量值，也可以有默认值）
    const RETRY_COUNT: u32 = 3;

    // 3. 关联函数 / 方法（使用关联类型作为返回值）
    fn run(&self) -> Self::Output;
}
```
在应用中
```rust
struct PrintTask; // 普通非泛型结构体

impl Task for PrintTask {
    // 指定关联类型为具体的 String
    type Output = String;

    // 覆盖关联常量（若不写则使用默认值 3）
    const RETRY_COUNT: u32 = 5;

    // 实现方法
    fn run(&self) -> Self::Output {
        String::from("Task Finished")
    }
}

```

- 作用在泛型`trait`
- 关联类型在trait中定义，在impl中要指定类型
```rust
//使用关联数据
trait A{
	type X;
	type Y;
}
fn differece<T>(arg:&T)where T:A{

}
//如果要加限定应该在impl或者trait中
trait A<Abc=i32>
{

}//或者
impl A for B
{
	type A=i32;
}

where T: Divide<Seconds, Output = Speed>, //用where来约束关联类型，注意是用=
```
- 理解：因为trait中有泛型的数据，所以不能让函数成为泛型函数，所以泛型数据应该表明在trait上`trait<X,Y>`,所以之后在作为其他函数参数时就会要求表明泛型`fn difference<X,Y,Z>(arg:&Z)where Z:A<X,Y>`。使用关联数据就不是泛型trait了，之后也不必表明泛型`fn differece<T>(arg:&T)where T:A`。

## const N
- 是基于值的泛型，也就是不确定值
```rust
fn display_array<T: std::fmt::Debug>(arr: &[T]) {
    println!("{:?}", arr);
}
fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    display_array(&arr);

    let arr: [i32; 2] = [1, 2];
    display_array(&arr);
}
//未使用const 泛型
-----------------------------------------
//使用const 泛型
fn display_array<T: std::fmt::Debug, const N: usize>(arr: [T; N]) {
    println!("{:?}", arr);
}
fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    display_array(arr);

    let arr: [i32; 2] = [1, 2];
    display_array(arr);
}
