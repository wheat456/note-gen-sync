
## 所有权移动 
- 部分移动,使用`ref`
```rust 
  let Person { name, ref age } = person;
```
- 在解构时，使用`..`来忽略不需发生移动的部分
## 借用
-  `ref`用于创建对值的引用，而不移动值。在模式匹配和解构中常使用
## 生命周期
- 显示标注

- 函数
	- 任何引用都应该标注生命周期
	- 返回的引用应该与输入引用有相同的生命周期
```rust
fn pass_x<'a, 'b>(x: &'a mut i32, _: &'b mut i32) -> &'a i32 { x }
```
- 方法：一般不用标注
- 约束：和泛型使用方法一样
```rust
struct Ref<'a, T: 'a>(&'a T);
fn print_ref<'a, T>(t: &'a T) where
    T: Debug + 'a {}
```
- 强制转换
```rust 
fn choose_first<'a: 'b, 'b>(first: &'a i32, _: &'b i32) -> &'b i32 
//a的周期至少和b一样长
```
- static
	- 生命周期为整个程序运行时
	- 使用`static`来声明常量
	- `&'static str`的String类型字面量
