## stack
- 后入先出
- stack上的数据已知固定大小如int等
- 编译时大小未知或运行时会发生大小变化的数据放在heap上
- 指针在stack上
## heap
- 当把数据放入heap时，会申请一片空间，返回指针
## 所有权规则
- 每个值都有一个名字（变量），这个名字是该值的所有者
- 一个值只能由一个所有者（名字）
- 当所有者（名字）超出作用域时就会删除。

## string类型
- 存在heap上
- 字符串字面值：不可变，例如“hello”
- 创建string类型：`let s = String::from("hello");`
## 内存和分配
- 字符串字面值：`let s = "string"`,在编译时确定大小
- String类型：如你输入的字符串，未知大小
- 变量在超出作用域时，会自动释放
- `let s1 = String::from("hello");let s2 = s1;` s1会废弃，无法使用
- 拥有copy trait 的数据在赋值时，是传递副本，而没有的，则是发生移动，也就是转递所有权

## 引用和借用
- 引用：名字的指针
- 借用：将引用作为函数参数的变量，默认不可修改，添加mut修改
 
  ```rust
  fn calculate_length(s:&mut String) -> usize
  {
      s.len()
  }//传入的参数也应是相同类型，例如：&mut s1
  ```
- 在一个作用域内只能有一个可变引用
- 不能同时存在可变引用和不可变引用

  ```rust
  fn main()
  {
      let mut s = String::from("fds")
      let r1 = &s;
      let r2 = &s;
      let s1 = &mut s; 错误
  }
  ```
