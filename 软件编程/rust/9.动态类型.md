## Size 特征
- Rust 隐式的为每一个泛型函数增加了 `Sized` bound
- 默认的泛型参数都实现了`Sized`，一些固定大小的数据都实现了`Sized`,除了`str`和`trait`
- 每个`trait`都是通过名称来引用的动态大小类型
- 如果要使用泛型参数为动态类型，则约束为`?Size`,代表既有可能是固定大小，也有可能是动态大小数据类型，参数应该是`&T`,只能通过引用来使用动态大小数据类型
## Box\<str>
- 常用于比`String`更小内存且不修改的场景
```rust
let s1:Box<str>="fsd".into();
```

# 定长
**定长**的意思非常简单：**在程序还没运行（编译期）时，编译器就能准确知道这个变量占多少个字节。**
- `i32`：永远占 4 个字节。
- `bool`：永远占 1 个字节。 
- `[u8; 10]`（包含 10 个字节的数组）：永远占 10 个字节。
- `struct Point { x: i32, y: i32 }`：4 + 4 = 8 个字节
- `String` 本身是定长的，但是指向的内容不是，同理`vec`等也是这样

# 不定长（DST）

> [!NOTE] `str` 和 `&str`的关系
> `str` 是不定长，就好比”hello“这个字符串，除非用挨个去数，不然不知道长度。既然不定长就无法放到栈中，肯定需要一个地方来保存，那么就需要用到堆，堆就像一个仓库不管你的内容是什么，直接就放进去，那么就需要自己去记录该字符串在堆中的位置，那么就要用到`&str` ，这个类型是定长的，放在栈中
- `str` 指一串排在内存里的纯 UTF-8 字符（只有文字本身，没有元数据）。就好比输入的文字，不定长的，且该文字也没有携带任何长度信息
- `&str`是一种类型，和`i32`等类型一样

| 内容            | 含义                   |
| ------------- | -------------------- |
| **指针（8 字节）**： | 指向那串 `str` 的实际内存起始位置 |
| **长度（8 字节）**： | 明确说明这串 `str` 一共有几个字节 |
# dyn Trait （动态分发）
- `dyn trait` 只能接对象安全的trait,不能接泛型trait
- `dyn trait` 类型和 `stc` 类型都是不定长的，同理也需要一个胖指针，那就是`&dyn trait` 或者是`Box<dyn trait>`
```rust
//这里的animal 是一个trait 
//不加 Box 只能用引用`&dyn`；加 Box 获得所有权、能独立存放、放进集合。
fn get(flag: bool) -> Box<dyn Animal> {
    if flag { Box::new(Cat) } else { Box::new(Dog) }
}
```
