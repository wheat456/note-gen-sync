## 所有权的三条核心规则
- **每个值都有一个所有者（Owner）**：即绑定该值的变量。
- **同一时刻，一个值只能有一个所有者**。
- **当所有者离开其作用域（Scope）时，该值会被自动销毁并释放内存（调用 `Drop`）**。

## 所有权的转移与复制

### 移动
- 对于分配在堆上的复杂数据（如 `String`、`Vec`）或者是自定义的结构体(没有实现`copy`)，赋值或传参时会触发**所有权转移（Move）**

### 复制
- 存储在栈上的基本类型（如整数、浮点数、布尔值、定长数组）实现了 `Copy` Trait，赋值时会自动进行低成本的按位复制，原变量依然有效：

## 变量遮蔽
- 当使用同名变量会`shadow`之前的变量,前后两个变量不是同一个，被`shadow`后前一个不能用
```rust
变量遮蔽(shadowing)
fn main() {
    let x = 5;
    // 在main函数的作用域内对之前的x进行遮蔽
    let x = x + 1; //x变量只作用于右边，左边被shadowing

    {
        // 在当前的花括号作用域内，对之前的x进行遮蔽
        let x = x * 2;
        println!("The value of x in the inner scope is: {}", x);
    }

    println!("The value of x is: {}", x);
}
```

# 解构
- 当按值解构一个结构体时，非 `Copy` 字段的所有权会被转移给新绑定的变量，而 `Copy` 字段则执行复制：
- 使用`ref` 避免移动
```rust
let Person { name, ref age } = person;
```

- 只提取特定的字段，对其他字段不会有影响，同理tuple也是
```rust
let Person { name, .. } = p;
```
