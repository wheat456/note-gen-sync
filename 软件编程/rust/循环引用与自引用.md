# Weak
- 通过`downgrade`来获得一个一个`weak pointer`，再用weak pointer（upgrade） 来获得strong pointer(也就是对数据有所有权的智能指针)，用于操作数据，但是也有可能获取不到。
- 本来要使用rc.clone()来获得一个有所有权的指针，但是现在使用weak就可以创建一种可有可无的练习

# 自引用
- 下面代码错误，不能再借用了一个数据之后再发生move
```rust
    let x: String = "to".to_string();
    let y = &x;
    let z = x;
```
- 同理，在引用时，v还没有创建成功
```rust
    let v = SelfRef {
        value: "aaa".to_string(),
        pointer_to_value: &v.value
    };
```
- 当自引用发生移动时，引用还是之前的地址
