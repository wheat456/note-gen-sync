- `Vec`、`String` 和 `HashMap` 等是定长类型,在~={cyan}编译时=~能初始知道一个大小
- ~={purple}动态数据=~在~={cyan}堆=~上，~={cyan}栈=~中存在~={purple}引用类型（指向堆的指针）=~，运行时知道大小
	- `DST` 类型有: `str`（字符串的长度不知道）、`[T]`（切的长度不知道）、`dyn Trait`，必须通过借用或者Box间接使用
	- 切片是动态大小类型，`&str`在栈中是固定大小
	- `String`是固定大小
## Size特征
- Rust 隐式的为每一个泛型函数增加了 `Sized` bound
- 默认的泛型参数都实现了`Sized`，一些固定大小的数据都实现了`Sized`,除了`str`和`trait`
- 每个`trait`都是通过名称来引用的动态大小类型
- 如果要使用泛型参数为动态类型，则约束为`?Size`,代表既有可能是固定大小，也有可能是动态大小数据类型，参数应该是`&T`,只能通过引用来使用动态大小数据类型
## Box\<str>
- 常用于比string更小内存且不修改的场景
```rust
let s1:Box<str>="fsd".into();
```
# str
- 是一个动态的数据类型，因为是由字符组成。str代表C中的`char *c ="fsfs"`，虽然知道str但是不知道长度但是有\0结尾，对于rust不安全，所以需要管理长度，`&str`是一个结构体，用地址和长度，就能管理字符串,而`string`还有一个容量来管理长度，能实现访问的长度在容量内都是合法的。str可以存在硬编码也可以在堆中,但是需要一个长度来管理。

# dyn
- `dyn trait` 只能接对象安全的trait,不能接泛型trait
```rust
//这里的animal 是一个trait 
//不加 Box 只能用引用`&dyn`；加 Box 获得所有权、能独立存放、放进集合。
fn get(flag: bool) -> Box<dyn Animal> {
    if flag { Box::new(Cat) } else { Box::new(Dog) }
}
```
