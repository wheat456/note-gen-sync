# 命令

# Event
- 场景：后台长任务进度通知、系统状态变化监控、多窗口状态同步
后端
```rust
use tauri::Emitter; // Tauri v2

// 向所有窗口广播
app_handle.emit("download-progress", 42)?;

/* 发送到特定窗口
*/
let main_window = app_handle.get_webview_window("main").unwrap(); main_window.emit("notification", "任务完成")?;

// 监听前端发来的事件
let event_id=app_handle.listen("user-action", |event| {
    println!("Received: {:?}", event.payload());
});
app_handle.unlisten(event_id);

```

前端
```js
import { listen, emit } from '@tauri-apps/api/event';

/* 监听后端推送
 返回unlisten 用于卸载 unlisten()
 泛型 'number' 代表收到的payload 也就是 event.payload 拿到的数据
 'download-progress' 代表事件名
*/
const unlisten = await listen<number>('download-progress', (event) => {
    console.log(`Progress: ${event.payload}%`);
});

/* 单次监听


*/
await once('app-ready', (event) => { console.log('应用已就绪'); });


/* 发送事件给后端或其他窗口
'user-action' 代表事件名
'{ action: 'refresh' }' payload 数据
*/
await emit('user-action', { action: 'refresh' });

/* 定向发送
仅发送给特定 label 的窗口（例如仅发给主窗口 "main"）
*/
await emitTo('main', 'config-updated', { theme: 'dark' });
```


# Channel 
```rust 
use tauri::ipc::Channel;

/*
channel 中的T必须可以serde
*/
#[tauri::command]
fn stream_logs(channel: Channel<String>) {
    std::thread::spawn(move || {
        for i in 1..=5 {
            std::thread::sleep(std::time::Duration::from_millis(500));
            channel.send(format!("Log line {}", i)).unwrap();
        }
    });
}
```


```js
import { invoke, Channel } from '@tauri-apps/api/core';


/* 创建channel

*/
const onLog = new Channel<string>();
onLog.onmessage = (message) => {
    console.log('Received stream:', message);
};

await invoke('stream_logs', { channel: onLog });
```
