## 结构体
```rust
struct Point<T> { x: T, y: T, } //只有一种类型

struct Point<T,U> { x: T, y: U, }//两种不同类型
```
### 方法中的泛型
```rust
struct GenericVal<T>(T);// 添加某种类型的限制
impl GenericVal<i32>{
	fn temp(&self,x:i32){
	}
}
---------------------------------------------
//没有限制
struct GenericVal<T,U>(T,U);
impl <T,U>GenericVal<T,U>{
	fn temp(&self,x:T){
	}
}
```

## trait
- 当类型是泛型时
```rust
trait DoubleDrop<T> {
    // 定义一个调用者的方法，接受一个额外的参数 `T`，但不对它做任何事。
    fn double_drop(self, _: T);
}

impl<T, U> DoubleDrop<T> for U { //为U实现trait
    // 此方法获得两个传入参数的所有权，并释放它们。
    fn double_drop(self, _: T) {}
}
```
## 约束(bound)
- 使用默认方式
```rust
struct A<T=i32>{}//同样适用于函数等类型

//多重约束
struct A<T:Debug+Display>{}//同时使用2个特征
struct A<T:Debug,U:Display>{}//分别实现特征
```
 - 使用where
```rust
//当多重约束
struct A<T,U>where T:Debug+Display,U:Trait{}
```
## 关联项
- 作用在泛型trait
```rust
trait A<X,Y>{

}// 同时该trait会作为参数或者返回值
fn difference<X,Y,Z>(arg:&Z)where Z:A<X,Y>
{

}
--------------------
//使用关联数据
trait A{
	type X;
	type Y;
}
fn differece<T>(arg:&T)where T:A{

}
//如果要加限定应该在impl或者trait中
trait A<Abc=i32>
{

}//或者
impl A for B
{
	type A=i32;
}

```
- 理解：因为trait中有泛型的数据，所以不能让函数成为泛型函数，所以泛型数据应该表明在trait上`trait<X,Y>`,所以之后在作为其他函数参数时就会要求表明泛型`fn difference<X,Y,Z>(arg:&Z)where Z:A<X,Y>`。使用关联数据就不是泛型trait了，之后也不必表明泛型`fn differece<T>(arg:&T)where T:A`。
## const泛型
### 切片
1. **不可变和可变切片**:不可变切片（`&[T]`）和可变切片（`&mut [T]`）
2. **动态大小**：切片的大小在编译时未知
## const N
- 是基于值的泛型，也就是不确定值
```rust
fn display_array<T: std::fmt::Debug>(arr: &[T]) {
    println!("{:?}", arr);
}
fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    display_array(&arr);

    let arr: [i32; 2] = [1, 2];
    display_array(&arr);
}
//未使用const 泛型
-----------------------------------------
//使用const 泛型
fn display_array<T: std::fmt::Debug, const N: usize>(arr: [T; N]) {
    println!("{:?}", arr);
}
fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    display_array(arr);

    let arr: [i32; 2] = [1, 2];
    display_array(arr);
}
```
### const fn
- 函数是在运行时被调用和执行的,提高程序运行效率[[数据类型]]
```rust
const fn add(a: usize, b: usize) -> usize {
    a + b
}

const RESULT: usize = add(5, 10); // 在函数编译时调用,接收方必须为const

fn main() {
	 let temp=add(5, 10);//在运行时调用
    println!("The result is: {}", RESULT);
}
```
