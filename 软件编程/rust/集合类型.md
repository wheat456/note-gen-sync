## Vector
- 堆中连续分布，只能存储相同类型的值
```rust
let v=Vec::new(); //会自动推导类型
let v=vec![1,2,3] // vec![] 创建空的
```
### 操作方法

| 目的                   | 方法                                         |
| -------------------- | ------------------------------------------ |
| **添加**数据             | `v.push(1);`                               |
| **添加一组**数据           | `v.extend([1,2,3]);`                       |
| **插入**数据             | `v.insert(2,4)`                            |
| **访问**数据             | `v[1]`                                     |
|                      | 使用`v.get(1)`访问，返回`Option<&T>`,在越界时返回`None` |
| **获取**一个范围的数据        | `v[1..=3]`                                 |
| **遍历**数据             | `for i in &v`                              |
| **移除某个**数据并**返回**    | `v.remove(1)`                              |
| **移除尾部**数据           | `v.pop()`                                  |
| **移除指定范围**的数据并**返回** | `v.drain(1..=3)`                           |
| **存储**不同数据           | 使用`enum`                                   |
| **批量定义**数据           | `vec![0; 3];`连续3个0                         |
|                      | `Vec::from([0,0,0]);`                      |
| 指定**容量初始化**          | `Vec::with_capacity(10);`                  |
| **调整容量**             | `v.reserve(100)`                           |
| **释放容量**             | `v.shrink_to_fit();` 调整到实际占用大小             |
| **清空**数据             | `v.clear()`                                |
| **检查**是否为**空**       | `v.is_empty()`                             |
| 其他类型**转换**为`Vec`     | `.to_vec()`                                |
| 按**条件保留**数据          | `v.retain(\|x\| *x>1)`                     |

- Vector常用方法
	- 添加数据，并清空v1`v.append(&mut v1)`
	- 截断到某个长度`v.truncate(1)`
	- 按指定索引分割成2部分`v.split_off`
- 排序：`v.sort_untable()`
- 使用`derive`，`#[derive(Debug, Ord, Eq, PartialEq, PartialOrd)]`,`people.sort_unstable();`
## HashMap
- 使用`use std::collections::HashMap;`
- `let mut my_gems = HashMap::new();`
- 所有K应该同一类型，所有V应该同一类型
- 用法
	- `HashMap::with_capacity(10)`初始化容量
	- 查询`h.get(&name)`,返回`Option<T>`,找不到会返回`None`
	- 更新值
		- 覆盖h.insert("hello",20);
		- 查询值，如果不存在则插入值，`scores.entry("Yellow").or_insert(5);`
- `所有权`
	- 实现了`Copy`的会复制，否则会发生移动

## String
当你需要~={green}所有权和可变性时=~，请使用 `String`，当你只~={red}需要引用文本而不获得所有权时=~，请使用 `&str`。
### 字符串拼接
```rust
let x ="hello".to_string();
let y = "world".to_string();
let z = x+"-"+&y;
format!("{}-{}",x,y);
```
- unicode需要2个字节,但是String是vec\<u8>，所以不能使用下标索表
- 需要使用chars()解析单个字符
### 常用方法
- `.contains("...")` 检查 `String` 或 `&str` 是否包含~={green}指定的子字符串=~。
- `.find（“...”）` 和 ` .rfind（“...”）`在字符串中搜索模式，返回一个 `Option<usize>`，指示第一个 （`.find`） 或最后一个 （`.rfind`） 匹配项的起始索引。
- `.trim（）、.trim_start（）、.trim_end（）`  从字符串切片的开头和/或结尾~={green}删除空格=~。1.删除开始和结束的空格
2.删除开头的空格 3.删除结尾的空格
- `.trim_matches("pattern")` 删除特定的开头和结尾
- `.to_uppercase（）` `.to_lowercase（）` 全部转为大写和小写
- `.split（“pattern”）.split_whitespace（）` 按照特定字符或空格分解，返回迭代器
- `.join("separator")` 在迭代器的元素中插入分隔符
- `.starts_with（“...”）` 和 `.ends_with（“...”）` 检查是否以指定的开头和结尾
- `.chars().rev()` 转换为迭代器后反转
- `.chars().nth(index)` 检索特定索引的字符
- `.chars().count()` 返回字符数目
- .replace("被替换的", "replacement") 替换字符串
- `.replace_range(range, "replacement")` 替换特定范围
-  `.push('x')` 添加单个字符
-  `.push_str("...")` 添加字符串
- `.insert_str(position, "substring")` 特定位置插入字符串
-  `.escape_debug()` 转义字符串中的特殊字符，通常用于调试输出。
-  `.as_bytes()` 返回整个字符串的字节切片 u8类型
