## Vector
- 堆中连续分布，只能存储相同类型的值
```rust
let v=Vec::new(); //会自动推导类型
let v=vec![1,2,3] // vec![] 创建空的
```
### 操作方法

| 目的                   | 方法                                         |
| -------------------- | ------------------------------------------ |
| **添加**数据             | `v.push(1);`                               |
| **添加一组**数据           | `v.extend([1,2,3]);`                       |
| **插入**数据             | `v.insert(2,4)`                            |
| **追加**数据并**清空源**     | `vec1.append(&mut vec2);`                  |
| **访问**数据             | `v[1]`                                     |
|                      | 使用`v.get(1)`访问，返回`Option<&T>`,在越界时返回`None` |
| **获取**一个范围的数据        | `v[1..=3]`                                 |
| **遍历**数据             | `for i in &v`                              |
| **移除某个**数据并**返回**    | `v.remove(1)`                              |
| **移除尾部**数据           | `v.pop()`                                  |
| **移除指定范围**的数据并**返回** | `v.drain(1..=3)`                           |
| **截断**数据             | `vec.truncate(2);` 保留前两个                   |
| **拆分**数据             | `v.split_off(2)` 修改源`vec`返回被拆分的`vec`       |
| **存储**不同数据           | 使用`enum`                                   |
| **批量定义**数据           | `vec![0; 3];`连续3个0                         |
|                      | `Vec::from([0,0,0]);`                      |
| 指定**容量初始化**          | `Vec::with_capacity(10);`                  |
| **调整容量**             | `v.reserve(100)`                           |
| **释放容量**             | `v.shrink_to_fit();` 调整到实际占用大小             |
| **清空**数据             | `v.clear()`                                |
| **检查**是否为**空**       | `v.is_empty()`                             |
| 其他类型**转换**为`Vec`     | `.to_vec()`                                |
| 按**条件保留**数据          | `v.retain(\|x\| *x>1)`                     |
| **排序**数据             | `v.sort_untable()` 相同元素顺序忽略                |

- 使用`derive`，`#[derive(Debug, Ord, Eq, PartialEq, PartialOrd)]` 后该`struct`就拥有了使用`= > <`等操作符的能力

| 宏          | 作用                                                                                     | 场景                                                                          |
| ---------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `Debug`    | 支持使用 `{:?}` 或 `{:#?}` 打印调试信息                                                           | println!("{:?}", user);                                                     |
| PartialEq  | 重载 `==` 和 `!=` 操作符                                                                     |                                                                             |
| Eq         | 一个标记 Trait（自身没有方法），向编译器承诺该类型**严格满足自反性**（即任何值都满足 $a == a$）                              |                                                                             |
| PartialOrd | 重载 `<`, `<=`, `>`, `>=` 操作符，实现 `partial_cmp` 方法。                                       | 1.先比较第 1 个字段。如果不相等，直接得出大小关系，**后面的字段完全被忽略**。2.如果第 1 个字段相等，才会继续比较第 2 个字段。<br> |
| Ord        | 保证集合中任意两个元素都能明确比出大小（返回 `Ordering::Less \| Equal \| Greater`），提供 `cmp`、`max`、`min` 等方法。 |                                                                             |
|            |                                                                                        |                                                                             |
- 只比较一个字段或者遇到有不可比较的字段时使用
```rust
impl PartialOrd for User {
    fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
        Some(self.cmp(other))
    }
}
// 其他宏也是类似
```

| **维度**       | **PartialOrd（偏序）**                             | **Ord（全序）**                                             |
| ------------ | ---------------------------------------------- | ------------------------------------------------------- |
| **数学性质**     | 允许存在**无法比较大小**的情况                              | **任意两项**必定满足 $a < b$、$a == b$ 或 $a > b$ 之一              |
| **方法签名**     | `partial_cmp(&self, &Rhs) -> Option<Ordering>` | `cmp(&self, &Self) -> Ordering`                         |
| **返回值处理**    | 返回 `Option`（不可比时为 `None`）                      | 直接返回 `Ordering`（无需解包，绝不为 `None`）                        |
| **典型类型**     | `f32`, `f64`（因存在 `NaN`）                        | `i32`, `String`, `char`, `bool` 等                       |
| **Trait 依赖** | 依赖 `PartialEq`                                 | 依赖 `Eq` + `PartialOrd`                                  |
| **支持的 API**  | 支持重载 `<, <=, >, >=` 操作符                        | 支持 `vec.sort()`、`BTreeMap`、`BinaryHeap`、`std::cmp::max` |


## HashMap

```rust
use std::collections::HashMap;
let mut my_gems = HashMap::new();
```

> [!NOTE] 注意
> 所有Key应该同一类型，所有Value应该同一类型
#### 常用操作

| 目的        | 方法                                              |
| --------- | ----------------------------------------------- |
| **初始化**容量 | `HashMap::with_capacity(10)`                    |
| **获取**数据  | `h.get(&name)`,返回`Option<T>`,找不到会返回`None`       |
| **插入**数据  | `h.insert("hello",20);`                         |
| **查询**数据  | `scores.entry("Yellow").or_insert(5);`如果不存在则插入值 |


## String
当你需要所有权和可变性时，请使用 `String`，当你只需要引用文本而不获得所有权时，请使用 `&str`。
### 字符串拼接
```rust
let x ="hello".to_string();
let y = "world".to_string();
let z = x+"-"+&y;
format!("{}-{}",x,y);
```

> [!NOTE] 注意
> - `unicode`需要2个字节,但是`String`是`vec\<u8>`，所以不能使用下标索表，需要使用chars()解析单个字符

### 常用方法

| 目的                | 方法                                         |
| ----------------- | ------------------------------------------ |
| 检查包含              | `.contains("...")`                         |
| 返回找到的第一个符合条件的     | `.find（“...”）`和 `.rfind（“...”）`            |
| 删除空格              | `.trim（）、.trim_start（）、.trim_end（）`        |
| 删除特定开头和结尾         | `.trim_matches("pattern")`                 |
| 转大小写              | `.to_uppercase（）` `.to_lowercase（）`        |
| 按条件拆分             | `.split(“pattern”).split_whitespace()`     |
| 迭代器插入分隔符          | `.join("separator")`                       |
| 检查是否以特定开头或者结尾     | `.starts_with(“...”)`和 `.ends_with(“...”)` |
| 翻转                | `.chars().rev()`                           |
| 查询特定索引            | `.chars().nth(index)`                      |
| 查询字符数             | `.chars().count()`                         |
| 替换字符串             | `.replace("被替换的", "replacement")`          |
| 添加单个字符            | `.push('x')`                               |
| 添加字符串             | `.push_str("...")`                         |
| 替换特定范围            | `.replace_range(range, "replacement")`     |
| 特定位置插入字符串         | `.insert_str(position, "substring")`       |
| 转义字符串中的特殊字符       | `.escape_debug()`                          |
| 返回整个字符串的字节切片 u8类型 | `.as_bytes()`                              |
