## 深入生命周期
- `&*self`先取得值在进行引用
- 裸指针:没有所有权和生命周期
	- 不可变裸指针`*const T`
	- 可变裸指针`*mut T`
	- 因为没有生命周期，所以在作为函数传出时，会生成一个无界生命周期
	- 可以创建裸指针，但是必须在unsafe中解引用
```rust

#![allow(unused)]
fn main() {
let mut num = 5;

let r1 = &num as *const i32;
let r2 = &mut num as *mut i32;
}

```
- 生命周期约束：有多个生命周期时，必须约束，否则编译器无法知道多个变量的作用域
- 再借用`&*s`,再使用在借用之前不能使用`s`
```rust
struct DoubleRef<'a,'b:'a, T> {//b的周期至少和a一样
    r: &'a T,
    s: &'b T
}
struct Ref<'a, T: 'a> {//T的生命周期至少和a一样
    r: &'a T
}
```
- 生命周期消除
	- 再未使用生命周期时，`impl Reader for BufReader<'_>`,使用`'_`
```rust
// Rust 2015
struct Ref<'a, T: 'a> {
    field: &'a T
}

// Rust 2018
struct Ref<'a, T> {
    field: &'a T
}
```
- 引用的生命周期：从创建到最后一次使用
## &‘static
- 字符串字面值`"fsdfs"`与**特征对象**都是`'static`
- 一个引用必须和剩下程序活的一样久才能被标注为`&'static`
