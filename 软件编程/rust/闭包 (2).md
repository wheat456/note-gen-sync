## 闭包
- **声明闭包**
```rust
let func = |val|val+1;
let func = |a,b|{a=3;b=4}; 
//也可以手动指定 |a:i32,b:i32|->i32{}
```

- 捕获
  - 通过`&T` 和`mut &T` 和 `T` 
  - 如果闭包内部的变量需要变化时，需使用`mut`,`let mut s = ||y+=1;`
  - 如果闭包是`mut`的，则必须再调用后才能对变量`&mut` 或者`&`
  - 如果需要强制发送移动，则`let s = move ||y+=1`;
- 当闭包作为函数参数时
	- `Fn`表示使用`&T`
	- `FnMut`表示使用`&mut T`
	- `FnOnce`表示使用`T`,会获取所有权，只能使用一次
	- 原理：闭包实现了多种`trait`，同时作为泛型参数并以此来进行约束
- 3种`Fn`的关系
	- 所有的闭包都实现了`FnOnce`
	- 没有移出捕获变量所有权的闭包实现了`FnMut`
	- 不需要对捕获变量进行该变的闭包自动实现了`Fn`
```rust
fn apply<T>(f:T)where T:FnOnce()
{
	f();
}//闭包没有参数和返回值

fn apply_to_3<T>(f:T)where T:Fn(i32)->i32
{//闭包的参数和返回值为i32
	f(3);
}
```
- 满足闭包约束的其他函数也可以当作参数进行传递
- 当闭包作为结果返回时
```rust
fn create_fn() -> impl Fn() {
	//返回类型是实现了Fn or FnMut or FnOnce特征的类型
    move || println!("This is a: {}", text)
    // 使用move ,强制闭包获取变量所有权
}
```
## 结构体的闭包
```rust
struct Cacher<T>where T:Fn(u32)->u32{
	query:T
	value:Option<u32>
}
```

# 高阶函数
## 函数指针
- 生命周期：由函数指针的生命周期由其参数和返回值的生命周期决定。
- 可自动适配闭包的特征
- 函数指针可以被返回
```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}

let func_ptr: fn(i32, i32) -> i32 = add; // 函数指针

```
