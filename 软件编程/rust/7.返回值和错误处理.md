## panic
- 用法：`panic!("string")`
- 当主线程`panic`，程序会崩溃，子线程`panic`，程序不会崩溃
- 使用`unwrap()`，成功返回值，错误直接`panic`，`expect("自定义信息")`实现`unwrap`的解包，并携带备注信息
## Result
- 定义：可以处理的错误
```rust
enum Result<T,E>{
	Ok(T),
	Err(E)
}//T和E代表实例的类型
```

## ？
- 用法：`let mut f = File::open("hello.txt")?`
- 处理`Result`，成功就返回`Ok`中的值，失败就`return Err(e)`
```rust

//在返回Result<T,E>的后面使用？等于下面的代码
let mut f = match f {
    // 打开文件成功，将file句柄赋值给f
    Ok(file) => file,
    // 打开文件失败，将错误返回(向上传播)
    Err(e) => return Err(e),
};

```
- 在`Option`中也可以返回，失败返回`None`
# ## !
- `panic`返回的类型是`！` 为永不返回任何类型
### Option 与 Result 转换
```rust
/* `Option` 转 `Result`：使用 `.ok_or()` 或 `.ok_or_else()`
*/
fn parse_first_number(list: &[&str]) -> Result<i32, String> {
    // 将 Option 转换为 Result 后再使用 ?
    let first = list.first().ok_or("列表为空")?; 
    let num = first.parse::<i32>().map_err(|e| e.to_string())?;
    Ok(num)
}

/* `Result` 转 `Option`：使用 `.ok()`
*/
fn parse_optional_number(s: &str) -> Option<i32> {
    // 将 Result 丢弃错误变为 Option 后再使用 ?
    let num = s.parse::<i32>().ok()?; 
    Some(num * 2)
}

```

## unwrap和？
- `unwrap`
	- 如果是`Err`或是None直接panic!
- `? `
	- 如果是`Err`就返回`Err` 类型
## 自定义错误
```rust
use std::error::Error;

fn main() ->Result<(),ErrorA>{

    println!("Hello, world!");

    match fn_error() {

        Err(e)=>{

            println!("{}",e);

            println!("{:?}",e.source());
        } ,
        _=>println!("OK")  

    }
    Ok(())
}

// 自定义错误
#[derive(Debug)]
struct ErrorA{
    err:ErrorB //错误来源
}

#[derive(Debug)]
struct ErrorB;
impl std::fmt::Display for ErrorA{

    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "ErrorA") //错误信息
    }
}

impl std::error::Error for ErrorA {
    fn source(&self) -> Option<&(dyn std::error::Error + 'static)> {
        Some(&self.err) //错误来源
    }
}

impl std::fmt::Display for ErrorB{
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
       write!(f, "ErrorB")
    }
}
  
impl std::error::Error for ErrorB {
}

fn fn_error()->Result<(),ErrorA>{
    Err(ErrorA{err:ErrorB})
}
```

## anyhow

依赖
```toml
anyhow="1.0"
```

```rust
use anyhow::Result;
fn xx()->Result<()> // 可以不用指定错误类型
```

```rust
fn read_file_content(path: &str) -> Result<String> {
    std::fs::read_to_string(path)
        .with_context(|| format!("Failed to read file at path: {}", path))
}
fn main() -> Result<()> {
    let content = read_file_content("example.txt")?;
    println!("File content: {}", content);
    Ok(())
}
```
