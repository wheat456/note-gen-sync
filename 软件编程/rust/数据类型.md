## 所有权
-  栈中的所有数据都必须占用已知且固定的大小，不确定的数据放在堆上，将返回的指针放在栈上
### 移动
- 在堆上的数据由指针控制，发生移动就是复制栈上的指针，同时~={red}失效=~之前的指针
### 复制
- 大小不可变的类型放在栈上，移动的行为是复制，相当于~={red}创建=~了~={green}新的变量=~，原因实现了`copy`

## 变量（variable)
### 变量遮蔽
- 当使用同名变量会`shadow`之前的变量,前后两个变量不是同一个，被`shadow`后前一个不能用
```rust
变量遮蔽(shadowing)
fn main() {
    let x = 5;
    // 在main函数的作用域内对之前的x进行遮蔽
    let x = x + 1; //x变量只作用于右边，左边被shadowing

    {
        // 在当前的花括号作用域内，对之前的x进行遮蔽
        let x = x * 2;
        println!("The value of x in the inner scope is: {}", x);
    }

    println!("The value of x is: {}", x);
}
```

## 常量(const)
- 关键字是`const`而不是`let`
- 定义常量必须~={red}指明类型=~（例如 i32）不能省略，且~={red}不可变=~其值在编译时已经确定
- 定义常量时变量的命名规则一般是全部大写
- 可以在~={red}局部=~中定义，遵循作用域，也就是有~={green}生命周期=~
```rust
const MAX_ID: usize =  usize::MAX / 2;//常量必须表明大小,这里是usize
fn main() {
   println!("用户ID允许的最大值是{}",MAX_ID);
}
```
## 静态变量(static)
- 程序启动时初始化，在全局数据区中
- 类似C中的~={green}全局变量=~
- 必须使用`unsafe`语句块才能~={red}访问和修改=~`static`变量
- 不能在局部定义，只能在~={green}全局区=~定义，生命周期为整个运行时期
```rust
static mut REQUEST_RECV: usize = 0;
fn main() {
   unsafe {//使用unsafe来修改
        REQUEST_RECV += 1;
        assert_eq!(REQUEST_RECV, 1);
   }
}
```
## 原子类型
```rust
use std::sync::atomic::{AtomicUsize,Ordering};  
static REQUEST_RECV:AtomicUsize=AtomicUsize::new(0);  
  
fn main() {  
    for _ in 0..10{  
        REQUEST_RECV.fetch_add(1,Ordering::Relaxed);  
    }  
}
```
