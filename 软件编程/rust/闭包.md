## 闭包
- **声明闭包**
```rust
let func = |val|val+1;
let func = |a,b|{a=3;b=4}; 
//也可以手动指定 |a:i32,b:i32|->i32{}
```
### 捕获
- **作用：** 能直接访问作用域内的各种变量，不像函数在`{}`外的变量就不能用
- **三种方式**：通过`&T` 和`mut &T` 和 `T` 
```rust
//以何种形式的捕获完全取决于里面的函数如何使用
let mut closure = || s.push_str(" world"); //mut &T ，此时s变量可变
let closure = || println!("{}", s); //&T
let closure = || { let _t = s.into_bytes(); }; // T
let closure = move || { let _t = s.into_bytes(); }; // 强制拿到所有权
```




# 高阶函数
## 函数指针
- 生命周期：由函数指针的生命周期由其参数和返回值的生命周期决定。
- 可自动适配闭包的特征
- 函数指针可以被返回
```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}

let func_ptr: fn(i32, i32) -> i32 = add; // 函数指针

```
