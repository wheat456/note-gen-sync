# Send
类型的**所有权**可以安全跨线程转移。
- **`Send`**：表明数据的所有权可以在线程间安全转移。几乎所有原生类型都是 `Send`，但裸指针 `*const T`、`Rc<T>` 不是。

# Sync
- 类型的**不可变引用 `&T`** 可以安全在多个线程间共享
- 表明在多个线程间共享引用（`&T`）是安全的。换言之：**若 `&T` 是 `Send`，则 `T` 就是 `Sync`**

# 标准库
### 创建与等待线程
```rust
use std::thread;
use std::time::Duration;

fn main() {
    // spawn 接收一个闭包并返回一个 JoinHandle
    let handle = thread::spawn(|| {
        for i in 1..=3 {
            println!("子线程执行: {i}");
            thread::sleep(Duration::from_millis(10));
        }
    });

    println!("主线程先执行...");

    // 等待子线程执行完毕；如果省略 join，主线程退出时子线程会被直接终止
    handle.join().unwrap(); join
    println!("子线程已结束");
}
```

### 捕获变量
- 捕获的变量生命周期要么使用`move` ,要么生命周期为`static`
```rust
use std::thread;

fn main() {
    let message = String::from("Rust 并发");

    // 使用 move 关键字将 message 的所有权转移进闭包
    let handle = thread::spawn(move || {
        println!("子线程消费数据: {message}");
    });

    // 此处无法再使用 message（已被 move）
    handle.join().unwrap();
}
```
### 作用域线程
- 所有建立的子线程都是在作用域中，所有捕获的变量就不用担心生命周期
```rust
use std::thread;

fn main() {
    let data = vec![1, 2, 3, 4, 5];

    // 在普通 spawn 中，你必须用 Arc 包裹 data
    // 但在 scope 中，直接传引用即可：
    thread::scope(|s| {
        s.spawn(|| {
            println!("子线程 1 观察总和: {}", data.iter().sum::<i32>());
        });

        s.spawn(|| {
            println!("子线程 2 观察元素个数: {}", data.len());
        });
    }); // 离开此大括号时，自动隐式等待两个子线程全部结束

    // 离开 scope 后，主线程依然拥有 data，没有任何所有权损失
    println!("主线程继续使用: {:?}", data);
}
```
- barrier用于同步线程数,类似与rc有多所有权，在每个线程中都有barrier的所有权,当执行到b.wait，时就记录下执行到这里的线程数，即可同步线程数

## 共享内存
- **锁不是独立的看门人，而是包裹数据的容器**。必须先获取锁守卫（`LockGuard`），才能解引用访问内部数据。
- `Mutex<T>` 是一个智能指针。更准确的说，`lock` 调用 **返回** 一个叫做 `MutexGuard` 的智能指针。
```rust
use std::sync::Mutex;

fn main() {
    let m = Mutex::new(5);

    {
        let mut num = m.lock().unwrap();
        *num = 6;
    }
    println!("m = {:?}", m);
}
```
- m指向一个结构体，这个结构体有一个变量记录锁的状态，同时存储数据，当锁被拿走时，改变变量状态，其他线程调用lock会阻塞。当锁未被拿走，调用lock会返回'自身‘就可以访问数据

## 原子操作
- **`load(order)`**：原子地读取内存值。
- **`store(val, order)`**：原子地向内存写入新值，覆盖旧值。
- **`fetch_add` / `fetch_sub` / `fetch_and`**：读取旧值，同时执行算术/位运算并写回，**返回修改前的旧值**。
- **`compare_exchange`（简称 CAS）**： “比较并交换”，无锁算法的心脏。 逻辑为：_“如果当前值等于期待的 A，则将其更新为 B；如果不等于 A，则更新失败并返回实际的当前值”_。
```rust
 let counter = Arc::new(AtomicUsize::new(0)); // 其他线程需要获得所有权，所以使用arc
 counter_clone.fetch_add(1, Ordering::Relaxed);
```

## 协同原语

`Mutex<T>` 与 `RwLock<T>`
**锁不是独立的看门人，而是包裹数据的容器**。必须先获取锁守卫（`LockGuard`），才能解引用访问内部数据。
```rust
use std::sync::{Arc, Mutex};
use std::thread;

let counter = Arc::new(Mutex::new(0));
let mut handles = vec![];

for _ in 0..5 {
    let counter_clone = Arc::clone(&counter);
    let handle = thread::spawn(move || {
        // lock() 返回 RAII 守卫，离开作用域自动释放锁
        let mut guard = counter_clone.lock().unwrap();
        *guard += 1;
    });
    handles.push(handle);
}

for h in handles { h.join().unwrap(); }
println!("Result: {}", *counter.lock().unwrap());
```

`RwLock<T>`（读写锁）
允许多个读者并发访问，或独占一个写者（读者-写者模型）。适用于“读多写少”的场景：
```rust
use std::sync::RwLock;

let lock = RwLock::new(5);

// 多个只读锁并存
{
    let r1 = lock.read().unwrap();
    let r2 = lock.read().unwrap();
    assert_eq!(*r1, *r2);
} // 读锁在这里 drop

// 独占写锁
{
    let mut w = lock.write().unwrap();
    *w += 1;
}
```

Condvar
```rust
use std::sync::{Arc, Mutex, Condvar};
use std::thread;

let pair = Arc::new((Mutex::new(false), Condvar::new()));
let pair_clone = Arc::clone(&pair);

thread::spawn(move || {
    let (lock, cvar) = &*pair_clone;
    let mut ready = lock.lock().unwrap();
    *ready = true;
    cvar.notify_one(); // 通知等待者
});

let (lock, cvar) = &*pair;
let mut ready = lock.lock().unwrap();
// 使用 while 循环防止虚假唤醒（Spurious Wakeup）
while !*ready {
    ready = cvar.wait(ready).unwrap(); // 自动释放互斥锁并挂起线程
}
```


Barrier
```rust
use std::sync::{Arc, Barrier};
use std::thread;

let barrier = Arc::new(Barrier::new(3)); // 等待 3 个线程集合

for _ in 0..3 {
    let b = Arc::clone(&barrier);
    thread::spawn(move || {
        println!("阶段 1 完成，等待就绪...");
        b.wait(); // 阻塞直到 3 个线程都执行到这里
        println!("全部就绪，开始执行阶段 2");
    });
}
```

# thread_local
- 用于创建**线程局部存储**,一个线程中对该变量所做的更改不会影响其他线程。
- 线程局部变量，必须是static，因为static是全局共享的
```rust
//创建线程局部变量
thread_local!(static FOO: RefCell<u32> = RefCell::new(1));

FOO.with(|f|*f.borrow(),1) //每个子线程都可以用这个方式使用

```
