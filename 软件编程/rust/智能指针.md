## deref规则总结
- 把智能指针（比如在库中定义的，Box、Rc、Arc、Cow 等）从结构体脱壳为内部的引用类型，也就是转成结构体内部的 `&v`，把多重`&`，例如 `&&&&&&&v`，归一成 `&v`

## 3种deref转换
- 当 `T: Deref<Target=U>`，可以将 `&T` 转换成 `&U`，也就是我们之前看到的例子
- 当 `T: DerefMut<Target=U>`，可以将 `&mut T` 转换成 `&mut U`
- 当 `T: Deref<Target=U>`，可以将 `&mut T` 转换成 `&U`


# Rc
- 作用：获得多所有权，自动管理生命周期，多个地方获得同一份数据
- Rc的用法
```rust
use std::rc::Rc;
fn main() {
    let a = Rc::new(String::from("hello, world"));//获得一个智能指针
    let b = Rc::clone(&a);//复制智能指针给b
	let b = a.clone();
    assert_eq!(2, Rc::strong_count(&a));
    assert_eq!(Rc::strong_count(&a), Rc::strong_count(&b))
    //Rc::strong_count(&c)获得c的引用计数
}
```


# Arc
- 使用方法和Rc类似，同样是不可修改的

## Rc与Arc
- 是不可变引用(不能用mut)，你无法修改它指向的值，只能进行读取，如果要修改
- 允许多个指针指向同一个堆

- Arc的用法
	- `std::sync::Arc`,可以在多线程中使用
	- 与Rc一样都是不可变的引用

## Cell
- **作用**：解决rust 不可变引用不能修改值的问题，只能在单线程种使用
- 用法和refcell一样，但是被操作的数据必须实现copy,也就是不能是智能指针的类型
- copy就是无堆分配
- `Cell<T>` 适用于 `Copy` 类型
```rust
use std::cell::Cell;//实现了Copy trait
fn main() {
  let c = Cell::new("asdf");
  let one = c.get();//复制了一份
  c.set("qwer");
  let two = c.get();
  println!("{},{}", one, two);
}
```

# RefCell
- 相比于 `Cell<T>`，它可以存储 **非 `Copy` 类型** 的值，并允许内部的 **可变借用**
- 运行时借用检查
	- **`borrow()`**：获取不可变借用（`&T`），允许多个并发读取。
	- **`borrow_mut()`**：获取可变借用（`&mut T`），但同一时间只能有一个可变借用。
```rust
use std::cell::RefCell;

// 存放非Copy的String
let val = RefCell::new(String::from("测试"));

// 只读借用
let read = val.borrow();
println!("{}", read);

// 可变借用修改内容
let mut write = val.borrow_mut();
write.push_str("新增文字");
```

- refcell的数据存在一个堆中，由refcell指针操作，其中方法有borrow()和borrow_mut(),都是以自身的借用去访问数据
- 用于通过编译，由用户自己维护规则,如果违反了借用规则，不会再编译时报错，而在运行时panic


## OnceCell\<T>
- 非标准库
- `OnceCell<T>` 是一个 **只能初始化一次** 的 `Cell<T>`。
- 你可以手动 `set()` 一次值，然后~={red}只能读取=~，~={red}不能再更改=~。除非你使用onecell的可变借用来修改，但是这样没有意义
