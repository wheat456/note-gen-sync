## deref规则总结
- 把智能指针（比如在库中定义的，Box、Rc、Arc、Cow 等）从结构体脱壳为内部的引用类型，也就是转成结构体内部的 `&v`，把多重`&`，例如 `&&&&&&&v`，归一成 `&v`

## 3种deref转换
- 当 `T: Deref<Target=U>`，可以将 `&T` 转换成 `&U`，也就是我们之前看到的例子
- 当 `T: DerefMut<Target=U>`，可以将 `&mut T` 转换成 `&mut U`
- 当 `T: Deref<Target=U>`，可以将 `&mut T` 转换成 `&U`

# Rc

> [!NOTE] Tip
> 通过`Rc::clone(&a)` 持有的是对原数据的`&a` 当然是不可变的

- 作用：获得多所有权，自动管理生命周期，多个地方获得同一份数据
- Rc的用法
```rust
use std::rc::Rc;
fn main() {
    let a = Rc::new(String::from("hello, world"));// 获得一个智能指针
    let b = Rc::clone(&a);// 复制智能指针给b
	let b = a.clone(); // 等同于上面那种写法
    assert_eq!(2, Rc::strong_count(&a));
    assert_eq!(Rc::strong_count(&a), Rc::strong_count(&b))
    //Rc::strong_count(&c)获得c的引用计数
}
```

# Arc
- 使用方法和Rc类似，同样是不可修改的

## Rc与Arc
- Arc的用法
	- `std::sync::Arc`,可以在多线程中使用
	- 与Rc一样都是不可变的引用

| **特性**     | **Rc<T> (Reference Counted)** | **Arc<T> (Atomically Reference Counted)** |
| ---------- | ----------------------------- | ----------------------------------------- |
| **适用场景**   | 单线程                           | 多线程                                       |
| **线程安全**   | **否**（未实现 `Send` 与 `Sync`）    | **是**（当 `T: Send + Sync` 时安全）             |
| **计数实现**   | 普通整数（`usize`）                 | 原子类型（`AtomicUsize`）                       |
| **性能开销**   | 极低（单指令普通内存加减）                 | 略高（跨核心缓存同步与原子指令开销）                        |
| **修改数据方案** | 搭配 `RefCell<T>`               | 搭配 `Mutex<T>` 或 `RwLock<T>`               |

## Cell

> [!NOTE] Tip
> 使用 `cell` 的思路是在一个只需要不可变引用的参数下还想要修改值就用`cell` 包裹数据

- **作用**：解决rust 不可变引用不能修改值的问题，只能在**单线程**中使用
```rust
use std::cell::Cell;

let c = Cell::new(10); // 注意：c 是不可变绑定
c.set(20);             // 可以在 &c 下直接修改值
println!("value: {}", c.get()); // 20

// 对于没有实现 Copy 的类型：
let s = Cell::new(String::from("hello"));
let old = s.replace(String::from("world")); // 取出 "hello"，放入 "world"
```

## RefCell
- 相比于 `Cell<T>`，它可以存储 **非 `Copy` 类型** 的值，并允许内部的 **可变借用**
- 运行时借用检查
	- **`borrow()`**：获取不可变借用（`&T`），允许多个并发读取。
	- **`borrow_mut()`**：获取可变借用（`&mut T`），但同一时间只能有一个可变借用。
```rust
use std::cell::RefCell;

// 存放非Copy的String
let val = RefCell::new(String::from("测试"));

// 只读借用
let read = val.borrow();
println!("{}", read);

// 可变借用修改内容
let mut write = val.borrow_mut();
write.push_str("新增文字");
```

- `Refcell`的数据存在一个堆中，由`Refcell`指针操作，其中方法有`borrow()`和`borrow_mut()`,都是以自身的借用去访问数据
- 用于通过编译，由用户自己维护规则,如果违反了借用规则，不会再编译时报错，而在运行时`panic`

| **特性**       | **Cell<T>**            | **RefCell<T>**                       |
| ------------ | ---------------------- | ------------------------------------ |
| **借用机制**     | **不借用**（直接拷贝或移入/移出值）   | **运行时动态借用**（返回智能指针引用）                |
| **访问方式**     | 返回值本身（复制或转移所有权）        | 返回借用引用：`Ref<T>`（只读）/ `RefMut<T>`（独占） |
| **运行时开销**    | **0 额外开销**（仅数据本身的内存大小） | **微小开销**（内部维护一个引用计数标志位 `isize`）      |
| **Panic 风险** | **绝对安全**，永不 panic      | 违背借用规则时会触发 **panic**（运行时报错）          |
| **适用类型**     | 适合小型、轻量且实现了 `Copy` 的类型 | 适合复杂类型、大型结构体或需要借用字段的场景               |

## OnceCell\<T>
- `OnceCell<T>` 是一个 **只能初始化一次** 的 `Cell<T>`。
- 你可以手动 `set()` 一次值，然后只能读取，不能再更改。
```rust
use std::cell::OnceCell;

let cell = OnceCell::new();
assert!(cell.get().is_none()); // 初始为空

// 1. 尝试写入（仅首次有效）
cell.set("hello".to_string()).unwrap();
// cell.set("world".to_string()); // 第二次写入会失败返回 Err

// 2. 直接借出 &T，不需要像 RefCell 那样处理生命周期守卫
let s: &String = cell.get().unwrap();
println!("{s}");

// 3. 惯用法：get_or_init（如果没初始化就执行闭包初始化，否则直接返回引用）
let val = cell.get_or_init(|| "fallback".to_string());
```


## lazycell
```rust
use std::cell::LazyCell;

// 定义时绑定昂贵的计算逻辑，此时闭包不会执行
let lazy_data = LazyCell::new(|| {
    println!("开始执行耗时计算...");
    vec![1, 2, 3, 4, 5]
});

println!("LazyCell 已创建，但尚未求值");

// 首次解引用访问时自动触发计算并缓存结果
println!("第一次访问，长度: {}", lazy_data.len()); // 输出: 开始执行耗时计算... 长度: 5

// 第二次访问直接走缓存，不会再次执行闭包
println!("第二次访问，长度: {}", lazy_data.len()); // 直接输出: 长度: 5
```
