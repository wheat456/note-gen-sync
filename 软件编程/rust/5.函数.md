
# 参数
- **定义：** fn name(变量:类型)`

> [!NOTE] Tip
> 这里的`mut 变量` 相当于在这个函数中该变量是可变的,比如`let mut 变量=传入过来的参数`。
> 传入过来的参数，只会以**借用**、**移动**、**复制**三种方式，当使用**借用**时，这里的变量相当于一个指针，即使`mut`也只能让变量指向不同的值。如果是**移动**或者**复制**，那么这个变量就拥有了该值，不加`mut`就无法修改对应的值

| 变量        | 含义         |
| --------- | ---------- |
| `变量名`     | 该变量是不可以修改的 |
| `mut 变量名` | 该变量可以修改    |

| 类型        | 含义  |
| --------- | --- |
| `类型`      |     |
| `&类型`     |     |
| `&mut 类型` |     |

## 函数作为参数
### 普通函数

```rust
//fn(i32,i32)->i32 
fn exec(f: fn(i32,i32)->i32, x:i32,y:i32) -> i32{ f(x,y) }

//也可以接受闭包，前提是这个闭包没有捕获变量
exec(|a,b| a*b, 3,4);
```

### 闭包
- **三种类型**： `Fn` `FnMut` `FnOnce`
- **继承关系** ：
	- `Fn: FnMut`
	- `FnMut: FnOnce`
	- 满足 `Fn` 的闭包，可以传给要求 `FnMut`、`FnOnce` 的地方
	- 满足 `FnMut`，可以传给 `FnOnce`；
#### Fn
- 闭包只做`&T`捕获
- `Fn(params)->Ret`
```rust
fn run_fn<F>(f:F) where F: Fn(i32)->i32 { let _ = f(1); let _ = f(2); // 可多次调用 }
```
#### FnMut
- 闭包只做`mut &T`捕获
- 将闭包作为变量看待，因为里面的用到了可变的东西，所以闭包这个变量也要有`mut`属性
```rust
// 这里的参数要mut f 这样闭包才能
fn run_fnmut<F>(mut f:F) where F: FnMut(){ f(); f(); // 允许多次调用 }
```
#### FnOnce
- 闭包只做`T`捕获
```rust
fn run_fnonce<F>(f:F) where F: FnOnce(){ f(); // f(); // ❌不能再调用，已经被消耗 }
```
#### 语法糖
```rust 
// 等价于 fn run<F:FnMut()>(mut f:F)
 fn run(mut f: impl FnMut()){ f(); }
```



# 返回值
## 闭包

```rust
fn create_fn() -> impl Fn() {
	//返回类型是实现了Fn or FnMut or FnOnce特征的类型
    move || println!("This is a: {}", text)
    // 使用move ,强制闭包获取变量所有权
}
```
## 函数
```rust
fn create_fn() -> fn() {
	//返回类型是实现了Fn or FnMut or FnOnce特征的类型
    move || println!("This is a: {}", text)
    // 使用move ,强制闭包获取变量所有权
}
```
