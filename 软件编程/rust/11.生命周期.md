- 写法
```rust
// a 和b 指代的是传入变量的生命周期，也就是传入变量的作用域
foo<`a,`b>(x:&`a i32,y:&`a i32) 
```

# 结构体的生命周期

```rust
struct AuthContext<'a> {
    token: &'a str,
}

// 2. 实现块中也必须声明 <'a>
impl<'a> AuthContext<'a> {
    // 构造函数：参数 raw 的生命周期必须与结构体的 'a 绑定
    fn new(raw_header: &'a str) -> Self {
        // 调用第三方函数，获得 &'a str
        let token = external_lib::parse_token(raw_header);
        
        AuthContext { token }
    }
}
```


## 深入生命周期
- `&*self`先取得值在进行引用
- 生命周期约束：有多个生命周期时，必须约束，否则编译器无法知道多个变量的作用域
- 再借用`&*s`,再使用在借用之前不能使用`s`
```rust
struct DoubleRef<'a,'b:'a, T> {//b的周期至少和a一样
    r: &'a T,
    s: &'b T
}
struct Ref<'a, T: 'a> {// T的生命周期至少和a一样
    r: &'a T
}
```
- 生命周期消除
	- 再未使用生命周期时，`impl Reader for BufReader<'_>`,使用`'_`
```rust
// Rust 2018
struct Ref<'a, T> {
    field: &'a T
}
```
- 引用的生命周期：从创建到最后一次使用
