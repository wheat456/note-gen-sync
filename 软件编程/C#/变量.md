# 记录
使用场景
1. 需要**不可变性（Immutability）**时
2. 需要基于“**值**”进行相等性比较时
3. 作为数据传输对象 (DTO)
4. 需要轻量级的解构（Deconstruction）支持，可以直接解构
**不可变性**
这是 **Record** 与 **Class** 最大的区别：
- **Class:** 比较的是**引用**（两个对象必须指向同一个内存地址才相等）。
-  **Record:** 比较的是**内容**（只要两个 Record 的所有属性值都一样，它们就被视为相等）。
- `record`是引用类型，但是`struct`是值类型
	- `init` 表示只是在初始阶段可以赋值，后面就不可以修改了
 ```cs
 public record User(string Name, int Age);
 
 public record User { public string Name { get; init; } // 注意这里是 init，不是 set }
 ```

## 嵌套Record
```cs
// 定义子 Record
public record Address(string City, string Street);

// 定义父 Record，其中一个属性是 Address 类型
public record User(string Name, Address Location);

// 初始化
var user = new User("张三", new Address("北京", "朝阳路"));
```

 默认不可变（就是不能再赋值了，如果有set方法，那就是可变的），想要修改就重新复制一份
 ```cs
 var user1 = new User("Alice", 25);
// 创建一个新对象，除了 Age 改为 26，其他属性和 user1 一样
var user2 = user1 with { Age = 26 }; 
 ```
