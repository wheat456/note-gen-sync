# 单独的命令
1. 继承ICommand
```cs
    public class SaveCommand : ICommand
    {
        public event EventHandler? CanExecuteChanged;

        public bool CanExecute(object? parameter) => throw new NotImplementedException();

        public void Execute(object? parameter) => throw new NotImplementedException();
    }

```

2. 其中`CanExecute` 是的参数是从Xaml 那里拿到的，返回的Bool是给Xaml控件看的，`CanExecute` 的调用是系统调用的，比如，前端点击了按钮，那么就会自动调用`CanExecute` ，查看命令是否能运行
3. `public event EventHandler? CanExecuteChanged;` 提供再次触发命令的能力，因为一般是控件来触发命令，但是有时候也需要其他地方也触发命令，那么就使用这个
