# 格式化
stringFormate={0:xxx} 其中xxx是格式方式，比如日期等
如果内容中有{}，那么就需要转移使用stringFormate={}{0:xxx} ，否则就不用

使用方法
```xml
<TextBlock Text="{Binding Value, StringFormat='数值：{0:F2} 元'}"/>
```
 - 多参数

```xml
    <TextBlock.Text>
        <MultiBinding StringFormat="姓名：{0}，年龄：{1}">
            <Binding Path="Name"/>
            <Binding Path="Age"/>
        </MultiBinding>
    </TextBlock.Text>
```

# RelativeSource
- 当想要绑定的数据不在当前上下文中就需要这个
- `Self` 就是本身，比如按钮的高宽，可以互相绑定
- `FindAncestor` 沿着 UI 向上找 
	- 比如你是一个简单的按钮，想上找就是 **window** 了
	- 此时可以选择类型 **AncestorType** 比如 button window 等
	- `AncestorLevel` 假如有多个，那么就用1 2 3 4由近到远指代
- **TemplatedParent**
	- 专门用于 **ControlTemplate**（控件模板）中
```cs
<ControlTemplate TargetType="Button">
    <Ellipse Fill="{Binding RelativeSource={RelativeSource TemplatedParent}, Path=Background}" />
</ControlTemplate>
```

- `PreviousData` 拿到当前这一行数据的**前一行数据**。



# WPF 窗口 InputBinding

`InputBinding` 是 WPF 中**将「键盘 / 鼠标操作」和「命令 / 方法」绑定**的核心机制

```cs
    <!-- 窗口 InputBinding：全局快捷键 -->
    <Window.InputBindings>
        <!-- 1. Ctrl + S 绑定保存命令 -->
        <KeyBinding Key="S" Modifiers="Control" Command="{Binding SaveCommand}" />
        
        <!-- 2. Delete 键绑定删除命令 -->
        <KeyBinding Key="Delete" Command="{Binding DeleteCommand}" />
        
        <!-- 3. Ctrl + Z 撤销 -->
        <KeyBinding Key="Z" Modifiers="Control" Command="{Binding UndoCommand}" />
        
        <!-- 4. 鼠标左键双击 绑定命令 -->
        <MouseBinding MouseAction="LeftDoubleClick" Command="{Binding DoubleClickCommand}" />
    </Window.InputBindings>
```
### 1. 两个子类（实际只用这两个）

- **`KeyBinding`**：绑定**键盘按键**（最常用）
- **`MouseBinding`**：绑定**鼠标操作**
