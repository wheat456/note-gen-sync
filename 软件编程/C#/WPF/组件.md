# 快捷键

`<AccessText` 是下划线，相当于按下alt后加一个键就能触发

```xml
<Button>
    <AccessText Text="_点击我"/> //或者xxx(_F)
</Button>
```

`AccessKeyManager`  用来 **“监听并拦截快捷键按下动作”** 的。
当按下快捷键时，有默认的动作，但是不想执行默认的动作就可以用这个给重写
```xml

<Border Background="LightGray" Padding="10"
        AccessKeyManager.AccessKeyPressed="Border_AccessKeyPressed">
    <AccessText Text="按下 Alt+C 触发自定义事件(_C)" />
</Border>
```

# 路由
## frame
通过 `MainFrame.Navigate(new Uri("Pages/SettingPage.xaml", UriKind.Relative));`
导航到自定义`Page`
`Page`：创建一个`Pages`文件夹，里面放的就是`Page.xaml`文件
```xml
<Window ...>
    <Grid>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="200"/> <ColumnDefinition Width="*"/>   </Grid.ColumnDefinitions>

        <Frame x:Name="MainFrame" 
               Grid.Column="1" 
               Source="Pages/HomePage.xaml" 
               NavigationUIVisibility="Hidden"/> </Grid>
</Window>
```

# MVVM 路由模式
将动态的页面与VM关联，通过改变VM来切换页面

```xml
<Window.Resources>
    <DataTemplate DataType="{x:Type local:HomeViewModel}">
        <local:HomePage />
    </DataTemplate>
</Window.Resources>

<Grid>
    <ContentControl Content="{Binding CurrentViewModel}" />
</Grid>
```

# DataGrid

1. 首先，想到数据源`ItemsSource`，使用`ObservableCollection`
2. 如何排版
	1. 设置 `AutoGenerateColumns="True"`。DataGrid 会根据你类里的属性名，自动生成列。
	2. 设置 `AutoGenerateColumns="False"`。你会立刻想到要去定义 `DataGrid.Columns`

`datagrid` 就是一张表格，不过是动态的，数据变，表格中的内容也变
1. 准备一个数据对象，比如 `ObservableCollection<T>`
2. 在界面上放置 `datagrid`，并关联数据
```xml
<DataGrid ItemsSource="{Binding UserList}" />
```
3. 可以自动写列或者手动写列
```xml
<DataGrid ItemsSource="{Binding Users}" AutoGenerateColumns="True" />
```
手动写列
```xml
<DataGrid ItemsSource="{Binding Users}" AutoGenerateColumns="False">
    <DataGrid.Columns>
        <DataGridTextColumn Header="用户名" Binding="{Binding Name}" Width="*" />
        
        <DataGridTemplateColumn Header="权限状态">
            <DataGridTemplateColumn.CellTemplate>
                <DataTemplate>
                    <Ellipse Width="10" Height="10" 
                             Fill="{Binding IsAdmin, Converter={StaticResource AdminToColorConverter}}" />
                </DataTemplate>
            </DataGridTemplateColumn.CellTemplate>
        </DataGridTemplateColumn>
    </DataGrid.Columns>
</DataGrid>
```
