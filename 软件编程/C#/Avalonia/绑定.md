```xml
<ContentControl Content="{Binding CurrentUser}" ContentTemplate="{StaticResource MyUserTemplate}" />
```
一般来说，content 指定的是数据，而contentTemplate 指定的是模板
，这两者都需要指定。但是如果在数据模板中指定了类型，那么ContentTemplate 就不用写
```xml
<DataTemplate DataType="{x:Type local:UserViewModel}">
    </DataTemplate>

```
ContentTemplate 这个只能放数据模板


# ava
绑定命名控件
```xml
<TextBox Name="other">

<!-- 绑定到命名为“other”控件的Text属性 -->
<TextBlock Text="{Binding #other.Text}"/>
```

绑定到祖先
```xml
<Border Tag="Hello World!">
  <Border>
    <TextBlock Text="{Binding $parent[1].Tag}"/>
  </Border>
</Border>
```
索引器从0开始，因此`$parent[0]`等同于`$parent`。

按照类型
```xml
<Border Tag="Hello World!">
  <Decorator>
    <TextBlock Text="{Binding $parent[Border].Tag}"/>
  </Decorator>
</Border>
```


组合形式
```xml
<Border Tag="Hello World!">
  <Border>
    <Decorator>
    <TextBlock Text="{Binding $parent[Border;1].Tag}"/>
    </Decorator>
  </Border>
</Border>
```

如果需要在祖先类型中包含XAML命名空间，一般使用`:`字符：

```
<local:MyControl Tag="Hello World!">
  <Decorator>
    <TextBlock Text="{Binding $parent[local:MyControl].Tag}"/>
  </Decorator>
</local:MyControl>
```


# 转换绑定值
可以使用`！`取反
双感叹号可用于将非布尔值转换为布尔值。
```xml
<StackPanel>
  <TextBox Name="input" IsEnabled="{Binding AllowInput}"/>
  <TextBlock IsVisible="{Binding !AllowInput}">Sorry, no can do!</TextBlock>
</StackPanel>

```
