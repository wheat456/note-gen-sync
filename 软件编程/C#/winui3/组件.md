# relativepanel
## 用在这个容器中的组件上
- **`RelativePanel.AlignTopWithPanel="True"`**: 与 Panel 顶部对齐
- **`RelativePanel.AlignBottomWithPanel="True"`**: 与 Panel 底部对齐
- **`RelativePanel.AlignLeftWithPanel="True"`**: 与 Panel 左侧对齐
- **`RelativePanel.AlignRightWithPanel="True"`**: 与 Panel 右侧对齐
- **`RelativePanel.AlignHorizontalCenterWithPanel="True"`**: 在 Panel 中水平居中
- **`RelativePanel.AlignVerticalCenterWithPanel="True"`**: 在 Panel 中垂直居中
# 用在这个容器中的组件同级
- **`RelativePanel.RightOf="TargetName"`**: 位于 `TargetName` 的**右侧**
- **`RelativePanel.LeftOf="TargetName"`**: 位于 `TargetName` 的**左侧**
- **`RelativePanel.Below="TargetName"`**: 位于 `TargetName` 的**下方**
- **`RelativePanel.Above="TargetName"`**: 位于 `TargetName` 的**上方**

##  同级元素对齐
- **`RelativePanel.AlignTopWith="TargetName"`**: 与 `TargetName` **顶边对齐**
- **`RelativePanel.AlignBottomWith="TargetName"`**: 与 `TargetName` **底边对齐**
- **`RelativePanel.AlignLeftWith="TargetName"`**: 与 `TargetName` **左边对齐**
- **`RelativePanel.AlignRightWith="TargetName"`**: 与 `TargetName` **右边对齐**
- **`RelativePanel.AlignHorizontalCenterWith="TargetName"`**: 与 `TargetName` **水平中心对齐**
- **`RelativePanel.AlignVerticalCenterWith="TargetName"`**: 与 `TargetName` **垂直中心对齐**
