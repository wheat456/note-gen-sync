# 错误处理

### 命令中的错误处理
不要使用messagebox，而是使用`Interaction`
```cs
// 1. 定义一个交互：输入错误信息，输出用户是否想重试
public Interaction<string, bool> ConfirmError { get; } = new();

// 2. 在命令中使用
LoginCommand = ReactiveCommand.CreateFromTask(async () => {
    try {
        await DoWork();
    } catch (Exception ex) {
        // 唤起 UI 层处理
        bool retry = await ConfirmError.Handle(ex.Message);
        if (retry) await DoWork();
    }
});
```
### 不中断流
没有发生异常就SearchResult传递下去，如果发生了异常就捕获然后交给ex去处理
```cs
var searchObservable = this.WhenAnyValue(x => x.SearchTerm)
    .SelectMany(term => SearchRemoteApi(term)
        .Catch<SearchResult, Exception>(ex => 
        {
            // 如果报错，返回一个空的搜索结果，而不是让流死掉
            return Observable.Return(SearchResult.Empty);
        })
    );
```

### 中断流做法
遇到错误就`throw new Exception("网络连接超时！"); `,然后再在`ThrownExceptions.Subscribe`q去统一处理
```cs
public MyViewModel()
{
    // 创建命令
    LoginCommand = ReactiveCommand.CreateFromTask(async () => {
        await Task.Delay(500);
        throw new Exception("网络连接超时！"); 
    });

    // 统一处理该命令的错误
    LoginCommand.ThrownExceptions.Subscribe(ex => {
        // 在这里把错误信息显示给用户
        this.ErrorMessage = ex.Message;
        Console.WriteLine($"捕获到异常: {ex.Message}");
    });
}
```
