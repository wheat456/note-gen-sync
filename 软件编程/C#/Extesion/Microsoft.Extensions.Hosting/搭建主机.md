```cs
using Microsoft.Extensions.Hosting;

// 1. 创建默认主机构建器并开始配置
IHost host = Host.CreateDefaultBuilder(args)
    // 2. 这里可以添加更多的服务或配置...
    // 例如：.ConfigureServices(...)
    .Build(); // 3. 构建 IHost 实例

// 4. 运行主机
await host.RunAsync();
```


# 配置
```cs
IHost host = Host.CreateDefaultBuilder(args)
    .ConfigureServices((hostContext, services) => // 🔑 就在这里！
    {
        // 注册你的 IHostedService 后台服务
        services.AddHostedService<MyBackgroundService>();
        
        // 注册其他自定义服务，例如：
        services.AddSingleton<ICustomApi, CustomApi>();
        
    })
    .Build();
```

# 获取appsetting.json
```cs
using Microsoft.Extensions.Configuration;

public class MyBackgroundService : BackgroundService
{
    private readonly IConfiguration _configuration;

    // 1. 通过构造函数注入 IConfiguration 接口
    public MyBackgroundService(IConfiguration configuration) 
    {
        _configuration = configuration;
        
        // 2. 访问配置值
        string apiKey = _configuration["ApiKeys:ExternalService"]; 
        Console.WriteLine($"API Key is: {apiKey}");
    }
    
    // ... 其他 BackgroundService 实现细节
}
```

# Service函数
`host.Services` 就是一个di容器
- `AddSingleton<T>()` 
	- `T`是一个类，然后()中就加入对象
	- T是有类和接口时，然后使用的地方就用接口来调用方法
- `AddHostedService<T>` 添加一个服务
	- `T` 必须是一个实现接口的类，推荐是`BackgroundService`
		- 然后就会自动的生成一个类
- `GetRequiredService<T>()`获取不到就报错
- `GetService<T>()` 返回null
- `GetService<T>()` 获取一组服务
