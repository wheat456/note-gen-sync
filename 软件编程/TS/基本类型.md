# 1. 基础原始类型
```ts
// 字符串 string
let username: string = "Alice";

// 数字 number（支持整数、浮点数、二进制、十六进制等）
let age: number = 25;
let price: number = 19.99;

// 布尔值 boolean
let isOpen: boolean = true;

// null 与 undefined
let u: undefined = undefined;
let n: null = null;

// 大整数 bigint 与 唯一标识符 symbol
let big: bigint = 100n;
let sym: symbol = Symbol("key");
```
# 2. 容器与复合类型

## 数组
```ts
let list1: number[] = [1, 2, 3];
let list2: Array<string> = ["apple", "banana"];
```

## 元组

固定长度且每个位置类型固定的特殊数组：
```ts
// 必须严格对应：第 0 项是 string，第 1 项是 number
let user: [string, number] = ["Bob", 18]; 

// user = [18, "Bob"]; // ❌ 报错：类型顺序不匹配
```

## 对象 (Object)
可以直接使用字面量形式定义对象的内部结构：
```ts
let person: { name: string; age: number } = {
  name: "Charlie",
  age: 30
};
```

### 3. TypeScript 特殊类型

这几个类型是 TypeScript 类型系统的精髓，初学者需要特别注意区分：

| **类型**    | **说明**      | **使用场景 / 建议**                 |
| --------- | ----------- | ----------------------------- |
| `any`     | 放弃类型检查      | 尽量避免使用，否则失去 TS 静态检查的意义        |
| `unknown` | 类型安全的 `any` | 接收未知输入（如 API 返回），必须先做类型检查才能使用 |
| `void`    | 表示没有任何类型    | 绝大多数用于**没有返回值的函数**            |
| `never`   | 永远不可能存在的值   | 抛出异常或死循环的函数返回值，或穷尽性检查         |

## 4. 灵活的类型组合
### 联合类型 (Union Types)
```ts
let id: string | number;
id = 101;      // ✅
id = "2026-A";  // ✅
```

### 字面量类型

> [!NOTE] Tip
> 字面量类型的意思是自己用字符串定义了一个类型，比如值叫“abc”，同时它也是一种叫“abc”的类型

```ts 
// 结合联合类型，常用于状态管理
let status: "loading" | "success" | "error" = "loading";
// status = "pending"; // ❌ 报错：只能是上面三种字符串之一
```


# `let` 与 `const`

```ts
// 1. 使用 let 声明：TS 认为它以后可能会变，所以推断为宽泛的 string
let x = "hello"; // x 的类型是 string

// 2. 使用 const 声明：TS 知道它永远不会改变，所以推断为精确的字面量类型
const y = "hello"; // y 的类型是 "hello"
```

# interface 和 type
- 描述一个**包含多个字段的对象** ,这时候用哪个完全没区别
```ts
// 用 type 写：
type User = {
  name: string;
  age: number;
};

// 用 interface 写：
interface User {
  name: string;
  age: number;
}
```
- type 可以给任何东西起别名
```ts
// 只能选“男”或“女”，给这个规则起名叫 Gender
type Gender = "男" | "女";

// 只能是 1、2、3，起名叫 Dice
type Dice = 1 | 2 | 3;
```

# Record
`Record<K, V>` 就是 TypeScript 专门给普通 JavaScript 对象 `{}` 定制的 `Dictionary<TKey, TValue>`。
用来快速构造一个**键为 `K` 类型、值为 `T` 类型**的对象结构。
TS 允许你在定义对象时，用 `in` 关键字去**遍历一个联合类型**：
```ts
type Record<K extends keyof any, T> = {
  [P in K]: T;
};

type Keys = 'name' | 'age';

// 语法：[P in Keys] 相当于把 Keys 里的每一项依次拿出来当作属性名
type Person = {
  [P in Keys]: string;
};

// 上面的代码经过 TS 展开后，等价于：
// type Person = {
//   name: string;
//   age: string;
// };
```
- `keyof any` 限制键只能是 `string | number | symbol`。
- `P in K` 会遍历联合类型 `K` 中的每一个键，并将值类型统一定义为 `T`。
