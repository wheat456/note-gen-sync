class User {

# 修饰符

| **修饰符**         | **允许访问范围** | **说明**                    |
| --------------- | ---------- | ------------------------- |
| **`public`**    | 任何地方       | 默认修饰符，外部和子类皆可访问           |
| **`protected`** | 当前类及子类内部   | 外部实例无法直接访问                |
| **`private`**   | 仅当前类内部     | 子类与外部实例均无法访问（TS 编译层检查）    |
| **`readonly`**  | 只读         | 仅能在声明时或 `constructor` 中赋值 |

```ts
class Account {
  public id: string;
  protected balance: number;
  private secretKey: string;
  readonly createdAt: Date;

  constructor(id: string, balance: number, secretKey: string) {
    this.id = id;
    this.balance = balance;
    this.secretKey = secretKey;
    this.createdAt = new Date();
  }

  getSecret(): string {
    return this.secretKey; // 合法：类内部可访问 private 属性
  }
}
```

# 继承
```ts
class Animal {
  constructor(public name: string) {}

  makeSound(): void {
    console.log("Some generic sound");
  }
}

class Dog extends Animal {
  constructor(name: string, public breed: string) {
    super(name); // 调用父类 constructor
  }

  // 显式声明方法重写，避免拼写错误导致覆盖失败
  override makeSound(): void {
    console.log("Woof! Woof!");
  }
}
```


### 静态成员与 Getter / Setter

- **`static`**：属于类本身而非实例，通过类名直接调用。
- **`get` / `set`**：拦截对属性的读取与修改，支持数据校验。

```ts
class Circle {
  static readonly PI: number = 3.14159;

  private _radius: number; // 通常讲这个给私有

  constructor(radius: number) {
    this._radius = Math.max(0, radius);
  }

  // Getter
  get radius(): number {
    return this._radius; // 用getter 或者setter暴露
  }

  // Setter
  set radius(value: number) {
    if (value < 0) throw new Error("半径不能为负数");
    this._radius = value;
  }

  get area(): number {
    return Circle.PI * this._radius ** 2;
  }
}

const c = new Circle(5);
console.log(c.area); // 78.53975
c.radius = 10;       // 触发 setter
```

# 类与接口

```ts
interface Loggable {
  log(message: string): void;
}

class ConsoleLogger implements Loggable {
  log(message: string): void {
    console.log(`[LOG]: ${message}`);
  }
}

// 类既可以作为值实例化，也可以直接当作类型来使用
function processLog(logger: ConsoleLogger) {
  logger.log("System operational");
}
```
