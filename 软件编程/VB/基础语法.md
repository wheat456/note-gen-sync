## 基本类型

- **Byte**：1 字节。范围 0 到 255。无符号。
- **Integer**：2 字节。范围 -32,768 到 32,767。整数。
- **Long**：4 字节。范围约正负 21 亿。长整数。
- **Single**：4 字节。单精度浮点数。处理小数。
- **Double**：8 字节。双精度浮点数。高精度小数。
- **Currency**：8 字节。定点货币型。适合财务计算，避免四舍五入误差。
- **String（变长）**：长度随内容变化。最多可容纳约 20 亿个字符。
- **String（定长）**：声明时指定长度。形如 `Dim Str As String * 10`。
- **Boolean**：2 字节。仅存储 `True` 或 `False`。
- **Date**：8 字节。存储日期和时间。范围从公元 100 年到 9999 年。
- variant 任意类型
```vb
Dim 变量名 as Integer = 100
变量名=200
```

## select case 
```vb
Dim today As Integer
today = 3

Select Case today
    Case 1
        MsgBox "星期一：开始工作"
    Case 2, 3, 4, 5  ' 可以用逗号分隔多个值（满足任意一个即可）
        MsgBox "工作日：继续努力"
    Case 6, 7
        MsgBox "周末：好好休息"
    Case Else        ' 相当于 If 中的 Else，处理所有其他不满足的情况
        MsgBox "错误的日期数字"
End Select


// case 1 to 100 可以表示范围
// case is >= 100 表示大于xxx

```

# 循环
## for
- step 表示步长为2
- `For i = 5 To 1 Step -1`  可以为复数
- 退出`for` exit for
```vb

For i As Integer = 1 To 10 step 2 
    Console.WriteLine(i)
    Exit For
Next

```

## each
```vb 
Dim textArray(2) As String
Dim item As Variant ' 必须是 Variant 才能用于数组的 For Each

textArray(0) = "苹果"
textArray(1) = "香蕉"
textArray(2) = "橙子"

' 自动循环 3 次，item 会依次变成 苹果、香蕉、橙子
For Each item In textArray
    Print item
Next item
```

# Sub

- **按值传递** ：此方式下，参数是原值的一个副本，原始数据在传递过程中不会被改变，适用于不需要修改参数值的情况。
- **按引用传递** ：此方式下，传递的是参数的内存地址，这样在 `Sub` 过程中对参数的任何修改都会影响到原始数据。
```vb
Sub ModifyValue(ByVal myValue As Integer, ByRef myRefValue As String)    //byval值传递 byref 引用传递
myValue = myValue + 10    
myRefValue = myRefValue.ToUpper()
End Sub

ModifyValue(value, refValue)

```
