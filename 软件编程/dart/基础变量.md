# 变量定义：`var`、`final` 与 `const`

| **关键字** | **Dart 含义** | **对应 C# 概念**            | **核心规则**                   |
| ------- | ----------- | ----------------------- | -------------------------- |
| `var`   | 类型推断变量      | `var`                   | 声明时确定类型，赋值后**不能**再赋其他类型的值。 |
| `final` | 运行时常量       | `readonly` / 仅 `get` 属性 | 只能赋值一次，可以在运行时计算出初值。        |
| `const` | 编译期常量       | `const`                 | 必须在编译期就能确定值；具有**深层不可变性**。  |
#### 3. 数值与基本类型

Dart 的基础类型更精简，去掉了 C# 中细碎的整型/浮点型划分：
- **`int`**：64 位有符号整数（对应 C# `long`）。
- **`double`**：64 位双精度浮点数（对应 C# `double`，Dart 没有独立的 `float` 和 `decimal`）。
- **`num`**：`int` 和 `double` 的父类（很少直接使用，除非需要同时兼容整型和浮点）。
- **`bool`**：布尔类型（`true` / `false`），**不能**用 0 或 1 隐式转换。

#### 4. 健全空安全 (Sound Null Safety)

Dart 拥有与 C# 类似但更严格的编译期空安全机制：**默认所有类型都不可为 null**。

```dart
// 1. 默认不可空
int a = 10;
// a = null; // 编译报错

// 2. 可空类型加 ?
int? b = null; // 正确

// 3. 空值合并操作符 ?? 与 ??= (与 C# 完全一致)
int c = b ?? 0; // 若 b 为 null 则取 0
b ??= 5;        // 若 b 为 null 则赋值为 5

// 4. 空断言操作符 ! (与 C# 的 null-forgiving ! 一致)
int d = b!; // 强制告诉编译器 b 一定非空（若为 null 会抛运行时异常）

// 5. 安全调用 ?.
String? text = null;
print(text?.length); // 输出 null，不会崩溃


```
**Dart 特有的 `late` 关键字：** 如果一个变量**不可为空**，但你无法在声明或构造函数初始时立即赋值，使用 `late` 修饰。

| **参数类型**   | **Dart 语法定义**                                     | **调用形式**                | **对应 C# 特性**                         |
| ---------- | ------------------------------------------------- | ----------------------- | ------------------------------------ |
| **必填位置参数** | `void fn(int a, String b)`                        | `fn(1, 'ok')`           | 普通形参 `void Fn(int a, string b)`      |
| **命名参数**   | `void fn({int? a, required String b, int c = 0})` | `fn(b: 'ok', a: 1)`     | 命名实参 + 可选参数（但 Dart 在定义处约束）           |
| **可选位置参数** | `void fn(int a, [String? b, int c = 0])`          | `fn(1)` 或 `fn(1, 'ok')` | C# 默认值参数 `void Fn(int a, string b =` |
**注意：** 命名参数 `{}` 和可选位置参数 `[]` **不能同时存在于同一个函数中**。

### 5. 一等公民函数与委托替代方案

Dart 中函数是一等公民，类型表示为 `ReturnType Function(ParamType)`，直接取代了 C# 中的 `Action<T>` 和 `Func<T, TResult>`。

**函数作为参数与匿名函数：**

Dart

```
// 对应 C# 的 void Process(Func<int, int> transformer)
void processList(List<int> numbers, int Function(int) transformer) {
  for (var n in numbers) {
    print(transformer(n));
  }
}

void main() {
  var list = [1, 2, 3];

  // 1. 传入具名顶层函数
  int square(int x) => x * x;
  processList(list, square);

  // 2. 传入匿名函数（Lambda）
  processList(list, (x) => x * 10);
  processList(list, (x) {
    var doubled = x * 2;
    return doubled + 1;
  });
}
```
