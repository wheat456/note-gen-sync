

# 运算符



| 运算符   | 作用                                         | 用法                                    |
| ----- | ------------------------------------------ | ------------------------------------- |
| `??`  | 如果左侧的表达式结果为 `null`，则返回右侧表达式的值；否则返回左侧表达式的值。 | `String name = lei ?? '默认'            |
| `??=` | 当message为null时就赋值，否则就不进行任何操作               | `message ??= '默认消息';`                 |
| `?.`  | 如果text为null,就给前面也赋值null，这是针对值的             | `inal length = text?.length;`         |
| ` ！`  | 确认变量不为null否则运行报错                           | `final result = text!.toUpperCase();` |
| `?..` | 如果list为null就返回null,否则就运行函数                 | `list?..add(1)..remove(0);`           |
|       |                                            |                                       |

# 级联
使用`..`就不用重复写对象
```dart
var p = Person()
  ..name = "张三"
  ..age = 20
  ..sayHi();
}
```

- 不管 `a()` 返回什么，直接丢了；表达式结果永远是最开始的 `obj`。
```dart
obj..a()..b()..c()
```
## ?..
如果为空就跳过
```dart
list?..add(1)..remove(0);
```
### ...？
不为空就插入，否则就不插入
```dart 
`List<int>? numbers;` `final all = [1, 2, ...? numbers];`
```

# 复合数据
| **特征**   | **List (列表)**                        | **Set (集合)**                            |
| -------- | ------------------------------------ | --------------------------------------- |
| **定义符号** | 方括号 `[]`                             | 花括号 `{}` 或 `Set()`                      |
| **顺序**   | **有顺序 (Ordered)**。元素按插入顺序排列。         | **无顺序 (Unordered)**。元素没有固定的索引位置。        |
| **重复性**  | **允许重复元素**。                          | **不允许重复元素**。所有元素必须是唯一的。                 |
| **访问方式** | 通过 **索引 (Index)** 访问：`list[0]`       | 通过 **值** 检查是否存在：`set.contains('value')` |
| **常见用途** | 存储需要保持顺序或允许重复的数据，例如用户评论列表、购物车中的商品列表。 | 存储需要确保唯一性的数据，例如用户 ID 列表、标签列表。           |
