# 工厂模式
- **简单工厂：** 负责生产“某一种”产品（通过参数决定哪种）。
	- 就是一个工厂类可以通过条件返回不同的对象
- **工厂方法：** 每一类产品由一个专门的子工厂生产。
    - 继承一个xx工厂基类，继承玩具工厂的基类能创建玩具厂，继承手机工厂的基类能创建手机厂等，里面有对应的类的创建函数
- **抽象工厂：** 负责生产“一整套”相关的产品系列。
	- 继承一个工厂基类/接口，里面有各种东西的生成方法，但是都是指的的产品的共同基类/接口。比如手机接口，电脑接口，不同的工厂创建的具体手机和电脑是不同的，但是都是继承的是手机接口和电脑接口

# 结构形模式

## 装饰器模式
- 在每一个函数中可以去调用基类中同样的函数

1. 有两个角色，一个是`被装饰对象`，另一个是`装饰器`
2. `被装饰对象`继承一个`基类/接口`
```cs
interface IBasic{
 void func1(){
 }
 void func2(){
 }
....
}



class BasicClass:IBasic{
	//实现接口中的方法
}
```
3. `装饰器基类`也同样实现其`接口`，但是内部还要添加一个`字段`，类型为继承的`接口/基类`
```cs
abstract class BasicDecorator(IBasic BeDecoratedClass) :IBasic{
	//实现接口,并表明虚方法
	...
	
	// 声明一个接口类型的字段
	IBasic BeDecoratedClass;

}

```
4. 实际装饰器继承装饰器基类，并重写装饰器基类中的虚方法
```cs
Class ConcreteDecorator(IBasic xxx):BasicDecorator(xxx){
	// 从写方法
	
	//
	IBasic BeDecoratedClass=xxx;
}

```
5. 最终，可以实例化一个`装饰器`，并填入需要`被装饰的类`，同样也可以填入`装饰器`
```cs


IBaisc Aa= new ConcreteDecorator(new BasicClass){}

```
