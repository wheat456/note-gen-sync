## 装饰器模式
- 在每一个函数中可以去调用基类中同样的函数

1. 有两个角色，一个是`被装饰对象`，另一个是`装饰器`
2. `被装饰对象`继承一个`基类/接口`
```cs
interface IBasic{
 void func1(){
 }
 void func2(){
 }
....
}



class BasicClass:IBasic{
	//实现接口中的方法
}
```
3. `装饰器基类`也同样实现其`接口`，但是内部还要添加一个`字段`，类型为继承的`接口/基类`
```cs
abstract class BasicDecorator(IBasic BeDecoratedClass) :IBasic{
	//实现接口,并表明虚方法
	...
	
	// 声明一个接口类型的字段
	IBasic BeDecoratedClass;

}

```
4. 实际装饰器继承装饰器基类，并重写装饰器基类中的虚方法
```cs
Class ConcreteDecorator(IBasic xxx):BasicDecorator(xxx){
	// 从写方法
	
	//
	IBasic BeDecoratedClass=xxx;
}

```
5. 最终，可以实例化一个`装饰器`，并填入需要`被装饰的类`，同样也可以填入`装饰器`
```cs


IBaisc Aa= new ConcreteDecorator(new BasicClass){}

```


## 代理模式


- 目的：给目标对象添加一层代理，用于限制对其的访问
- 不同代理的区别是，各种代理的职责不同

1. 创建一个`接口/类`，`代理`和`真实对象`都继承这个
2. 其中`代理`持有一个`真实对象`的字段
3. 可以在代理的操作方法中添加一些行为，从而实现各种功能，在访问真实对象之前

```cs
interface Subject{
	void Operation(){
	
	}
}
class proxy:Subject{
	RealSubject _realsubject;
	void Operation(){
	}
}

class RealSubject:Subject{
	void Operation(){
	
	}
}

```

# 状态模式
- 首先一个对象拥有改变状态的方法，拥有一些对外暴露的行为，持有状态字段，但是对外暴露的行为实际上是取决于状态的，也就是具体是由状态去实现到底要干什么
- 状态可以通过持有对象来改变状态，状态中的方法是实际上在该状态下会执行的特定的逻辑


1. 创建一个类，拥有一个为`状态`的字段，同时这个类也应该有一些行为方法
```cs
// 假如创建一个“Person”的类
Class Person{
	// 拥有一个状态的字段
	State state;
	
	// 各种行为方法,里面通过状态去调用
	void eat(){
		state.HandleEate(this);
	}
	
	void sleep(){
		state.HandleSleep(this);
	}
	
	// 切换状态的方法
	void SetState(State state){
		_state=state
	}
	
}
```

2. 创建`状态`的基类，同时拥有在该状态下处理各种行为的方法
```cs
interface IBaseState{
//持有人的本身，方便拿到一些上下文信息
	void HandleEat(Person person){
		
	}
	void HandleSleep(Person person){
	
	}
	
}

```
3. 创建真正的状态，继承至状态基类
```cs
// 假如有两个状态，分别是正常状态和生病状态

class NormState:IBaseState{
	// 实现接口中的方法，定义自己的逻辑
	void HandleEat(Person person){
		//吃的多，然后生病了
		person.SetSate(new SickState())
		
	}
	void HandleSleep(Person person){
		//着凉了，然后生病了
		person.SetSate(new SickState())
	}
	

}

class SickState:IBaseState{
	// 实现接口中的方法，定义自己的逻辑
	void HandleEat(Person person){
		//吃的多，大补，然后好了
		person.SetSate(new NormState())
		
	}
	void HandleSleep(Person person){
		//睡一觉，然后好了
		person.SetSate(new NormState())
	}

}

```
