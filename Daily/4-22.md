# 工厂模式
- **简单工厂：** 负责生产“某一种”产品（通过参数决定哪种）。
	- 就是一个工厂类可以通过条件返回不同的对象
- **工厂方法：** 每一类产品由一个专门的子工厂生产。
    - 继承一个xx工厂基类，可以创建比如玩具厂，手机厂等，里面有对应的类的创建函数
- **抽象工厂：** 负责生产“一整套”相关的产品系列。
	- 继承一个工厂基类/接口，里面有各种东西的生成方法，
## 工厂基类

# 观察者模式

## 可观察对象
### 通用接口
- 拥有添加`观察者`的函数
```cs 
void Attach(IObservable){
}
```
- 拥有去除`观察者`的函数
```cs
void Dettach(IObservable){
}
```
- 拥有`通知`的函数
```cs 
void Notify(){

}
```
### 具体可观察者
- 实现上述的接口
- 拥有一个观察者对象的`List`
```cs
List<Observaber>
```
- 在`通知函数`中调用每个`观察者`的`更新函数`
```cs
void Notify(){
	xxxObservaber.Update();
}
```
- 拥有一个`获取数据方法`，给`观察者`用
## 观察者
### 通用接口
- 拥有`更新`的函数
```cs
void Update(){

}
```
### 具体观察者
- 拥有可观察者的引用
```cs
xxx(IObservable xx){
}
```
- 在`更新函数`中去调用`可观察者`的`获取数据方法`
```cs
void Update(){
	IObservable.GetData();
}
```
