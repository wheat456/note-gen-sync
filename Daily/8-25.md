```html
<video width="640" height="360" controls poster="cover.jpg" preload="metadata">
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.webm" type="video/webm">
  <p>您的浏览器不支持 HTML5 视频播放。</p>
  <track src="subtitles_zh.vtt" kind="subtitles" srclang="zh" label="中文"> 字幕
</video>
```

| **属性**                 | **类型 / 可选值**                   | **说明**                                       |
| ---------------------- | ------------------------------ | -------------------------------------------- |
| **`controls`**         | 布尔属性                           | 显示原生播放控制条（播放/暂停、音量、进度、全屏）。                   |
| **`autoplay`**         | 布尔属性                           | 页面加载后自动播放（现代浏览器要求通常需搭配 `muted`）。             |
| **`muted`**            | 布尔属性                           | 默认静音播放。                                      |
| **`loop`**             | 布尔属性                           | 播放结束后自动循环播放。                                 |
| **`poster`**           | URL 字符串                        | 视频加载完成前或播放前显示的封面图片。                          |
| **`preload`**          | `auto` \| `metadata` \| `none` | 视频预加载策略：`metadata` 仅加载元数据（时长/尺寸），`none` 不预载。 |
| **`playsinline`**      | 布尔属性                           | 移动端（尤其是 iOS Safari）在页面内播放，避免强制全屏。            |
| **`width` / `height`** | 像素数值                           | 设置播放器的显示宽度与高度。                               |
