# 日志
## WPF中
- 安装serilog
```cs
Log.Logger = new LoggerConfiguration() .MinimumLevel.Debug() .WriteTo.File("logs/app_log.txt", rollingInterval: RollingInterval.Day) .CreateLogger();
```

```cs
Ioc.Default.ConfigureServices(new ServiceCollection() // 注册日志 .AddLogging(builder => builder.AddSerilog()) // 注册 ViewModels .AddTransient<MainViewModel>() // 注册 Services .AddSingleton<IDataService, DataService>() .BuildServiceProvider());
```



```cs
private readonly ILogger<MainViewModel> _logger; 
private readonly IDataService _dataService; // 构造函数通过 DI 自动获取 Logger public MainViewModel(ILogger<MainViewModel> logger, IDataService dataService) { _logger = logger; _dataService = dataService; _logger.LogInformation("MainViewModel 初始化完成"); }
```


## MVVM 默认的依赖注入
还是要配置`Microsoft.Extensions.DependencyInjection`
```cs
Ioc.Default.ConfigureServices( new ServiceCollection() .AddSingleton<IDatabaseService, MyDatabaseService>() .AddTransient<MainViewModel>() .BuildServiceProvider());
```
