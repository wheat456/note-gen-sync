### useWebWorker
```js
const { data, post, isRunning, terminate } = useWebWorker( new URL('../workers/sort.ts', import.meta.url).href,{type:'module'} );

post([5, 1, 9, 3, 7, 2]);
//data 就是回传结果
```

在sort.ts中
```ts
// 1. 監聽主線程透過 post() 送過來的訊息
self.onmessage = (event: MessageEvent<number[]>) => {
  const numbers = event.data;

  // 2. 執行耗時計算或排序邏輯
  const sorted = [...numbers].sort((a, b) => a - b);

  // 3. 將結果傳回主線程，會直接更新 Vue 元件中的 `data`
  self.postMessage(sorted);
};

// 4. (可選) 捕捉 Worker 內部異常
self.onerror = (error) => {
  console.error('Worker 內部運算錯誤:', error);
};
```


|**屬性 / 方法**|**適用 Hook**|**說明**|
|---|---|---|
|`workerFn(...args)`|`useWebWorkerFn`|非同步呼叫函式，回傳 Promise|
|`post(data)`|`useWebWorker`|向 Worker 線程發送訊息|
|`data`|`useWebWorker`|響應式 `Ref`，即時儲存 Worker 回傳的最新資料|
|`workerStatus` / `isRunning`|兩者皆有|追蹤當前執行緒狀態（`PENDING`、`RUNNING`、`SUCCESS`、`ERROR` 等）|
|`workerTerminate()` / `terminate()`|兩者皆有|手動立即銷毀 Worker 執行緒|

> [!NOTE] 注意
> Worker 線程中無法操作 `document`、`window` 或 LocalStorage。

# 字面量类型与联合类型
**字面量类型**：`type Fruit = 'apple';`（这个变量的值只能是字符串 `'apple'`，写 `'banana'` 就会报错）。
**联合类型（`|`）**：相当于逻辑“或”。
```ts
// Status 只能是这 3 个具体字符串之一
type Status = 'loading' | 'success' | 'error';
```
