# 打包vue 项目
1. **安装插件**
```bash
npm install vite-plugin-singlefile -D
```
2. **修改 `vite.config.js`**

``` js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { viteSingleFile } from 'vite-plugin-singlefile'

export default defineConfig({
  plugins: [vue(), viteSingleFile()],
})
```

3. **打包构建**

```bash
npm run build
```


### 常见的 CSS 伪元素
- **`::before`** 在选定元素的内容**最前面**插入生成的内容。必须配合 `content` 属性使用。
```css
h2::before { content: "★ "; color: red; }
```
- **`::after`** 在选定元素的内容**最后面**插入生成的内容。必须配合 `content` 属性使用
```css
blockquote::after { content: " ”"; font-size: 1.5em; color: #888; }
```
- **`::first-letter`** 选择文本块的**第一个字母/字符**（常用于首字下沉排版）
- **`::first-line`** 选择文本块的**第一行**（第一行长度会随窗口大小改变而自动适应）。
- **`::selection`** 匹配用户在页面上**高亮/选中**的文本部分（可以修改选中时的背景色和文字颜色）
```css
::selection { background-color: #ffb703; color: #000; }
```
- **`::placeholder`** 匹配表单输入框（`<input>` 或 `<textarea>`）中的**占位符提示文字**。

# 表格css

```css
table {
  width: 100%;
  border-collapse: collapse; /* 合并边框 */
}

th, td {
  border: 1px solid #ddd;   /* 设置简洁的边框 */
  padding: 8px 12px;        /* 增加内边距 */
  text-align: left;         /* 文字对齐 */
}
```
