# ava
绑定命名控件
```xml
<TextBox Name="other">

<!-- 绑定到命名为“other”控件的Text属性 -->
<TextBlock Text="{Binding #other.Text}"/>
```

绑定到祖先
```xml
<Border Tag="Hello World!">
  <Border>
    <TextBlock Text="{Binding $parent[1].Tag}"/>
  </Border>
</Border>
```
索引器从0开始，因此`$parent[0]`等同于`$parent`。

按照类型
```xml
<Border Tag="Hello World!">
  <Decorator>
    <TextBlock Text="{Binding $parent[Border].Tag}"/>
  </Decorator>
</Border>
```


组合形式
```xml
<Border Tag="Hello World!">
  <Border>
    <Decorator>
    <TextBlock Text="{Binding $parent[Border;1].Tag}"/>
    </Decorator>
  </Border>
</Border>
```

如果需要在祖先类型中包含XAML命名空间，一般使用`:`字符：

```
<local:MyControl Tag="Hello World!">
  <Decorator>
    <TextBlock Text="{Binding $parent[local:MyControl].Tag}"/>
  </Decorator>
</local:MyControl>
```


# 转换绑定值
可以使用`！`取反
双感叹号可用于将非布尔值转换为布尔值。
```xml
<StackPanel>
  <TextBox Name="input" IsEnabled="{Binding AllowInput}"/>
  <TextBlock IsVisible="{Binding !AllowInput}">Sorry, no can do!</TextBlock>
</StackPanel>

```

# WPF 窗口 InputBinding

`InputBinding` 是 WPF 中**将「键盘 / 鼠标操作」和「命令 / 方法」绑定**的核心机制

```cs
    <!-- 窗口 InputBinding：全局快捷键 -->
    <Window.InputBindings>
        <!-- 1. Ctrl + S 绑定保存命令 -->
        <KeyBinding Key="S" Modifiers="Control" Command="{Binding SaveCommand}" />
        
        <!-- 2. Delete 键绑定删除命令 -->
        <KeyBinding Key="Delete" Command="{Binding DeleteCommand}" />
        
        <!-- 3. Ctrl + Z 撤销 -->
        <KeyBinding Key="Z" Modifiers="Control" Command="{Binding UndoCommand}" />
        
        <!-- 4. 鼠标左键双击 绑定命令 -->
        <MouseBinding MouseAction="LeftDoubleClick" Command="{Binding DoubleClickCommand}" />
    </Window.InputBindings>
```


### 1. 两个子类（实际只用这两个）

- **`KeyBinding`**：绑定**键盘按键**（最常用）
- **`MouseBinding`**：绑定**鼠标操作**
