# flexrender
```js
<FlexRender :render="cell.column.columnDef.cell" :props="cell.getContext()" />
```

- `:render`：渲染目标，通常来自 `columnDef.header` 或 `columnDef.cell`。
- `:props`：上下文对象，通过 `header.getContext()` 或 `cell.getContext()` 获取，提供当前行数据、值（`getValue()`）和表格实例。

`FlexRender` 会根据你在 `columnDef` 中配置的类型自动选择渲染策略：
#### 1. 纯文本 / 默认渲染

直接返回字符串或数值，`FlexRender` 会将其渲染为普通文本节点。


```js
columnHelper.accessor('name', {
  header: 'Full Name',
  // 不显式写 cell 时，FlexRender 默认输出原始值
})
```

#### 2. Vue 渲染函数（`h()`）
用于需要局部定制标签结构、添加简单样式或绑定事件的场景。
```js
import { h } from 'vue'

columnHelper.accessor('email', {
  header: () => h('span', { class: 'text-gray-500 font-bold' }, 'Email Address'),
  cell: info => h('a', {
    href: `mailto:${info.getValue()}`,
    class: 'text-blue-600 underline'
  }, info.getValue())
})
```
#### 3. 挂载自定义 Vue 组件 (SFC)
当单元格包含复杂交互（如下拉菜单、状态徽章、操作按钮组）时，可以在渲染函数中渲染单独的 Vue 组件并传递 props。

```js
import { h } from 'vue'
import StatusBadge from './StatusBadge.vue'

columnHelper.accessor('status', {
  header: 'Account Status',
  cell: info => h(StatusBadge, {
    status: info.getValue(),
    rowId: info.row.original.id,
    onUpdate: (newVal) => console.log('Updated:', newVal)
  })
})
```
#### 4. display
在 `display` 列中，由于没有绑定具体 key，`cell` 上下文中通常不使用 `info.getValue()`，而是直接通过 `info.row.original` 读取整行数据或使用 `info.row.index`。

| 字段   | 作用                                                  |
| ---- | --------------------------------------------------- |
| `id` |  `display` 没有绑定任何数据字段，TanStack 无法推断，因此强制要求手动提供 `id` |

| 方法                        | 核心定位    | 是否绑定数据                  | info.getValue() | 核心上下文取值                               |
| ------------------------- | ------- | ----------------------- | --------------- | ------------------------------------- |
| `columnHelper.accessor()` | 数据列     | 是（必须提供 key 或 getter）    | 支持              | `info.getValue() / info.row.original` |
| `columnHelper.display()`  | 纯 UI 列  | 否（必须显式指定 id）            | 不支持             | `info.row.original / info.row.index`  |
| `columnHelper.group()`    | 分组/多级表头 | 否（包含 columns: [...] 子列） | 不适用             | 用于合并与表头层级划分                           |


## header 填入方式
- **静态字符串 / 数字：** 最常见的基础写法。

```ts
header: '用户姓名'
```

- **动态计算函数（返回字符串）：** 常用于国际化多语言（i18n）或读取表格状态。

```ts
header: () => t('table.columns.userName')
```

- **渲染函数（返回 VNode）：** 使用 Vue 的 `h()` 自定义标签、类名与子元素。


```ts
header: (info) => h('div', { class: 'flex items-center gap-2' }, [
  h('span', '创建时间'),
  h(SortIcon, { isSorted: info.column.getIsSorted() })
])
```
- `info` 解构其中包含：
```ts
// cell 中常用解构：getValue, row, table, column
cell: ({ getValue, row }) => `${row.original.name}: ${getValue()}`

// header 中常用解构：column, table, header
header: ({ column }) => `Column ID: ${column.id}`
```
- **`cell` 的上下文对象 (`CellContext`)：**
    - `getValue()`：获取当前单元格的原始数据值。
    - `renderValue()`：获取经过过滤/格式化后的单元格渲染值。
    - `row`：行模型（包含 `row.original` 原始行数据、`row.index` 索引、`row.getIsSelected()` 等）。
    - `column`：当前列的实例与配置。
    - `table`：整个表格的全局实例。
    - `cell`：当前单元格的实例对象。
- **`header` 的上下文对象 (`HeaderContext`)：**
    - `column`：当前列实例（用于读取排序、筛选状态等）。
    - `header`：表头实例（包含层级、宽度、深度等信息）。
    - `table`：整个表格的全局实例。

- **直接传入 Vue 单文件组件 (SFC)：** 将封装好的表头组件直接作为值传入。组件内部通过 `defineProps` 即可拿到 `HeaderContext`。
```ts
import SortableHeader from './SortableHeader.vue'

header: SortableHeader
```


# useVueTable
```ts
const table = useVueTable({
  // 1. 数据源 (Vue 响应式必须通过 Getter 传入)
  get data() {
    return data.value
  },

  // 2. 列定义
  columns,

  // 3. 行模型管道 (按需引入的功能模型)
  getCoreRowModel: getCoreRowModel(), // 必需：核心模型
  getSortedRowModel: getSortedRowModel(), // 可选：排序模型
  getFilteredRowModel: getFilteredRowModel(), // 可选：过滤模型
  getPaginationRowModel: getPaginationRowModel(), // 可选：分页模型
  getExpandedRowModel: getExpandedRowModel(), // 可选：展开折叠模型

  // 4. 受控状态 (State)
  state: {
    get sorting() {
      return sorting.value
    },
    get pagination() {
      return pagination.value
    },
    get expanded() {
      return expanded.value
    },
  },

  // 5. 状态变更监听 (Updater 回调)
  onSortingChange: (updater) => {
    sorting.value =
      typeof updater === 'function' ? updater(sorting.value) : updater
  },
  onPaginationChange: (updater) => {
    pagination.value =
      typeof updater === 'function' ? updater(pagination.value) : updater
  },

  // 6. 其他行为控制
  manualPagination: false, // 是否开启服务端分页（关闭则由前端自动分页）
  getSubRows: (row) => row.children, // 树形结构提取子行
})
```


# h函数

```ts
h(type, props?, children?)
```

`h()` 最多接收 3 个参数：
- **第 1 个参数 `type`（必填）：** 要渲染的目标。
    - 原生 HTML 标签字符串（如 `'div'`, `'button'`, `'span'`）
    - Vue 单文件组件对象（如 `import MyButton from './MyButton.vue'`）
    - 渲染函数或内置 Symbol（如 `Fragment`, `Teleport`）
- **第 2 个参数 `props`（可选）：** 节点的属性、类名、样式、事件监听器以及传给组件的 Props。
- **第 3 个参数 `children`（可选）：** 子节点，可以是纯文本字符串、数值、VNode 数组，或是包含插槽函数的对象。


# 对象中写getter
```js
const table = useVueTable<Person>({
  // 利用 getter 保持对 ref.value 的响应式访问
  get data(): Person[] {
    return data.value
  },
  get columns() {
    return columns.value
  },
  getCoreRowModel: getCoreRowModel(),
})
```
