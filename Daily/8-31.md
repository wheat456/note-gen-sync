`watch` 的第一个参数是**侦听源**，第二个参数是**回调函数** `(newVal, oldVal) => {}`。
```js
// 1. 侦听单个 ref（注意：直接传 ref 对象，不要写 count.value）
watch(count, (newVal, oldVal) => {
  console.log(`count 改变: ${oldVal} -> ${newVal}`)
})

// 2. 侦听 reactive 对象的某个基本类型属性（必须使用 getter 函数）
watch(
  () => user.age,
  (newAge, oldAge) => {
    console.log(`age 改变: ${oldAge} -> ${newAge}`)
  }
)

// 3. 侦听多个数据源（数组语法）
watch([count, () => user.name], ([newCount, newName], [oldCount, oldName]) => {
  console.log('count 或 name 发生了变化')
})
```

## 配置项
```js
watch(source, callback, {
  // 1. 立即执行：创建侦听器时先立即触发一次回调
  immediate: true,

  // 2. 一次性侦听器（Vue 3.4+）：只在第一次变化时执行，之后自动销毁
  once: true,

  // 3. 深度侦听（Vue 3.5+ 增强）：
  // - 设为 true：深度递归遍历所有属性
  // - 设为具体数字：指定最大遍历层级（例如 deep: 1 只侦听第一层，大幅降低大对象的遍历性能开销）
  deep: 2,

  // 4. 执行时机：'pre' (默认，DOM 更新前) | 'post' (DOM 更新后) | 'sync' (同步触发)
  flush: 'post'
})
```

### 副作用清理与竞争取消
当监听源快速变化触发异步操作（例如快速搜索请求）时，需要取消未完成的请求或清理定时器。
```vue
<script setup>
import { ref, watch, onWatcherCleanup } from 'vue'

const keyword = ref('')

watch(keyword, (newVal) => {
  const controller = new AbortController()
  
  // 注册清理回调：在下一次 watcher 触发前或 watcher 停止时执行
  onWatcherCleanup(() => {
    controller.abort() // 取消上一次未完成的请求
  })

  fetch(`/api/search?q=${newVal}`, { signal: controller.signal })
    .then(res => res.json())
    .then(data => console.log(data))
    .catch(err => {
      if (err.name !== 'AbortError') console.error(err)
    })
})
</script>
```

### 生命周期控制
```vue 
<script setup>
import { ref, watch } from 'vue'

const count = ref(0)

const { stop, pause, resume } = watch(count, (val) => {
  console.log('当前值：', val)
})

// 场景：在进行批量更新或特定动画时暂停触发
pause()
count.value = 10 // 不会触发回调

resume() // 恢复监听（如果期间值改变过，恢复时不会自动补发，只响应后续更新）
count.value = 20 // 触发回调

stop() // 彻底销毁侦听器
</script>
```

|**特性**|**watch**|**watchEffect**|
|---|---|---|
|**依赖收集**|显式声明（精确追踪指定源）|自动收集（执行代码中用到的所有响应式值）|
|**获取旧值**|可以拿到 `(newVal, oldVal)`|拿不到 `oldVal`|
|**默认时机**|惰性执行（值变化时才触发，除非配置 `immediate: true`）|立即自动执行一次以收集依赖|
|**适用场景**|监听特定字段变化发请求、需新旧值对比、表单校验|依赖项较多且只要有变动就重新运行一段统一逻辑|
