
协变和逆变**仅支持引用类型**
左边的类型只能是委托或者是接口 
```cs
IEnumerable<Dog> dogs = new List<Dog>(); // 协变：Dog 是 Animal，所以返回 Dog 的集合可以视为返回 Animal 的集合
IEnumerable<Animal> animals = dogs;


Func<Dog> getDog = () => new Dog(); 
Func<Animal> getAnimal = getDog; // 合法！
```

逆变和协变只能在泛型下使用
