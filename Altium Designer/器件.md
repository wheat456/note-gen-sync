# 二极管
## TVS
- 防止浪涌：突然出现的高压和大电流
- 反相并联到输入

## 快恢复二极管
- **普通的二极管**在电流反向的时候不能立刻关断，在高频下发热严重
- **肖特基二极管**就是关断更快的二极管
- **开关二极管**就是开关速度块
## 稳压管(齐纳二极管) 
- 当反相击穿时，就稳定电压


# 三极管

### 达令顿晶体管
- 就是把多个三极管组合到一起
- 专门放大电流
- 外观还是三极管的样子
## 达林顿阵列
- **多个独立的达林顿管**集成在一个芯片里
