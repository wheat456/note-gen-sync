# 二极管
## TVS
- 直流电路中使用
- 防止浪涌：突然出现的高压和大电流
- 反相并联到输入

## 快恢复二极管
- **普通的二极管**在电流反向的时候不能立刻关断，在高频下发热严重
- **肖特基二极管**就是关断更快的二极管
- **开关二极管**就是开关速度块
## 稳压管(齐纳二极管) 
- 当反相击穿时，就稳定电压


# 三极管

- **多个独立的达林顿管**集成在一个芯片里

# 电容
# 安规电容
### X
- 火线--零线之间
- 消除**差模**干扰
- 容量一般比较大：**0.01μF ~ 1μF**
- 失效时**只会短路 / 烧保险，不会触电**
### Y
- 火线--零线/地之间
- 滤除**共模干扰**
- 容量很小：**几千 pF ~ 几万 pF**
