

# 1.初始化时钟

- **开启 Flash 预取 / Cache**（提升访问效率）
- **设置 Flash Latency**（根据即将超频到的目标频率，先提高等待周期）
- **开启 PLL（锁相环）并倍频**（把时钟拉高到目标主频，如 72MHz）
- **切换系统时钟**（正式让 CPU 跑在最高频率上）
# 2.中断控制

- **中断优先级分组（Priority Grouping）**：决定抢占优先级（Preemption Priority）和响应优先级（Subpriority）的位数分配。
- **开启指定中断并设置优先级**：例如将串口接收中断设置为高优先级，定时器中断设置为低优先级。
