# 文章
`i`标签斜体
`b`加粗
`strong` 同样是加粗，但是这个同样是给计算机看的
`br` 换行
`del` 划线
`ins` 配合del使用，表示是新插入的文本
`em`强调
`kbd` 描述键盘上的符号
`mark` 高亮
`wbr`一个单词或长字符串，但如果空间不够，你可以在这里换行
`var` 表示数学或者代码中变量
`u` 下划线
`s` 删除线
`section` 用于分节，没有视觉效果
`hr`水平分割线
`small`将字变小
```html
<p>
  <small
    >The content is licensed under a Creative Commons Attribution-ShareAlike 2.5
    Generic License.</small
  >
</p>
```
`span` 在行内包裹一段文本
`sub` 文字下标
`sup` 上标
**`<details>`**：**容器**。它负责控制内容的显示与隐藏状态。
 - **`<summary>`**：**按钮/标题**。它是用户点击的区域。如果不写它，浏览器会默认显示“详细信息”（或 "Details"）作为标题。
```html
<details>
  <summary>
    I have keys but no doors. I have space but no room. You can enter but can't
    leave. What am I?
  </summary>
  A keyboard.
</details>
```

# 组件
table
- `<caption>` 主要用于为表格添加**标题**或**简要说明**,比如表格下方的注解
- `thread` 第一行，常用于列名
- `tbody` 用于内容区
- `tfoot`用于最后一行
- `tr`表格行
	- th就是该行的第一个
	- td就是内容格
```html
<table>
  <caption>
    Council budget (in £) 2018
  </caption>
  <thead>
    <tr>
      <th scope="col">Items</th>
      <th scope="col">Expenditure</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Donuts</th>
      <td>3,000</td>
    </tr>
    <tr>
      <th scope="row">Stationery</th>
      <td>18,000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Totals</th>
      <td>21,000</td>
    </tr>
  </tfoot>
</table>
```
