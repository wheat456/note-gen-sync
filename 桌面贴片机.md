
# 坐标文件导出

- **X** $\rightarrow$ `Center-X(mm)`
- **Y** $\rightarrow$ `Center-Y(mm)`
- **Value / Name** $\rightarrow$ `Comment`
- **Part ID / Designator** $\rightarrow$ `Designator`
- **Package / Footprint** $\rightarrow$ `Footprint`
- **Side** $\rightarrow$ `Layer`
- **Rotation** $\rightarrow$ `Rotation`
