# 步骤
**输入 → 调制 → 开关放大 → 滤波输出**

# 工作模式
1. **STEREO** / **立体声模式**（默认、最常用）
	- 每声道独立推一个音箱
	- 左声道推左箱，右声道推右箱
	- 常见负载 $4\ohm$ ,$8\ohm$
2. **BRIDGE** / **桥接模式**
	- 相当于输出的电压叠加了 
	- 把**两个声道合并成一个超大功率单声道**
	- 输出功率≈原来单声道的 **4 倍左右**
	- 常见阻抗为$8\ohm$
3. **PARALLEL** / **并联模式**
	-  两个声道**输入同一路信号**
	- 输出还是两个声道，但**电流更大**
	- 两个通道的**功率叠加**
# XLR 卡侬
- **1 脚：GND 地线（屏蔽）**
- **2 脚：热端（+ 正相信号）**
- **3 脚：冷端（- 反相信号）**


# 输入信号
| 参数       | 通用标准数值               |
| -------- | -------------------- |
| 标准工作电平   | +4 dBu（1.228Vrms）    |
| 最大安全输入   | +20~+22 dBu（≈10Vrms） |
| 平衡输入阻抗   | 20kΩ                 |
| 针脚定义     | Pin2+、Pin3-、Pin1 地   |
| CMRR 抗干扰 | ≥50dB（全频）            |

|电压值|对应 dBu|功放档位定位|
|---|---|---|
|0.775V|0 dBu|高灵敏档，标准舞台常用|
|1.228V|+4 dBu|调音台 0VU 标准输出|
|1.55V|+6 dBu|0.775V 两倍，低灵敏档 (标 1.4V)|
