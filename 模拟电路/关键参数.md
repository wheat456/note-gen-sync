# 三极管
| 参数名称     | 符号                    | 作用/意义                                             |
| -------- | --------------------- | ------------------------------------------------- |
| 集电极最大电压  | $V_{CEO}​$、$V_{CBO}$​ | 决定三极管在关断时能承受的最高电压，选型时要保证高于实际工作电压（留一定裕量，一般1.5-2倍）。 |
| 集电极最大电流  | $I_C$                 | 决定负载电流能力，实际工作电流要低于此值。                             |
| 功耗       | $P_{tot}$             | 决定器件散热极限，功耗 = $V_{CE}×I_C​$，要低于额定值。               |
| 直流电流放大倍数 | $hFE$ 或 $β$           | 决定放大能力，比如在放大电路中要保证足够的 β 才能驱动负载。注意 β 会随温度、电流变化。    |
| 截止频率     | $f_T$                 | 高频性能指标，频率高的电路要选$f_T$ 高的三极管，否则增益会下降。               |
| 饱和压降     | $V_{CE(sat)}​$        | 开关应用中，压降越小效率越高，发热越少。                              |
| 封装       | -                     | 影响散热能力和焊接方式。                                      |

# MOS
## 电压
| 参数         | 符号            | 说明                                                     |
| ---------- | ------------- | ------------------------------------------------------ |
| **漏源最大电压** | $V_{DS(max)}$ | MOSFET 能承受的最大漏-源电压。必须大于电路中可能出现的最大电压，一般留 **1.5~2 倍裕量**。 |
| **栅源最大电压** | $V_{GS(max)}$ | 栅极能承受的最大电压。逻辑驱动（如 5V、3.3V）必须低于这个值。                     |

## 电流与功耗
| 参数         | 符号        | 说明                                  |
| ---------- | --------- | ----------------------------------- |
| **连续漏极电流** | $I_D$     | 器件能持续承受的最大电流，取决于封装和散热。实际工作电流要低于这个值。 |
| **脉冲漏极电流** | $I_{DM​}$ | 短时间脉冲电流能力，比如开关浪涌。不能长时间使用。           |
| **功耗**     | $P_D$     | 取决于 $I_D^2$×$R_{DS}$(on)​ 和散热条件。    |
## 导通性能
| 参数       | 符号            | 说明                                                      |
| -------- | ------------- | ------------------------------------------------------- |
| **导通电阻** | $R_{DS}(on)​$ | MOS 导通时的漏-源电阻，越小导通损耗越低。注意 $R_{DS(on)}$ 会随温度升高而增大。       |
| **阈值电压** | $V_{GS}(th)​$ | MOS 开始导通的栅源电压，不是完全导通的电压。比如 $V_{GS(th)}$=2V 并不意味着 2V 就能大 |

# 运放

### 直流与精度指标
- **输入失调电压（Input Offset Voltage, $V_{os}$）：** 当输入端电压相同时，输出端非零的误差电压折算到输入端的数值。$V_{os}$ 越小，放大器的直流精度越高（精密运放通常 $< 100\ \mu\text{V}$，发烧/斩波稳零运放可达 $\mu\text{V}$ 级别）。
    
- **失调电压漂移（Offset Voltage Drift, $\Delta V_{os}/\Delta T$）：** $V_{os}$ 随温度变化的变化率（单位 $\mu\text{V}/\text{°C}$），对全温度范围内的测量精度影响极大。
    
- **输入偏置电流（Input Bias Current, $I_b$）：** 运放输入端所需的静态偏置电流。FET 输入或 CMOS 输入型运放的 $I_b$ 极小（pA 到 fA 级），非常适合高阻抗传感器；而双极型（BJT）运放的 $I_b$ 相对较大（nA 级）。
    
- **共模抑制比（CMRR）：** 抑制两输入端共模信号（如干扰噪声）的能力。测量小信号时，CMRR 越高越好（通常要求 $> 80\text{dB}$，精密级可达 $> 120\text{dB}$）。
## 动态与交流指标

- **增益带宽积（Gain-Bandwidth Product, GBW / GBP）：** 运放开环增益降至 $1$ ($0\text{dB}$) 时的频率。若放大器的闭环增益为 $A_v$，则其允许的最大信号带宽近似为 $\text{BW} = \frac{\text{GBW}}{A_v}$。
    
- **压摆率/转换速率（Slew Rate, SR）：** 输出电压随时间变化的最大速率，定义为 $SR = \frac{dV}{dt}$（单位 $\text{V}/\mu\text{s}$）。SR 决定了运放在大信号输入时，输出不发生削顶/失真所能达到的最高频率。
    
- **建立时间（Settling Time）：** 阶跃信号输入后，输出到达并稳定在最终值指定误差范围内（如 $0.1\%$ 或 $0.01\%$）所需的时间，ADC 驱动电路对此指标极其敏感。
    
- **相干与相位裕度（Phase Margin）：** 衡量运放闭环稳定性、是否容易发生自激振荡的指标，通常建议相位裕度大于 $45^\circ$。

### 输出与电源指标

- **电源电压范围（Supply Voltage Range, $V_S$）：** 运放正常工作允许的单电源（如 $3.3\text{V}, 5\text{V}$）或双电源（如 $\pm 15\text{V}$）范围。
    
- **轨到轨特性（Rail-to-Rail, RRO / RRIO）：**
    
    - _轨到轨输入（RRI）：_ 输入信号范围可以达到甚至略微超出电源轨（$V_{SS} \sim V_{DD}$）。
        
    - _轨到轨输出（RRO）：_ 输出电压摆幅能够非常接近电源电压边缘，极大提高了低电压供电时的动态范围。
        
- **静态电流（Quiescent Current, $I_Q$）：** 芯片无负载时的工作电流。低功耗/微功耗运放（$I_Q < 1\ \mu\text{A}$）适用于便携式电池设备，但通常会牺牲 GBW 和 SR。
    
- **电源抑制比（PSRR）：** 电源电压波动对输出的影响，PSRR 越高，对电源纹波的抗干扰能力越强。

## 噪声指标
**等效输入电压噪声密度（$e_n$）与电流噪声密度（$i_n$）：** 单位通常为 $\text{nV}/\sqrt{\text{Hz}}$ 和 $\text{pA}/\sqrt{\text{Hz}}$。在微弱信号放大（如前置放大器）中，低噪声运放能避免将噪声过度放大而淹没有效信号。
