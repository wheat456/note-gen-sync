#  1. 整流二极管 Rectifier Diode

- 结构：PN 结大功率管
- 作用：**交流电转直流电（整流）**，电源适配器、开关电源主力器件，承受大电流
- 特点：反向耐压高，正向电流大，开关速度慢
## 关键参数

### 电压参数

| 参数               | 意义                                                                                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $V_{RRM}$        | 二极管在周期性工作时，能够承受的最大反向脉冲峰值电压。                                                                                                                                                   |
|                  | 选型时必须保留足够的降额裕量。一般建议选取工作电压峰值的 **1.5 ~ 2 倍** 以上。例如在 220V AC 工频整流中，整流后峰值电压约为 $220\sqrt{2} \approx 311\text{V}$，通常需选用 $V_{RRM} \ge 600\text{V} \sim 1000\text{V}$ 的二极管（如 1N4007）。 |
| $V_R$ 或 $V_{DC}$ | 二极管能够长期连续承受的最大直流反向阻断电压。通常略低于或等于 $V_{RRM}$。                                                                                                                                    |
| $V_{(BR)}$       | 反向电压增加到反向电流急剧增大时的拐点电压。正常工作时反向电压绝对不能达到该值。                                                                                                                                      |
| $V_F$            | 在特定正向电流 $I_F$ 和结温 $T_j$ 下，二极管两端的正向导通压降。                                                                                                                                       |
|                  | 直接决定导通损耗：$P_{\text{cond}} \approx V_F \times I_{F(AV)}$。<br>$V_F$ 越小，器件发热越低、效率越高。<br>硅 PN 结二极管的 $V_F$ 随结温升高而**降低**（负温度系数）；肖特基二极管（SBD）在小电流下也有类似特性。                             |

### 电流参数

| 参数                  | 意义                                                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| $I_{F(AV)}$ 或 $I_O$ | 在规定散热条件和外壳/环境温度（如 $T_C=100^\circ\text{C}$ 或 $T_A=25^\circ\text{C}$）下，二极管允许长期流过的最大半波整流平均电流。                                                        |
|                     | Datasheet 中会给出 **降额曲线（Derating Curve）**。随着温度升高，允许的最大电流会迅速下降。实际选用时一般降额至额定值的 **50% ~ 70%** 使用。                                                      |
| $I_{FSM}$           | 在规定的短时间内（通常为单个 8.3ms 或 10ms 的半正弦波脉冲），二极管能够承受且不损坏的最大瞬态浪涌电流。                                                                                        |
|                     | 在电容滤波整流电路中，开机上电瞬间滤波大电容相当于短路，会产生巨大的充电阻抗电流（Inrush Current）。必须确保电路的最大浪涌电流远小于 $I_{FSM}$。                                                              |
| $I^2t$              | 表征二极管承受短时过载能量的能力（单位：$\text{A}^2\text{s}$）。通常用于与前端快熔熔断器配合，做过载/短路保护选型匹配。                                                                            |
| $I_R$               | 二极管处于反向阻断状态时流过的微小电流，通常在额定 $V_{RRM}$ 条件下标称。                                                                                                        |
|                     | 普通硅整流管漏电流很小（$\mu\text{A}$ 级），但在高温下会显著增加。<br>**肖特基二极管（SBD）** 的 $I_R$ 普遍较大（可能达到数 $\text{mA}$ 级），且随着结温升高呈指数级飙升。如果散热设计不足，极易引发热失控（Thermal Runaway）而炸管。 |
### 动态/开关特性参数（高频整流与开关电源的关键）

> 如果用于 **50Hz/60Hz 工频整流**，该部分通常无需严格要求；但如果用于 **开关电源（DCDC、Flyback 输出整流、逆变高频整流）**，这是决定成败的核心指标。

1. **$t_{rr}$ (Reverse Recovery Time / 反向恢复时间)**
    - **物理意义**：二极管从正向导通状态迅速切换到反向截止状态时，由于结区存储电荷无法瞬间消失，会经历一段短暂的反向导通（反向恢复）时间。 
    - **影响**：
        - $t_{rr}$ 越大，开关切换时的交叠损耗（开关损耗）越大，且会引发严重的电压尖峰和 EMI 噪声。  
        - **常见分类**： 
            - 普通整流管（如 1N4007）：$t_{rr}$ 较长（通常未标出或在微秒级），仅适于 $\le 1\text{kHz}$ 工频。    
            - 快恢复（FRD）/ 超快恢复（FRED）：$t_{rr}$ 在数十纳秒到数百纳秒（如 25ns ~ 75ns）。  
            - 肖特基（SBD）/ 碳化硅肖特基（SiC SBD）：多数载流子器件，几乎无反向恢复电荷（$t_{rr} \approx 0$），高频性能极佳。  
2. **$Q_{rr}$ (Reverse Recovery Charge / 反向恢复电荷)**
    - **物理意义**：在反向恢复阶段反向抽取的总电荷量。$Q_{rr}$ 越小，开关损耗越低。
3. **$C_J$ 或 $C_T$ (Junction Capacitance / 结电容)**
    - **物理意义**：PN 结或肖特基势垒的等效电容。影响高频阻抗和信号边沿震荡。


# 2. 开关二极管 Switching Diode

- 作用：高速通断，数字电路逻辑切换、高频小信号开关
- 特点：结电容小，开关速度极快，适合高频、脉冲电路

# 3. 稳压二极管（齐纳二极管）Zener Diode

- 作用：**反向击穿稳压**，提供稳定基准电压、过压保护
- 工作条件：反向偏置击穿区，固定电压输出
# 4. 肖特基二极管 Schottky Barrier Diode (SBD)

- 金属 - 半导体结，无传统 PN 结
- 作用：低压大电流整流、高频开关、快充电源
- 优点：**正向压降低**、**恢复速度极快**；缺点反向耐压低

# 5.瞬态抑制二极管 TVS Transient Voltage Suppressor

- 作用：**浪涌 / 静电保护**，瞬间吸收高压脉冲，保护芯片端口
