#  1. 整流二极管 Rectifier Diode

- 结构：PN 结大功率管
- 作用：**交流电转直流电（整流）**，电源适配器、开关电源主力器件，承受大电流
- 特点：反向耐压高，正向电流大，开关速度慢
# 2. 开关二极管 Switching Diode

- 作用：高速通断，数字电路逻辑切换、高频小信号开关
- 特点：结电容小，开关速度极快，适合高频、脉冲电路

# 3. 稳压二极管（齐纳二极管）Zener Diode

- 作用：**反向击穿稳压**，提供稳定基准电压、过压保护
- 工作条件：反向偏置击穿区，固定电压输出
# 4. 肖特基二极管 Schottky Barrier Diode (SBD)

- 金属 - 半导体结，无传统 PN 结
- 作用：低压大电流整流、高频开关、快充电源
- 优点：**正向压降低**、**恢复速度极快**；缺点反向耐压低

# 5.瞬态抑制二极管 TVS Transient Voltage Suppressor

- 作用：**浪涌 / 静电保护**，瞬间吸收高压脉冲，保护芯片端口
