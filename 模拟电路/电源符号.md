# 一、电源类（正电源）

| 符号              | 意义                                                                      |
| --------------- | ----------------------------------------------------------------------- |
| **VCC**         | 直插双极型（BJT）电路里最常用的“正电源”代号，C 表示 Collector（集电极）。  <br>　　例：单片机 5 V 脚常标 VCC。 |
| **VDD**         | MOS/CMOS 电路里的“正电源”，D 表示 Drain（漏极）。<br>例：STM32 芯片 3.3 V 供电脚标 VDD。        |
| **VSS**         | 对应 VDD 的“地”，S 表示 Source（源极）。                                            |
| **VREF**        | 基准电压，给 ADC/DAC 或比较器当“尺子”。  <br>例：STM32 的 VDDA / VREF+。                  |
| **AVCC / AVDD** | 模拟部分专用正电源，A = Analog。  <br>例：MCU 的 ADC 模块独立供电脚。                         |
| **VBAT**        | 电池备份电源，掉电后维持 RTC、SRAM。  <br>例：STM32 的 VBAT 接 3 V 纽扣电池。                  |
| **VBUS**        | USB 线缆里的 5 V 总线电源。  <br>例：Type-C 口第一脚就是 VBUS。                           |


# 地

| 符号   | 意义                                              |
| ---- | ----------------------------------------------- |
| AGND | 用于 ADC、DAC、运放、音频等敏感模拟电路回流。                      |
| DGND | 数字地                                             |
| PGND | 用于 DC-DC 开关电源功率回路、MOSFET/IGBT 驱动、电机驱动等大电流脉冲回路。  |
| CGND | 机壳地（Chassis Ground）或大地（Earth），多用于接插件外壳、防雷防浪涌回路。 |
