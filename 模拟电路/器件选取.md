# 三极管
| 参数名称     | 符号          | 作用/意义                                             |
| -------- | ----------- | ------------------------------------------------- |
| 集电极最大电压  | VCEO​、VCBO​ | 决定三极管在关断时能承受的最高电压，选型时要保证高于实际工作电压（留一定裕量，一般1.5-2倍）。 |
| 集电极最大电流  | IC          | 决定负载电流能力，实际工作电流要低于此值。                             |
| 功耗       | PtotPtot​   | 决定器件散热极限，功耗 = VCE×ICVCE​×IC​，要低于额定值。              |
| 直流电流放大倍数 | hFE或 β      | 决定放大能力，比如在放大电路中要保证足够的 ββ 才能驱动负载。注意 ββ 会随温度、电流变化。  |
| 截止频率     | fT          | 高频性能指标，频率高的电路要选 fTfT​ 高的三极管，否则增益会下降。              |
| 饱和压降     | VCE(sat)​   | 开关应用中，压降越小效率越高，发热越少。                              |
| 封装       | -           | 影响散热能力和焊接方式。                                      |

# mosfet
## 电压
| 参数         | 符号            | 说明                                                     |
| ---------- | ------------- | ------------------------------------------------------ |
| **漏源最大电压** | $V_{DS}(max)$ | MOSFET 能承受的最大漏-源电压。必须大于电路中可能出现的最大电压，一般留 **1.5~2 倍裕量**。 |
| **栅源最大电压** | $V_{GS}(max)$ | 栅极能承受的最大电压。逻辑驱动（如 5V、3.3V）必须低于这个值。                     |

## 电流与功耗
| 参数         | 符号        | 说明                                  |
| ---------- | --------- | ----------------------------------- |
| **连续漏极电流** | $I_D$     | 器件能持续承受的最大电流，取决于封装和散热。实际工作电流要低于这个值。 |
| **脉冲漏极电流** | $I_{DM​}$ | 短时间脉冲电流能力，比如开关浪涌。不能长时间使用。           |
| **功耗**     | $P_D$     | 取决于 ID2×RDS(on)​ 和散热条件。             |
