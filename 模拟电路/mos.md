# 关于放大的理解
- 放大指的是电压变化的幅度变大了，比如$G$极电压变化了0.2$V$，在$D$级的电压就会变化2$V$。
- 而非电流的增大，电流的大小实际取决于$D$极的电压，而$mos$只是控制了通道的大小，让流过的电流变大或者变小，如果不要$mos$那么这个路径的电流就可以直接达到最大
# 电流流向
- **NMOS** 就是从$S{\rightarrow}D$极流出电子，**PMOS** 就是从$S{\rightarrow}D$极流出空穴(带正电)，所以电流方向就明确了

# NMOS
- $G$ 极是没有电流流过的，也就是说接在G极的电压是多少就是多少，$GS$ 电压差表示控制能力强弱
### 截至
- $V_{GS}​$≤$V_{TH}$​
### 线性 
- $V_{GS}$​>$V_{th}​$
- ($V_{GS}$ - $V_{TH}$)>$V_{DS}$ 
>[!warning] 注意
>1.$V_{GS}$的电压不会像三极管那样被钳在一个值上，$V_{GS}$只要不大于击穿电压就可以
>2.同时 $V_D$ 可以在 0 到 ($V_G$ - $V_{TH}$) 之间**自由变化**
>mos类似于一条河，当G点的电压越大，水流就越大，D点的电压就越接近S点
### 饱和
- $V_{GS}$ > $V_{TH}$
- ($V_{GS}$ - $V_{TH}$) ≤$V_{DS}$
>[!warning] 注意
>1.当饱和时D点的电压可以一直大，但不要大于击穿电压
>2.如果G点的电压小，然而D点的电压大于 G点，就会导致没有放大特性，直接就饱和了
>


> [!Success] 理解
> 把沟道比喻成一条河流，$V_{GS}$就是$G$点相对于$S$点高出多少电压，在河流的每一点的电压差都必须大于vth。这里设置v(y)相对于s点高出多少电压，如果想打开s点，那么就必须vgs-v(y)>vth,因为这里是在s点，所以v(y)就是0。沿着河流上走，假设g点是一个河边上的岸，所有电压都是一样的。在最上方时，也就是d点，那么相对s点的电压就是vds,此时如果不想被关断就必须使Vgs-v(y)=vds>Vth,这样才能保持在线性区，否则就会被关断。


	
# PMOS 
## 截至
- $V_{SG}$<截至电压     是正数，比如0.5，1等
## 线性
 - $V_{SG}$>截至电压
 - $V_{SD}$ <$V_{SG}$ - 截至电压
 - $V_G$+截止电压<$V_D$
## 饱和
 - $V_{SG}$>截至电压
 - $V_{SD}$ >=$V_{SG}$ - 截至电压


| 器件类型 | 导通条件                               | 线性区条件                           | 饱和区条件                           |
| ---- | ---------------------------------- | ------------------------------- | ------------------------------- |
| PMOS | $V_{SG}​$>∣$V_{th}​$∣              | $V_{SD}​$<$V_{SG}​$−∣$V_{th}​$∣ | $V_{SD}​$≥$V_{SG}​$−∣$V_{th}​$∣ |
| NMOS | $V_{GS​}$>$V_{th}​$​（$V_{th}​$ 为正） | $V_{DS}​$<$V_{GS​}$​−$V_{th}​$  | $V_{DS}​$≥$V_{GS​}$−$V_{th​}$   |

>[!success] 理解
>首先，假设$v(y)$是河流上的任意一点相对于s点的压降，如果要使s点打开，那么$V_{sg}$(这里是g点相对于s点降了多少)-$v(y)$>$V_{th}$，在s点v(y)就等于0.
>当$v(y)$=$V_{SD}$ <$V_{SG}$ - 截至电压,时v(y)处于d点

# 增强型和耗尽型
## 增强型 MOS（Enhancement mode MOSFET）
- **简单理解**：增强型MOS就是默认沟道是断开的
- **阈值电压 \(V_{th}\)**  
  - NMOS：正值  
  - PMOS：负值  

- **特性**  
  - 在 \($V_{gs}$=0\) 时，器件截止。  
  - 只有当 \($V_{gs}$\) 超过阈值时才会在栅下“增强”出一个反型沟道，才能导通。  
    - NMOS：\($V_{gs}$ > $V_{th}$ > 0\)  
    - PMOS：\($V_{sg}$ > |$V_{th}$|\)  

- **常态**：关断 → 加电压才导通  
## 耗尽型 MOS（Depletion mode MOSFET）
- **简单理解**：耗尽型MOS就是默认沟道是连接的
- **阈值电压 $V_{th}$  
  - NMOS：负值  
  - PMOS：正值  

- **特性**  
  - 在 \($V_{gs}=0$\) 时，器件已有一条天然的导电沟道，可以导通。  
  - 如果给栅加反向电压，才会“耗尽”沟道载流子，逐渐关断。  
    - NMOS：\($V_{gs}$<0\)  
    - PMOS：($V_{gs}$>0)  

- **常态**：导通 → 加电压才关断

**PMOS**:沟道中的任意一点电压减去G点电压，如果小于  $V_{th}$ 就夹断



# 使用NMOS

## 1. 明确设计目标与工作模式

首先问自己：这个 NMOS 是用来做什么的？
- **做开关（开关管/驱动管）**：追求尽可能低的导通电阻 $R_{DS(on)}$，让管子工作在**线性区（饱和导通）**或**截止区**。
- **做放大器/恒流源**：追求稳定的跨导 $g_m$ 和高输出阻抗，必须确保管子稳定工作在**饱和区**。
## 2. 设定静态工作点（DC Bias Point）

在确定做放大电路后，设计者不会盲目选元件，而是**先定工作点 ($I_D, V_{DS}$)**：
- **设定偏置电流 $I_D$**：根据系统的**功耗预算**或**速度/驱动能力**需求，优先指定一个静态电流 $I_D$。
- **设定漏源电压 $V_{DS}$**：为了留足输出电压摆幅（Dynamical Range），通常将 $V_D$ 设定在电源电压 $V_{DD}$ 的中间附近（例如 $V_{DS} \approx \frac{1}{2}V_{DD}$），同时确保满足饱和条件：
    
    $$V_{DS} \ge V_{GS} - V_{th}$$


## 3. 确定过驱动电压 $V_{ov}$ 与 $V_{GS}$

设计者通常用**过驱动电压（Overdrive Voltage）** $V_{ov} = V_{GS} - V_{th}$ 来作为设计桥梁：
- **分立元件设计（PCB 板级设计）**：
    MOS 管的 $W/L$ 和 $V_{th}$ 是选型时已固定的。此时根据手册中的 $I_D - V_{GS}$ 曲线或公式，反算出需要的 **$V_{GS}$**。


## 4. 计算并配置外围电阻元件

确定了 $I_D$、$V_{DS}$ 和 $V_{GS}$ 后，接下来才是**放置并计算外围电阻**：
1. **设置源极电阻 $R_S$（若需要直流稳定/负反馈）**：
    - $R_S$ 可以稳定 $I_D$，防止温度漂移。
    - 源极电压：$V_S = I_D \cdot R_S$
2. **设置栅极偏置网络（$R_G1, R_G2$）**：
    - 栅极所需电压：$V_G = V_{GS} + V_S = V_{GS} + I_D \cdot R_S$
    - 利用分压公式确定电阻比值：$V_G = V_{DD} \cdot \frac{R_{G2}}{R_{G1} + R_{G2}}$（通常取 $M\Omega$ 级电阻以保持高输入阻抗）。
3. **设置漏极负载电阻 $R_D$**：
    - 根据目标 $V_D$（由 $V_{DS} + V_S$ 决定），计算 $R_D$ 的阻值： $$R_D = \frac{V_{DD} - V_D}{I_D}$$






要掌控 $V_{DS}$，你的脑海里只需要记住这根“临界线”——**临界饱和电压** $V_{DS(sat)} = V_{GS} - V_{th}$：

- **想让它工作在放大状态（饱和区）**：必须保证 **$V_{DS} \ge V_{GS} - V_{th}$**
    
- **想让它工作在开关导通状态（线性区）**：必须保证 **$V_{DS} < V_{GS} - V_{th}$**（越小越好，接近 $0\text{V}$）
