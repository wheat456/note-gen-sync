# 关于放大的理解
- 放大指的是电压变化的幅度变大了，比如G极电压变化了0.2v，在D级的电压就会变化2V，而非电流的增大，电流的大小实际取决于D极的电压，而mos只是控制了通道的大小，让流过的电流变大或者变小，如果不要mos那么这个路径的电流就可以直接达到最大

# nmos
默认s点的电压小于g和d
### 截至
- $V_{GS}​$≤$V_{TH}$​
### 线性
- $V_{GS}$​>$V_{th}​$
- $V_{D}$ < ($V_{G}$ - $V_{TH}$)
>[!warning] 注意
>1.$V_{GS}$的电压不会像三极管那样被钳在一个值上，$V_{GS}$只要不大于击穿电压就可以
>2.同时$V_D$可以在 0 到 ($V_G$ - $V_{TH}$) 之间**自由变化**
>mos类似于一条河，当G点的电压越大，水流就越大，D点的电压就越接近S点
### 饱和
- $V_{GS}$ > $V_{TH}$
- $V_D$ ≥ ($V_{G}$ - $V_{TH}$)
>[!warning] 注意
>1.当饱和时D点的电压可以一直大，但不要大于击穿电压
>2.如果G点的电压小，然而D点的电压大于 G点，就会导致没有放大特性，直接就饱和了
