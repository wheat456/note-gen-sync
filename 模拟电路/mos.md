# nmos
默认s点的电压小于g和d
### 截至
- $V_{GS}​$≤$V_{TH}$​
### 线性
- $V_{GS}$​>$V_{th}​$
- $V_{D}$ < ($V_{G}$ - $V_{TH}$)
>[!warning] 注意
>1.$V_{GS}$的电压不会像三极管那样被钳在一个值上，$V_{GS}$只要不大于击穿电压就可以
>2.同时$V_D$可以在 0 到 ($V_G$ - $V_{TH}$) 之间**自由变化**
### 饱和
- $V_{GS}$ > $V_{TH}$
- $V_D$ ≥ ($V_{G}$ - $V_{TH}$)
>[!warning] 注意
>当饱和时D点的电压可以一直打，但不要大于击穿电压
