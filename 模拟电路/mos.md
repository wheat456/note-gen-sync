# 关于放大的理解
- 放大指的是电压变化的幅度变大了，比如$G$极电压变化了0.2$V$，在$D$级的电压就会变化2$V$。
- 而非电流的增大，电流的大小实际取决于$D$极的电压，而$mos$只是控制了通道的大小，让流过的电流变大或者变小，如果不要$mos$那么这个路径的电流就可以直接达到最大
# 电流流向
- **NMOS** 就是从$S{\rightarrow}D$极流出电子，**PMOS** 就是从$S{\rightarrow}D$极流出空穴(带正电)，所以电流方向就明确了

# NMOS
- G极是没有电流流过的，也就是说接在G极的电压是多少就是多少，GS电压差表示控制能力强弱
### 截至
- $V_{GS}​$≤$V_{TH}$​
### 线性
- $V_{GS}$​>$V_{th}​$
- ($V_{GS}$ - $V_{TH}$)>$V_{DS}$ 
>[!warning] 注意
>1.$V_{GS}$的电压不会像三极管那样被钳在一个值上，$V_{GS}$只要不大于击穿电压就可以
>2.同时$V_D$可以在 0 到 ($V_G$ - $V_{TH}$) 之间**自由变化**
>mos类似于一条河，当G点的电压越大，水流就越大，D点的电压就越接近S点
### 饱和
- $V_{GS}$ > $V_{TH}$
- ($V_{GS}$ - $V_{TH}$) ≤$V_{DS}$
>[!warning] 注意
>1.当饱和时D点的电压可以一直大，但不要大于击穿电压
>2.如果G点的电压小，然而D点的电压大于 G点，就会导致没有放大特性，直接就饱和了
>


> [!Success] 理解
> 把沟道比喻成一条河流，Vgs就是g点相对于s点高出多少电压，在河流的每一点的电压差都必须大于vth。这里设置v(y)相对于s点高出多少电压，如果想打开s点，那么就必须vgs-v(y)>vth,因为这里是在s点，所以v(y)就是0。沿着河流上走，假设g点是一个河边上的岸，所有电压都是一样的。在最上方时，也就是d点，那么相对s点的电压就是vds,此时如果不想被关断就必须使Vgs-v(y)=vds>Vth,这样才能保持在线性区，否则就会被关断。



# PMOS 
## 截至
- $V_{SG}$<截至电压     是正数，比如0.5，1等
## 线性
 - $V_{SG}$>截至电压
 - $V_{SD}$ <$V_{SG}$ - 截至电压
 - $V_G$+截止电压<$V_D$
## 饱和
 - $V_{SG}$>截至电压
 - $V_{SD}$ >=$V_{SG}$ - 截至电压


| 器件类型 | 导通条件                               | 线性区条件                           | 饱和区条件                           |
| ---- | ---------------------------------- | ------------------------------- | ------------------------------- |
| PMOS | $V_{SG}​$>∣$V_{th}​$∣              | $V_{SD}​$<$V_{SG}​$−∣$V_{th}​$∣ | $V_{SD}​$≥$V_{SG}​$−∣$V_{th}​$∣ |
| NMOS | $V_{GS​}$>$V_{th}​$​（$V_{th}​$ 为正） | $V_{DS}​$<$V_{GS​}$​−$V_{th}​$  | $V_{DS}​$≥$V_{GS​}$−$V_{th​}$   |

>[!success] 理解
>首先，假设$v(y)$是河流上的任意一点相对于s点的压降，如果要使s点打开，那么$V_{sg}$(这里是g点相对于s点降了多少)-$v(y)$>$V_{th}$，在s点v(y)就等于0.
>当$v(y)$=$V_{SD}$ <$V_{SG}$ - 截至电压,时v(y)处于d点

# 增强型和耗尽型
## 增强型 MOS（Enhancement mode MOSFET）
- **简单理解**：增强型MOS就是默认沟道是断开的
- **阈值电压 \(V_{th}\)**  
  - NMOS：正值  
  - PMOS：负值  

- **特性**  
  - 在 \($V_{gs}$=0\) 时，器件截止。  
  - 只有当 \($V_{gs}$\) 超过阈值时才会在栅下“增强”出一个反型沟道，才能导通。  
    - NMOS：\($V_{gs}$ > $V_{th}$ > 0\)  
    - PMOS：\($V_{sg}$ > |$V_{th}$|\)  

- **常态**：关断 → 加电压才导通  
## 耗尽型 MOS（Depletion mode MOSFET）
- **简单理解**：耗尽型MOS就是默认沟道是连接的
- **阈值电压 $V_{th}$  
  - NMOS：负值  
  - PMOS：正值  

- **特性**  
  - 在 \($V_{gs}=0$\) 时，器件已有一条天然的导电沟道，可以导通。  
  - 如果给栅加反向电压，才会“耗尽”沟道载流子，逐渐关断。  
    - NMOS：\($V_{gs}$<0\)  
    - PMOS：($V_{gs}$>0)  

- **常态**：导通 → 加电压才关断
