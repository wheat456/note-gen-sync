| **滤波器类型**          | **功能描述 🔍**  | **现实类比 🔊**           |
| ------------------ | ------------ | --------------------- |
| **低通 (Low Pass)**  | 只让低频通过，滤除高频  | 隔墙听音（只能听到闷闷的低音）       |
| **高通 (High Pass)** | 只让高频通过，滤除低频  | 小喇叭（去掉了厚重的低音，只有清脆声）   |
| **带通 (Band Pass)** | 只让中间某一段频率通过  | 收音机调台（只听某一个频道的歌）      |
| **带阻 (Band Stop)** | 挡住某一段频率，其他通过 | 消除噪音（专门滤掉 50Hz 的电网杂音） |

# 一阶有源低通滤波
![[Pasted image 20251218154714.png]]

滤波器开始“发力”拦截信号的那个转折点，我们称为截止频率。它的计算公式非常简洁：

$$f_c = \frac{1}{2\pi RC}$$

在这个频率点之后，信号每增加 10 倍频率，强度就会衰减到原来的 $1/10$。
