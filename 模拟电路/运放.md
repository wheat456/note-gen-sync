- **同相放大器**的信号是从**同相端**进入，而**反相放大器**就是从**反相端**进入
- **开环（Open-Loop）** 和 **闭环（Closed-Loop）** 指的是反馈（Feedback）系统是否存在
	- **开环**指的是放大器**没有任何反馈回路**
	- **闭环**指的是在放大器的输出端和输入端之间**建立了一条通道（反馈网络）**，把输出信号的一部分“送回”到输入端，用来修正和控制放大器的行为
- 运放的本质是一个**差分放大器**，这意味着运放放大的是**两个端口之间的电压差**
- 除了**平衡信号**是两个端口都有信号，其他的一般只有一个端口接信号，另一个端口接参考电压
# 虚断
意思：运放的两个输入端，好像断开了一样，几乎没有电流流入。
# 虚短
“虚短”是指：在**负反馈**条件下，运放的两个输入端电压几乎相等，好像短路了一样。
**虚短**是运放的**后天技能**，它必须配合**负反馈电路**才能实现。

# 理想状态
1. **输入==阻抗无穷大**==：就像一堵密不透风的墙，电流根本进不去。
2. **开环==增益无穷大**==：哪怕输入端只有微伏级别的电压差，输出端也会瞬间飞到天边（实际上是受电源电压限制）。
# 反馈
- 负反馈：连在**输出脚**和**反相端**
- $$G=1+\frac{R_f}{R_g}$$
- $R_f$就是输出与反相端之间的电阻，$R_g$就是反相端前面的一个电阻


# 同相和反相放大器使用场景
## 同相
- 同相放大器的输入阻抗极高
## 反相
- 多路信号混合
- 需要把倍数做小，小于 1 倍
# 同相放大器
- 放大倍数永远大于或等于 1
- 输出端会通过反馈使$V_-$不断靠近$V_+$，最终使$V_{out}$电压稳定。
- 反馈电阻通常选取10K-100K
- $R_2$ 是$R_f$
- 公式
$$A_{V} = \frac{V_{out}}{V_{in}} = 1 + \frac{R_{f}}{R_{1}}$$

# 反相放大器
- 输入阻抗不再是无穷大，**反相放大器的输入阻抗就等于 $R_{in}$ 的阻值**。
- 为了平衡输入阻抗（希望 $R_{in}$ 大一点）和噪声/寄生电容（希望 $R_{f}$ 小一点），常规设计常常选择 **$R_{in} = 10\text{ k}\Omega$** 作为基准，再根据需要的倍数去调整 $R_{f}$。
- 放大倍数可以小于1
$$V_{out} = -\left( \frac{R_{f}}{R_{in}} \right) \times V_{in}$$

# 功率放大与运算放大器
|**特性**|**运算放大器 (Op-Amp)**|**功率放大器 (PA)**|
|---|---|---|
|**主要任务**|**电压放大**与数学运算（加减积分等）|**功率放大**（同时放大电压和电流）|
|**驱动能力**|弱。输出电流通常只有几十毫安 (mA)|强。输出电流可达几安培 (A) 或更多|
|**精确度**|极高。追求低失调、低漂移、高线性度|相对较低。更关注效率、散热和驱动力|
|**负载目标**|高阻抗负载（如下一级电路的输入端）|低阻抗负载（如扬声器 4/8Ω、电机、天线）|
|**反馈机制**|几乎总是配合**负反馈**网络使用|内部可能包含反馈，但通常作为一个独立的功率单元|

| 轨到轨  | 普通传统运放（如经典的 NE5532、LM358）如果接 5V 电源，输出端最多只能升到约 3.5V，最低降到约 0.7V，上下各留了 1V 多的空隙。如果输入信号幅度较大，波峰和波谷就会被强行削平（削波破音）。 |
### 速度与带宽

| 名称    | 意义                                                                                                                      |
| ----- | ----------------------------------------------------------------------------------------------------------------------- |
| 增益带宽积 | 如果你选了一颗 $\text{GBW} = 1\text{MHz}$ 的入门芯片，电路设计放大 100 倍，那它最多只能处理到 $10\text{kHz}$ 的信号。如果用来放 $20\text{kHz}$ 的高音，高频信号会被大幅衰减。 |
| 压摆率   | 即便带宽够用，当突然来了一个幅度很大、变化极快的波形时，如果压摆率不够，芯片输出电压“跑得不够快”，一个原本平滑的正弦波会被硬生生拉扯成“三角波”，声音会产生干瘪、刺耳的失真                                 |
