- 原理图检查规则
	- 位置：工程文件 -> 工程选项 -> error reporting
	- `duplicate part designators`:器件位号重复
	- `Floating Net Labels`:存在悬浮的网络标号
	- `Floating Power Objects`:存在悬浮的电源端口
	- `Nets with only one pin`:存在单端网络
- 技巧：
	- 原理图：
		- `alt+左键`原理图器件高亮
	- PCB:
		- `alt+左键`选中飞线
		- `dsd`快速定义板框
		- `shift e`抓取顶点
		- `E A` 特殊粘贴到当前层
		- `M S` 选择移动某个器件
		- `L`层叠颜色
		- `F11`打开器件属性
		- `T C` 定位器件原理图
		- `S L`线选
		- `A P`调整文本相对位置
- PCB导入
	- 第一次直接执行变更，再次执行变更发现错误元件
	- 通过报错的位号（C7等）名排查相应的元件
	- 原理图器件和PCB封装是通过`designators`关联
- PCB报错
	- `工具 -> 设计规则检查 -> Rules To Check `可以开关实时错误显示
- PCB布局步骤
	- 关闭飞线相对CPU摆放器件大致位置
	- 关闭电源线调整器件位置
	- 先布边缘器件，调整边缘器件的模块电路
