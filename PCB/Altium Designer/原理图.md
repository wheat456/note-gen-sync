# 快捷键

- 在 `components` 中拖出器件后
  - `tab`用来显示属性
    - 前提是必须鼠标选中后才能显示器件属性
  - `x`,`y`键左右和上下使器件镜像
  - `space` 逆时针90°旋转器件
- `ctrl+wheel`用来放大和缩小
- 在原理图上**鼠标右键**可以拖动视图
- 移动器件
	- 如果想断掉导线移动器件，可以ctrl加点击移动，此时导线不会跟随
	-  可以使用ctrl加方向键移动，同时按下shift移动距离x10
	-  `K` ：快速打开`panel`
	- `T+S` : 选中器件后，会在pcb快速定位到器件

# 画线

- ctrl+w
- 可以使用`enter`进行连线，比如在起点`enter`,终点`enter`,那么就直接连线
- 在连线中使用 `空格` 可以改变转角方向
- shift+空格可以使用45°等斜线方式
	- 其中有自动线
- 使用`回退键`可以回退上次做线
