`useEffect(() => { /* 副作用 */ }, [dep]);`

# 插槽
将组件作为参数传入到一个组件中
1. 首先，参数类型为`React.ReactNode`
```ts
function App1({child}:{child:React.ReactNode}){
	return(
	<child/>
	)
}

```
2. 传入参数
```ts
<App1>
<p>xxxxx</p> //这里就是参数

</App1>


或者具名参数
<Layout header={<h1>我是头部内容</h1>} footer={<p>我是底部内容</p>} />
```
