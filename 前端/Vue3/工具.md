# h函数

```ts
h(type, props?, children?)
```

`h()` 最多接收 3 个参数：
- **第 1 个参数 `type`（必填）：** 要渲染的目标。
    - 原生 HTML 标签字符串（如 `'div'`, `'button'`, `'span'`）
    - Vue 单文件组件对象（如 `import MyButton from './MyButton.vue'`）
    - 渲染函数或内置 Symbol（如 `Fragment`, `Teleport`）
- **第 2 个参数 `props`（可选）：** 节点的属性、类名、样式、事件监听器以及传给组件的 Props。
- **第 3 个参数 `children`（可选）：** 子节点，可以是纯文本字符串、数值、VNode 数组，或是包含插槽函数的对象。
