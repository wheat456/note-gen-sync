| **特性**        | **ref**                                         | **reactive**              |
| ------------- | ----------------------------------------------- | ------------------------- |
| **支持的数据类型**   | 任何类型（基础类型、对象、数组、Map 等）                          | 仅限**引用类型**（对象、数组、Set、Map） |
| **TS 访问方式**   | 脚本中需使用 `.value`，模板中自动解包                         | 直接读写属性，无需 `.value`        |
| **底层实现**      | 基于带有 `get/set` 访问器的包装对象（对象类型底层会自动转调 `reactive`） | 基于 ES6 `Proxy`            |
| **解构 / 重新赋值** | 重新赋值 `.value` 保持响应式                             | 直接解构或重新赋值整个对象会**丢失响应式**   |
# ref
- 在TS中推荐先用interface定义解构后使用ref
```ts 
interface UserProfile {
  id: number
  name: string
  avatar?: string
}

// 场景 1：初始值为 null 或 undefined 的异步数据
const user = ref<UserProfile | null>(null)
user.value = { id: 1, name: 'Alex' }
```
- 解构保持响应性 也就是解构出来的name和age 修改后会影响到`user`中name 和age的值
```ts
import { ref, toRefs } from 'vue'

const user = ref({ name: 'Alex', age: 20 })

// toRefs 会把对象的每个属性都包装成独立的 Ref
const { name, age } = toRefs(user.value)

name.value = 'Bob' // ✅ 原 user.value.name 同步变更为 'Bob'，页面正常触发更新
```
- 重新赋值 `.value` 保持响应式
```ts
import { ref, toRefs } from 'vue'

const user = ref({ name: 'Alex', age: 20 })
user.value = 一个新的对象 // 那么user还是响应式的
```

# reactive
- 使用时无需`.value`
- 不可以直接赋值，否则会丢失响应性
```ts
let state = reactive({ count: 0 })

// ❌ 错误：重新赋值直接切断了响应式连接，原代理丢失
state = reactive({ count: 1 })

// ✅ 正确做法 1：使用 ref 代替
const stateRef = ref({ count: 0 })
stateRef.value = { count: 1 }

// ✅ 正确做法 2：只修改内部属性
Object.assign(state, { count: 1 })
```
- 直接解构会丢失响应性
```ts
const state = reactive({
  name: 'Bob',
  age: 25
})

// ❌ 错误：解构出来的 name 和 age 只是普通的基础值，不再具备响应性
const { name, age } = state
```
- 安全解构
```ts
import { reactive, toRefs, toRef } from 'vue'

const user = reactive({
  name: 'Charlie',
  role: 'Admin'
})

// toRefs 将对象的每个属性都转换为对应的 Ref 对象
const { name, role } = toRefs(user)
// name 类型为 Ref<string>，修改 name.value 会同步更新 user.name
name.value = 'Dave'

// toRef 用于单独提取某一个属性
const roleRef = toRef(user, 'role')
```
