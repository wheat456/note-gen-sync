# 组件通信

## 1. 父子组件通信

### 1.1 父向子传递数据 (Props)

#### 基本用法

Props 是父组件向子组件传递数据的一种方式。它们是单向的，从父组件流向子组件。

在父组件中使用子组件时，通过属性传递数据：
```vue
<ChildComponent :message="parentMessage" /> //加了冒号就视为变量
```

在子组件中使用 **defineProps** 定义接收的 props：
```javascript
import { defineProps } from 'vue'

// 定义 props
const props = defineProps(['message'])
// 或者带类型定义
const props = defineProps({
  message: String
})
```

#### 类型验证

Vue 允许你为 props 指定类型，当传入的值类型不匹配时会在控制台发出警告。

使用 defineProps 进行类型验证：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型检查
  propA: Number,
  // 多种可能的类型
  propB: [String, Number],
  // 必填的字符串
  propC: {
    type: String,
    required: true
  },
  // 带有默认值的数字
  propD: {
    type: Number,
    default: 100
  },
  // 带有默认值的对象
  propE: {
    type: Object,
    default() {
      return { message: 'hello' }
    }
  },
  // 自定义验证函数
  propF: {
    validator(value) {
      return ['success', 'warning', 'danger'].includes(value)
    }
  }
})
```

#### 默认值设置

为 props 设置默认值可以提高组件的健壮性：

使用 defineProps 设置默认值：
```javascript
import { defineProps } from 'vue'

const props = defineProps({
  // 基础类型默认值
  title: {
    type: String,
    default: '默认标题'
  },
  // 对象类型默认值
  options: {
    type: Object,
    default() {
      return {
        size: 'medium',
        visible: false
      }
    }
  },
  // 数组类型默认值
  items: {
    type: Array,
    default() {
      return []
    }
  }
})
```

####  TS常用
- 使用接口定义类型，一般是一个对象
```ts
<script setup lang="ts">
interface Props {
  title: string
  count?: number // 可选
  list?: string[]
}
const props = defineProps<Props>()
// 设置默认值需要 withDefaults
const props = withDefaults(defineProps<Props>(), {
  count: 0,
  list: () => []
})
</script>
```
- 在父组件中传入参数时，使用了`<Child :count="num" :visible="true" />`,其中`:`是将num作为变量
### 1.2 子向父传递数据 (Emit) /自定义事件

子组件向父组件传递数据通常使用事件发射 (emit) 机制。
- 在子组件中定义事件，然后提交事件
```ts
const emit = defineEmits(['change-title', 'submit-data']) //定义事件
emit('change-title', '这是来自子组件的新标题') //发出事件
```
- 在父组件中使用`@事件名=""`进行响应的动作
### 自定义 v-model

Vue 3 中可以自定义组件的 v-model，实现双向数据绑定。

### 1.3 透传 Attributes (Attrs)

透传 Attributes 是 Vue 3 中一个重要的特性，允许父组件向子组件传递未被声明为 props 的属性。
使用v-bind="$attr"向下传递
#### 基本用法

在父组件中传递属性给子组件：
```vue
<!-- 父组件 -->
<ChildComponent :class="myClass" :style="myStyle" id="my-id" data-test="test" />
```

在子组件中使用 **useAttrs** 获取透传的属性：
```javascript
import { useAttrs } from 'vue'

export default {
  setup() {
    const attrs = useAttrs()
    
    // attrs 包含所有未被声明为 props 的属性
    console.log(attrs) // { class: 'my-class', style: 'color: red;', id: 'my-id', 'data-test': 'test' }
    
    return {
      attrs
    }
  }
}
```

在模板中使用透传的属性：
```vue
<template>
  <!-- 将 attrs 应用到根元素 -->
  <div v-bind="attrs">
    子组件内容
  </div>
  
  <!-- 或者选择性地应用某些属性 -->
  <div :class="attrs.class" :id="attrs.id">
    子组件内容
  </div>
</template>
```

#### inheritAttrs 属性

通过设置 `inheritAttrs` 选项可以控制是否自动将透传的属性应用到根元素：

```javascript
import { useAttrs } from 'vue'

export default {
  inheritAttrs: false, // 禁用自动继承 attrs
  setup() {
    const attrs = useAttrs()
    
    return {
      attrs
    }
  }
}
```

禁用自动继承后，需要手动决定将哪些属性应用到元素上：

```vue
<template>
  <!-- 不会自动应用 attrs -->
  <div>
    <!-- 手动选择要应用的属性 -->
    <div v-bind="attrs">内容</div>
    <!-- 或者只应用特定属性 -->
    <p :class="attrs.class">{{ attrs.title }}</p>
  </div>
</template>
```

使用场景：
1. 需要将属性应用到非根元素上
2. 需要对透传属性进行处理后再应用
3. 多根节点组件（Vue 3 支持多个根节点）

#### 基本用法

默认情况下，v-model 在组件上使用时等价于传递 `modelValue` prop 和监听 `update:modelValue` 事件：

```vue
<!-- 父组件 -->
<ChildComponent v-model="parentData" />

<!-- 等价于 -->
<ChildComponent :modelValue="parentData" @update:modelValue="parentData = $event" />
```

在子组件中实现 v-model：

```javascript
// 子组件
import { defineProps, defineEmits } from 'vue'

// 定义接收的 props
const props = defineProps({
  modelValue: String // 默认使用 modelValue 作为 prop 名称
})

// 定义可发射的事件
const emit = defineEmits(['update:modelValue'])

// 更新数据的方法
const updateValue = (newValue) => {
  emit('update:modelValue', newValue)
}
```

在子组件模板中使用：

```vue
<template>
  <input :value="modelValue" @input="updateValue($event.target.value)" />
</template>
```

#### 基本用法

在子组件中使用 **defineEmits** 定义可发射的事件，并使用返回的 emit 函数发射事件：

```javascript
import { defineEmits } from 'vue'

// 定义可发射的事件
const emit = defineEmits(['update', 'delete'])

// 发射事件
const onUpdate = () => {
  emit('update', { id: 1, name: 'updated item' })
}

const onDelete = () => {
  emit('delete', 1)
}
```

在父组件中监听子组件发射的事件：

```vue
<ChildComponent @update="handleUpdate" @delete="handleDelete" />
```

在父组件的处理函数中接收子组件传递的数据：

```javascript
const handleUpdate = (data) => {
  console.log('接收到更新数据:', data)
}

const handleDelete = (id) => {
  console.log('接收到删除ID:', id)
}
```

#### 类型定义

为 emit 事件添加类型定义可以提供更好的开发体验和类型检查：

```javascript
import { defineEmits } from 'vue'

// 带类型定义的 emit
const emit = defineEmits<{
  (e: 'update', data: { id: number; name: string }): void
  (e: 'delete', id: number): void
}>()

// 或者使用对象形式
const emit = defineEmits({
  update: ({ id, name }: { id: number; name: string }) => {
    return id > 0 && name.length > 0
  },
  delete: (id: number) => {
    return id > 0
  }
})
```

## 2. 跨组件通信 

### 2.1 Mitt 简介与基本用法
Mitt 是一个轻量级的事件总线库，用于在 Vue 3 应用中实现跨组件通信，特别适用于非父子关系的组件之间通信。

首先安装 Mitt：
```bash
npm install mitt
```

创建事件总线实例：
```javascript
// utils/eventBus.js
import mitt from 'mitt'

export const eventBus = mitt()
```

### 2.2 Mitt 事件监听与发射
在组件中使用 Mitt 进行事件通信：
```javascript
// 在需要发送事件的组件中
import { eventBus } from '@/utils/eventBus'

// 发射事件
const sendData = () => {
  eventBus.emit('data-updated', { message: 'Hello from component A' })
}
```

```javascript
// 在需要接收事件的组件中
import { eventBus } from '@/utils/eventBus'
import { onMounted, onUnmounted } from 'vue'

// 监听事件
const handleDataUpdated = (data) => {
  console.log('接收到数据:', data)
}

onMounted(() => {
  eventBus.on('data-updated', handleDataUpdated)
})

// 记得在组件销毁前移除事件监听
onUnmounted(() => {
  eventBus.off('data-updated', handleDataUpdated)
})
```

Mitt 常用 API：
- `emit(eventName, data)`: 发射事件
- `on(eventName, handler)`: 监听事件
- `off(eventName, handler)`: 移除事件监听
- `all`: 包含所有事件的 Map 对象
## 3. $refs 和 $parent

### 3.1 $refs 的使用

在组合式 API 中，`$refs` 主要用于访问 DOM 元素或子组件实例。有以下两种方式：

#### 1. 使用 ref 变量（推荐方式）

```vue
<template>
  <div>
    <!-- 访问DOM元素 -->
    <input ref="inputRef" />
    
    <!-- 访问子组件实例 -->
    <ChildComponent ref="childRef" />
    
    <button @click="handleClick">操作</button>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import ChildComponent from './ChildComponent.vue'

// 创建 ref 变量
const inputRef = ref(null)
const childRef = ref(null)

const handleClick = () => {
  // 访问DOM元素
  inputRef.value.focus()
  inputRef.value.value = 'Hello Vue3!'
  
  // 访问子组件实例并调用其方法
  childRef.value.childMethod()
}

onMounted(() => {
  // 组件挂载后可以访问 refs
  console.log(inputRef.value)
  console.log(childRef.value)
})
</script>
```

#### 2. 通过 getCurrentInstance() 访问 $refs

```vue
<template>
  <div>
    <input ref="inputField" />
    <ChildComponent ref="childRef" />
    <button @click="handleClick">操作</button>
  </div>
</template>

<script setup>
import { getCurrentInstance, onMounted } from 'vue'
import ChildComponent from './ChildComponent.vue'

// 获取当前组件实例
const instance = getCurrentInstance()

const handleClick = () => {
  // 访问DOM元素
  instance.proxy.$refs.inputField.focus()
  
  // 访问子组件实例
  instance.proxy.$refs.childRef.childMethod()
}

onMounted(() => {
  console.log(instance.proxy.$refs.inputField)
  console.log(instance.proxy.$refs.childRef)
})
</script>
```

#### 注意事项

1. `$refs` 只在组件渲染完成后填充，因此在 `mounted` 生命周期钩子中才能访问到。
2. `$refs` 是非响应式的，不应该在模板中使用它做数据绑定。
3. 避免过度使用 `$refs`，应优先考虑通过 props 和事件进行组件通信。

### 3.2 $parent 的使用

`$parent` 用于访问父组件实例，在组合式 API 中需要通过 `getCurrentInstance()` 获取当前组件实例来访问：

```vue
<!-- 子组件 -->
<template>
  <div>
    <button @click="callParentMethod">调用父组件方法</button>
  </div>
</template>

<script setup>
import { getCurrentInstance } from 'vue'

// 获取当前组件实例
const instance = getCurrentInstance()

const callParentMethod = () => {
  // 调用父组件的方法
  instance.proxy.$parent.parentMethod()
  
  // 访问父组件的数据
  console.log(instance.proxy.$parent.parentData)
}
</script>
```

#### 注意事项

1. 直接使用 `$parent` 会破坏组件的封装性，使组件难以复用和测试。
2. 官方不推荐直接依赖 `$parent`，应优先考虑通过 props 和事件进行组件通信。
3. `$parent` 的使用会使组件之间的耦合度增加，不利于维护。

## 4. provide / inject

**provide** 和 **inject** 用于实现组件间的依赖注入，无论组件层级多深，父组件都可以为所有后代组件提供数据。

### 4.1 基本用法

#### 父组件提供数据 (provide)

```vue
<!-- 父组件 -->
<template>
  <div>
    <p>父组件</p>
    <ChildComponent />
  </div>
</template>

<script setup>
import { ref, provide } from 'vue'
import ChildComponent from './ChildComponent.vue'

// 提供响应式数据
const message = ref('Hello from parent')
const count = ref(0)

// 提供方法
const updateMessage = (newMessage) => {
  message.value = newMessage
}

const incrementCount = () => {
  count.value++
}

// 使用 provide 提供数据和方法
provide('message', message)
provide('count', count)
provide('updateMessage', updateMessage)
provide('incrementCount', incrementCount)
</script>
```

#### 后代组件注入数据 (inject)

```vue
<!-- 子组件或孙组件 -->
<template>
  <div>
    <p>注入的消息: {{ message }}</p>
    <p>注入的计数: {{ count }}</p>
    <button @click="updateMessage('Updated message')">更新消息</button>
    <button @click="incrementCount">增加计数</button>
    
    <!-- 如果有更深层的组件 -->
    <GrandChildComponent />
  </div>
</template>

<script setup>
import { inject } from 'vue'
import GrandChildComponent from './GrandChildComponent.vue'

// 使用 inject 注入数据和方法
const message = inject('message')
const count = inject('count')
const updateMessage = inject('updateMessage')
const incrementCount = inject('incrementCount')
</script>
```

### 4.2 注入默认值

当注入的数据可能不存在时，可以提供默认值：

```vue
<script setup>
import { inject } from 'vue'

// 注入带默认值的数据
const theme = inject('theme', 'light')
const config = inject('config', () => ({ apiEndpoint: '/api' }), true)
</script>
```

### 4.3 注意事项

1. provide 和 inject 主要用于组件树中深层传递数据，避免了逐层传递 props 的繁琐。
2. 提供的响应式数据会保持响应性，后代组件可以响应数据变化。
3. 官方推荐尽可能将响应式数据的修改操作也一起提供出去，而不是在注入的组件中直接修改。
4. provide 和 inject 的数据传递不是响应式的，如果需要响应性需要使用 ref 或 reactive。

## 5. 插槽 (Slots)

插槽（Slots）是 Vue 组件中一种非常有用的功能，用于在父组件中向子组件传递内容。

### 5.1 默认插槽

默认插槽是 Vue 组件中最简单的插槽用法，允许我们在父组件中传递内容到子组件。

#### 子组件定义默认插槽

```vue
<!-- Card.vue -->
<template>
  <div class="card">
    <h3>卡片标题</h3>
    <div class="card-content">
      <!-- 默认插槽出口 -->
      <slot></slot>
    </div>
  </div>
</template>

<style scoped>
.card {
  border: 1px solid #ccc;
  border-radius: 4px;
  padding: 16px;
  margin: 16px 0;
}
</style>
```

#### 父组件使用默认插槽

```vue
<!-- 父组件 -->
<template>
  <div>
    <!-- 使用默认内容 -->
    <Card />
    
    <!-- 自定义内容 -->
    <Card>
      <p>这是自定义的卡片内容</p>
      <button>操作按钮</button>
    </Card>
  </div>
</template>

<script setup>
import Card from './Card.vue'
</script>
```

### 5.2 具名插槽

当组件需要多个插槽时，可以使用具名插槽来区分不同的内容区域。

#### 子组件定义具名插槽

```vue
<!-- Layout.vue -->
<template>
  <div class="layout">
    <header>
      <!-- 具名插槽：header -->
      <slot name="header"></slot>
    </header>
    
    <main>
      <!-- 默认插槽 -->
      <slot></slot>
    </main>
    
    <footer>
      <!-- 具名插槽：footer -->
      <slot name="footer"></slot>
    </footer>
  </div>
</template>
```

#### 父组件使用具名插槽

```vue
<!-- 父组件 -->
<template>
  <Layout>
    <!-- 具名插槽内容 -->
    <template #header>
      <h1>网站标题</h1>
      <nav>导航栏</nav>
    </template>
    
    <!-- 默认插槽内容 -->
    <div>
      <p>主要内容区域</p>
    </div>
    
    <!-- 具名插槽内容 -->
    <template #footer>
      <p>版权所有 © 2023</p>
    </template>
  </Layout>
</template>

<script setup>
import Layout from './Layout.vue'
</script>
```

### 5.3 作用域插槽

作用域插槽允许子组件向父组件传递数据，使得父组件可以根据子组件的数据来定制渲染内容。

#### 子组件提供数据

```vue
<!-- List.vue -->
<template>
  <ul>
    <li v-for="(item, index) in items" :key="item.id">
      <!-- 作用域插槽，传递数据给父组件 -->
      <slot :item="item" :index="index"></slot>
    </li>
  </ul>
</template>

<script setup>
import { ref } from 'vue'

const items = ref([
  { id: 1, name: '项目1', description: '描述1' },
  { id: 2, name: '项目2', description: '描述2' },
  { id: 3, name: '项目3', description: '描述3' }
])
</script>
```

#### 父组件使用作用域插槽

```vue
<!-- 父组件 -->
<template>
  <div>
    <!-- 基本使用 -->
    <List :items="listItems">
      <template #default="{ item, index }">
        <strong>{{ index + 1 }}. {{ item.name }}</strong>
        <p>{{ item.description }}</p>
      </template>
    </List>
    
    <!-- 自定义样式 -->
    <List :items="listItems">
      <template #default="{ item }">
        <div class="custom-item">
          <span class="item-name">{{ item.name }}</span>
          <span class="item-desc">{{ item.description }}</span>
        </div>
      </template>
    </List>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import List from './List.vue'

const listItems = ref([
  { id: 1, name: 'Vue.js', description: '前端框架' },
  { id: 2, name: 'React', description: '前端库' },
  { id: 3, name: 'Angular', description: '前端框架' }
])
</script>

<style scoped>
.custom-item {
  display: flex;
  justify-content: space-between;
  padding: 8px;
  border: 1px solid #eee;
  margin: 4px 0;
}

.item-name {
  font-weight: bold;
}

.item-desc {
  color: #666;
}
</style>
```

### 5.4 插槽注意事项

1. 插槽内容可以访问父组件的数据作用域，但无法访问子组件的数据。
2. 可以为插槽设置默认内容，在父组件未提供内容时显示。
3. 具名插槽通过 `name` 属性区分，未命名的插槽默认名为 "default"。
4. 作用域插槽通过 `v-slot` 指令接收子组件传递的数据。
5. `v-slot` 有简写形式 `#`，例如 `v-slot:header` 可以简写为 `#header`。
