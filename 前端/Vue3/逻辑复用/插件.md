Vue 3 的插件（Plugin）是一种为 Vue 应用添加全局功能的机制。官方生态中的 Vue Router、Pinia、Element Plus 等库，本质上都是基于这套机制构建的。

在 Vue 3 中，插件的形式非常简单：它可以是一个**带有 `install` 方法的对象**，或者直接是一个**安装函数**。
```js
// 形式 1：对象形式（推荐，可扩展性强）
export const myPlugin = {
  install(app, options) {
    // 插件逻辑
  }
}

// 形式 2：函数形式（轻量级）
export function myPlugin(app, options) {
  // 插件逻辑
}
```
