**v-bind**: `:id=xxx` 
- 单向绑定：意思是`xxx`变化会传递给`id`,但是`id`变化不会传递给`xxx`
- 绑定语法通常写在元素上比如`<div :id="xx">`，如果id不是元素的标注属性，那么就会作为自定义属性，渲染时为`<div id="xxx">` 但是如果想要实现自定义属性推荐`<div :data-xxx="xx"`这种写法
- 如果绑定是写在组件上的，且不是作为Props(在defineProps中没有定义)，那么就会把该属性自动放在组件中的根元素上，比如是`div`,那么就是`<div name="xxx">`,多个根元素会有警告


**v-model**:双向绑定

# 透传属性
**透传 Attribute（Fallthrough Attributes）** 指的是传递给组件、但**没有被该组件的 `props` 或 `emits` 显式声明**的属性或事件监听器（最常见的是 `class`、`style`、`id`、`data-*` 以及 `@click` 等原生事件）。

### 1. 默认透传行为（单根节点组件）
当组件只有一个根元素时，所有透传的属性会自动添加到该根元素上。

#### 属性合并与覆盖规则

- **`class` 与 `style`（合并）**：父组件传入的值会与子组件根元素现有的 `class` / `style` 自动合并拼在一起。
- **普通属性（覆盖）**：如 `id`、`type`，父组件传入的值会直接覆盖子组件根元素上的同名属性。
- **事件监听器（`v-on`）**：父组件传递的 `@click` 等事件会直接绑定到子组件的根元素上，点击根元素即可触发父组件方法。

- 这里会将属性透传的根元素上
```vue 
<!-- 父组件 Parent.vue -->
<template>
  <CustomButton class="parent-class" id="submit-btn" @click="handleClick">
    提交
  </CustomButton>
</template>
```

### 2. 禁用透传与精准指定：`inheritAttrs: false`
- 
```vue 
<!-- 子组件 MyInput.vue -->
<script setup lang="ts">
// 1. 声明 Props（被声明的属性不会进入 $attrs）
defineProps<{
  label: string
}>()

// 2. 禁用根节点自动继承透传属性
defineOptions({
  inheritAttrs: false
})
</script>

<template>
  <div class="input-wrapper">
    <label>{{ label }}</label>
    
    <!-- 3. 将所有未声明的属性（如 placeholder, type, @input, class 等）透传给原生 input -->
    <input v-bind="$attrs" />
  </div>
</template>
```

### 3. 在 `<script>` 中访问透传属性：`useAttrs`
**注意**：`attrs` 并不是响应式的 `ref`，它的属性虽然会随父组件更新而更新，但不建议对 `attrs` 做解构，如果需要响应性跟踪建议使用 `computed(() => attrs.xxx)`。

```vue 
<script setup lang="ts">
import { useAttrs } from 'vue'

const attrs = useAttrs()

// attrs 是一个包含所有透传属性的响应式对象
console.log(attrs.class)
console.log(attrs.placeholder)
console.log(attrs.onClick) // 事件监听器以 onXxx 命名存在
</script>
```
- 将`attrs`分类
```ts
const attrs = useAttrs()

// 2. 提取需要挂在外层 div 上的属性（例如 class、style）
const rootAttrs = computed(() => ({
  class: attrs.class,
  style: attrs.style
}))

// 3. 提取需要挂在内部 input 上的属性（排除 class 和 style 后的其余属性）
const inputAttrs = computed(() => {
  const { class: _, style: __, ...rest } = attrs
  return rest
})

```
