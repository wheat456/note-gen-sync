## \<a>
- `href` 
	- 跳转`id` `<a href="#C4">跳转到第四章</a>`
	- `<a href="html_demo.html#C4">跳转到第四章</a>`
	- 跳转`url` `<a href="https://www.w3school.com.cn/">访问 W3School.com.cn！</a>`
- `target` 默认情况下，链接的页面将在当前浏览器窗口中显示。要改变这一点，必须为链接指定另一个目标。
	- - `_self` - 默认值。在点击链接的同一窗口/标签页中打开文档
	- `_blank` - 在新窗口或标签页中打开文档
	- `_parent` - 在父框架中打开文档
	- `_top` - 在窗口的整个主体中打开文档
- 用图片作为链接
```html
<a href="index.asp">
<img src="smiley.gif" alt="HTML 教程" style="width:64px;height:64px;">
</a>
```
- 按钮作为link
```html
<button onclick="document.location='index.asp'">HTML 教程</button>
```
- `title`
```html
<a href="https://www.w3school.com.cn/html/" title="转到 W3School 的 HTML 部分">访问我们的 HTML 教程</a>
```
