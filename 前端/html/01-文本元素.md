# 文本元素

## 标题与段落

```html
<h1>标题</h1>
<p>块级文本，独占一行</p>
<span>行内文本，不独占一行</span>
```

## 文本修饰符

```html
<q>引用，自动打上 ""</q>
<hr />   水平分割线
<br />   换行符
<em>强调文本</em>
<i>斜体</i>
<b>加粗</b>
<strong>加粗（语义更强，表示重要性）</strong>
<small>字号变小</small>
<del>划线，表示已删除</del>
<ins>配合 del 使用，表示新插入的文本</ins>
<s>删除线，表示已失效</s>
<kbd>键盘按键</kbd>
<mark>高亮文本</mark>
<u>下划线</u>
<sub>下标</sub>
<sup>上标</sup>
<code>将文本视作代码</code>
<p>我们的聚会定在 <time datetime="2026-05-20">5月20号</time>。</p> `time` 标签：人看的是标签内容，机器读的是 `datetime` 属性。
```
