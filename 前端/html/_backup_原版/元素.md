# 文本
```html
<h1/> 标题
<p/>  块级文本，会占一行
<span/> 行内文本，不会占一行




```

## 文本修饰符
```html
<q/> 将一段话打上“”，就是引用
<hr/> 水平分割线
<br/> 代表一个换行符
<em/> 表示强调的文本
<i/> 斜体文本
<b/> 加粗文本
<strong/> 加粗文本
<small/> 将字变小
<del/> 划线，表示修改
<ins/> 配合del使用，表示是新插入的文本,比如先用del划线，然后用ins添加
<s/> 删除线，表示失效
<kbd/> 描述键盘上的符号
<mark/> 高亮文本
<u/> 下划线
<sub/> 文字下标
<sup/> 上标
<code/> 就是将文本视作代码
```
## 文字

`wbr`一个单词或长字符串，但如果空间不够，你可以在这里换行
`var` 表示数学或者代码中变量



`section` 用于分节，没有视觉效果


**`<details>`**：**容器**。它负责控制内容的显示与隐藏状态。
 - **`<summary>`**：**按钮/标题**。它是用户点击的区域。如果不写它，浏览器会默认显示“详细信息”（或 "Details"）作为标题。
```html
<details>
  <summary>
    I have keys but no doors. I have space but no room. You can enter but can't
    leave. What am I?
  </summary>
  A keyboard.
</details>
```

`time` **datetime**是机器读的
```html
<p>我们的聚会定在 <time datetime="2026-05-20">5月20号</time>。</p>
```

### **search**
```html
<header>
  <h1>我的博客</h1>
  <search>
    <form action="/search">
      <label for="query">搜索文章：</label>
      <input type="search" id="query" name="q" placeholder="输入关键字...">
      <button type="submit">点击搜索</button>
    </form>
  </search>
</header>
```
