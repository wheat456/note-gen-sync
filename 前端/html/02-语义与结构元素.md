# 语义与结构元素

## 分区

- `section`：用于分节，本身没有视觉效果。
- `nav`：导航栏。

## 折叠面板 details / summary

- `<details>`：**容器**，控制内容的显示与隐藏。
- `<summary>`：**标题/按钮**，用户点击的区域。不写它时浏览器默认显示"详细信息"（Details）。

```html
<details>
  <summary>
    I have keys but no doors. I have space but no room. You can enter but can't
    leave. What am I?
  </summary>
  A keyboard.
</details>
```

## 对话框 dialog

`dialog` 定义对话框。

## 输出样式 samp

`samp`：模拟终端/程序输出的样式。

## 列表

```html
<ol>  <!-- 有序列表 -->
  <li>列表项</li>
</ol>

<ul>  <!-- 无序列表 -->
  <li>列表项</li>
</ul>
```

> 注意：`li` 是列表项本身，有序/无序由外层的 `ol` / `ul` 决定。
