# 表格

![[table.png]]

```html
<table>
  <caption>Council budget (in £) 2018</caption>
  <thead>
    <tr>
      <th scope="col">Items</th>
      <th scope="col">Expenditure</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Donuts</th>
      <td>3,000</td>
    </tr>
    <tr>
      <th scope="row">Stationery</th>
      <td>18,000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Totals</th>
      <td>21,000</td>
    </tr>
  </tfoot>
</table>
```

## 结构说明

| 标签 | 作用 |
|---|---|
| `caption` | 表格标题 |
| `thead` | 表头区域 |
| `tbody` | 表格主体 |
| `tfoot` | 表尾（如合计行） |
| `tr` | 一行 |
| `th` | 表头单元格，`scope="col"` 列头 / `scope="row"` 行头 |
| `td` | 普通单元格 |
