# 表单

## form

> [!NOTE] 对内部的影响
> - **form 内部**：写 `<button>按钮</button>`（未指定 `type`），浏览器默认将其当做 `type="submit"` 处理。点击后会立即触发表单提交并**刷新页面**。
> - **form 外部**：单独的 `<button>` 没有任何默认提交动作
> - **避坑方式**：在 form 内部如果只想用按钮绑定普通 JS 点击事件，必须显式写为 `<button type="button">`。
> - **有 `name`**：`<input name="user" value="Tom">` $\rightarrow$ 会被打包发送为 `user=Tom`
> - **无 `name`**：`<input value="Tom">` $\rightarrow$ 无论输入什么，**完全被忽略**，不会被发送。
> - 回车键（Enter）自动提交
```html
<form action="/search" method="get"></form>
```
- 默认是向服务器发送请求
- `method="dialog"`：仅用于 `<dialog>` 弹窗内关闭对话框，不发网络请求
- 只要内部的元素有`name`且不被`disabled` 就可以将消息收集
- 阻止原生提交
```js
const form = document.querySelector('#userForm');
form.addEventListener('submit', function(event)
```

## input

通过 `type` 区分类型：

| type | 说明 | | type | 说明 |
|---|---|---|---|---|
| `text` | 文本 | | `checkbox` | 复选框 |
| `password` | 密码 | | `radio` | 单选框 |
| `email` | 邮箱 | | `file` | 文件 |
| `number` | 数字 | | `hidden` | 隐藏 |
| `tel` | 电话 | | `image` | 图片按钮 |
| `url` | 网址 | | `color` | 取色器 |
| `date` | 日期 | | `range` | 滑块 |
| `time` | 时间 | | `search` | 搜索框 |
| `month` | 月 | | `submit` | 提交按钮 |
| `week` | 周 | | `reset` | 重置按钮 |
| `datetime-local` | 本地日期时间 | | `button` | 普通按钮 |

## select 下拉框

```html
<select name="pets" id="pet-select">
  <option value="">--Please choose an option--</option>
  <option value="dog">Dog</option>
  <option value="cat">Cat</option>
</select>
```

## textarea 多行文本

```html
<textarea id="story" name="story" rows="5" cols="33">
It was a dark and stormy night...
</textarea>
```

## button 按钮

三种 `type`：
- **submit**：将表单数据发送到服务器，并**刷新页面**（默认值）。
- **reset**：将表单内所有输入控件**恢复到初始值**。
- **button**：普通按钮，无默认行为。
## label 与 for

```html
<label for="query">搜索文章：</label>
<input type="search" id="query" name="q" placeholder="输入关键字...">
```

`label` 的 `for` 绑定组件的 `id`，点击 label 即可聚焦到该组件。见 [[06-常用属性]]。

## search 搜索区域

```html
<header>
  <h1>我的博客</h1>
  <search>
    <form action="/search">
      <label for="query">搜索文章：</label>
      <input type="search" id="query" name="q" placeholder="输入关键字...">
      <button type="submit">点击搜索</button>
    </form>
  </search>
</header>
```
