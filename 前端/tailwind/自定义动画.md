**1. 通过 `@theme` 定义全局动画（推荐）**

在项目的主 CSS 入口文件（如 `globals.css` 或 `app.css`）中，使用 `@theme` 声明 `--animate-<名称>` 变量，并在其中嵌入 `@keyframes`：
``` css
@import "tailwindcss";

@theme {
  /* 定义动画属性及关键帧 */
  --animate-wiggle: wiggle 1s ease-in-out infinite;
  /* 
  -animate-wiggle 其中wiggle动画名
  wiggle 动画名
  1s 周期
  ease-in-out 缓动函数
  infinite 播放次数
  */
  @keyframes wiggle {
    0%, 100% { transform: rotate(-3deg); }
    50% { transform: rotate(3deg); }
  }
}
```

在 HTML / 组件模板中，Tailwind 会根据变量名自动生成 `animate-wiggle` 类名：

``` html
<div class="animate-wiggle">
  摇摆的内容
</div>
```

**2. 使用任意值语法（单次即席动画）**

如果某个动画仅在单一组件中使用，不想注册到全局主题，可以直接在类名中使用方括号定义任意值：

```html
<!-- 直接传入原生 animation 简写属性（空格用下划线 _ 替代） -->
<div class="animate-[spin_2s_linear_infinite]">
  即席动画
</div>

<!-- 引用外部或已存在的 CSS 变量 -->
<div class="animate-(--my-custom-animation)">
  变量动画
</div>
```

**3. 使用 v4 新增的 `@utility` 指令**

如果需要封装更复杂的动画逻辑（例如附加特定的 `animation-fill-mode` 或复合样式），可以使用 Tailwind v4 的 `@utility` 指令：

```css
@utility animate-fade-in {
  animation: fadeIn 300ms cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```
