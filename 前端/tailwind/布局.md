# flex
**方向**：**单行 or 单列**（一维）

# grid
**方向**：**行 + 列**（二维）
justify是水平
rem 绝对单位，1rem=16px

均分两列
```css
grid grid-cols-2
```

按比例
`grid-cols-\[1fr_2fr]` ：1：2的比例



- `aspect-ratio` 工具类，用于直接控制元素的宽高比
	- **常用预设类名**
	- `aspect-square`：宽高比为 **1:1**（正方形，`aspect-ratio: 1 / 1;`）
	- `aspect-video`：宽高比为 **16:9**（标准视频比例，`aspect-ratio: 16 / 9;`）
	- `aspect-auto`：恢复默认比例（`aspect-ratio: auto;`）
	**自定义任意比例**
	使用中括号语法 `aspect-[宽/高]` 定义任意尺寸：
	- `aspect-[4/3]`：4:3 比例
	- `aspect-[2/1]`：2:1 超宽比例
	- `aspect-[9/16]`：9:16 竖屏短视频比例
- columns-* 等分多列
