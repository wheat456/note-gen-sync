```css
选择器 {
    属性: 值;
    属性: 值;
}
```

- **元素选择器**： 直接写标签名，如 `p { }` 控制所有段落。
- **类选择器**（最常用）：​ 以 `.` 开头，如 `.title { }`，HTML 中对应 `class="title"`。
- **ID 选择器**：以 `#` 开头，如 `#header { }`，HTML 中对应 `id="header"`（一个页面通常唯一）。
- **通配符选择器**：​ `*` 代表所有元素，常用于清除默认边距：`* { margin: 0; padding: 0; }`

- **组合选择器**：上面的选择器组合起来，中间用空格隔开`.container p{}`
- **子元素选择器** : 只选中**直接子元素**。`ul > li{}`
- **相邻兄弟选择器**: 选中**紧接在后面的兄弟元素**。 `h1 + p{}`
- 通用兄弟选择器 `~` `h1 ~ p{}`
## 组合选择器

| **选择器** | **符号**  | **含义**            |
| ------- | ------- | ----------------- |
| 后代选择器   | `A B`   | A 里面的所有 B         |
| 子元素选择器  | `A > B` | A 的**直接子元素**​ B   |
| 相邻兄弟选择器 | `A + B` | A **紧挨着**的下一个兄弟 B |
| 通用兄弟选择器 | `A ~ B` | A **后面所有**兄弟 B    |
| 并集选择器   | `A, B`  | 同时选中 A 和 B        |

## 属性选择器
- 存在属性，只要元素有这属性就会被应用
```css
[disabled] {
  opacity: 0.5;
}
```
- 精确匹配 其中`type`就是属性
```css
[type="text"] {
  border: 1px solid #ccc;
}
```
- 模糊匹配
```css
[class^="btn"]   /* 以 btn 开头 */
[class$="primary"] /* 以 primary 结尾 */
[class*="box"]   /* 包含 box */
```
