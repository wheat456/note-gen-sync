```css
选择器 {
    属性: 值;
    属性: 值;
}
```

- **元素选择器**： 直接写标签名，如 `p { }` 控制所有段落。
- **类选择器**（最常用）：​ 以 `.` 开头，如 `.title { }`，HTML 中对应 `class="title"`。
- **ID 选择器**：以 `#` 开头，如 `#header { }`，HTML 中对应 `id="header"`（一个页面通常唯一）。
- **通配符选择器**：​ `*` 代表所有元素，常用于清除默认边距：`* { margin: 0; padding: 0; }`
- **组合选择器**：上面的选择器组合起来，中间用空格隔开`.container p{}`
- **子元素选择器** : 只选中**直接子元素**。`ul > li{}`
- **相邻兄弟选择器**: 选中**紧接在后面的兄弟元素**。 `h1 + p{}`
- 通用兄弟选择器 `~` `h1 ~ p{}`
## 组合选择器

| **选择器** | **符号**  | **含义**            |
| ------- | ------- | ----------------- |
| 后代选择器   | `A B`   | A 里面的所有 B         |
| 子元素选择器  | `A > B` | A 的**直接子元素**​ B   |
| 相邻兄弟选择器 | `A + B` | A **紧挨着**的下一个兄弟 B |
| 通用兄弟选择器 | `A ~ B` | A **后面所有**兄弟 B    |
| 并集选择器   | `A, B`  | 同时选中 A 和 B        |

## 属性选择器
- 存在属性，只要元素有这属性就会被应用
```css
[disabled] {
  opacity: 0.5;
}
```
- 精确匹配 其中`type`就是属性
```css
[type="text"] {
  border: 1px solid #ccc;
}
```
- 模糊匹配
```css
[class^="btn"]   /* 以 btn 开头 */
[class$="primary"] /* 以 primary 结尾 */
[class*="box"]   /* 包含 box */
```

## 伪元素选择器
### 常见的 CSS 伪元素
- **`::before`** 在选定元素的内容**最前面**插入生成的内容。必须配合 `content` 属性使用。
```css
h2::before { content: "★ "; color: red; }
```
- **`::after`** 在选定元素的内容**最后面**插入生成的内容。必须配合 `content` 属性使用
```css
blockquote::after { content: " ”"; font-size: 1.5em; color: #888; }
```
- **`::first-letter`** 选择文本块的**第一个字母/字符**（常用于首字下沉排版）
- **`::first-line`** 选择文本块的**第一行**（第一行长度会随窗口大小改变而自动适应）。
- **`::selection`** 匹配用户在页面上**高亮/选中**的文本部分（可以修改选中时的背景色和文字颜色）
```css
::selection { background-color: #ffb703; color: #000; }
```
- **`::placeholder`** 匹配表单输入框（`<input>` 或 `<textarea>`）中的**占位符提示文字**。


## 组件CSS
### 表格css

```css
table {
  width: 100%;
  border-collapse: collapse; /* 合并边框 */
}

th, td {
  border: 1px solid #ddd;   /* 设置简洁的边框 */
  padding: 8px 12px;        /* 增加内边距 */
  text-align: left;         /* 文字对齐 */
}
```
### 链接css
- :link 点击之前的状态
- :visited 访问之后的状态
- :hover 悬停
- :active 点击时的状态

### 无须列表
```css
list-style-type:square /*修改列表前的圆点*/
list-style-image 修改成图片
list-style-position 改变缩进
list-style 设置上面所有属性
:first-child 第一个元素
:last-child 最后一个元素
:nth-child() 作用于第几个元素 /* 2n even odd*/ 
```
