# transition
`transition: 属性 时间 速度 延迟;`
- 属性比如是width,hight 等
- 时间比如是1S
- 速度就是缓动曲线
- 延迟就是1S
### 多个属性
```css
.box {
  transition:
    width 1s,
    height 1s,
    background 0.5s;
}
```

## 缓动函数

| 函数          | 作用                    |
| ----------- | --------------------- |
| ease        | 默认，**先快后慢**，开始加速，末尾减速 |
| `linear`    | 匀速                    |
| `ease‑in`   | 先慢后快                  |
| ease‑out    | 先快后慢                  |
| ease‑in‑out | 两头慢，中间快               |


# @keyframes + animation

- 定义，其中move就是动画名

```css
@keyframes move {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(200px);
  }
}
```

- 使用
```css 
.box {
  animation: move 2s;
}
```

- 百分比
```css
@keyframes move {
  0% {
    transform: translateX(0);
  }
  50% {
    transform: translateX(100px);
  }
  100% {
    transform: translateX(200px);
  }
}
```

| 属性<br>                      | 作用    |
| --------------------------- | ----- |
| `animation-name`            | 动画名   |
| `animation-duration`        | 时长    |
| `animation-timing-function` | 速度    |
| `animation-delay`           | 延迟    |
| `animation-iteration-count` | 次数    |
| `animation-direction`       | 方向    |
| `animation-fill-mode`       | 结束状态  |
| `animation-play-state`      | 播放/暂停 |
# 2D 转换
```css

transform: translate(50px,100px);/*是从左边元素移动50个像素，并从顶部移动100像素*/
transform: rotate(30deg);
transform: scale(2,4);
transform: skew(30deg,20deg); /*X轴(水平方向)倾斜。 Y轴(垂直方向)倾斜*/
transform:matrix(0.866,0.5,-0.5,0.866,0,0); /*matrix 方法有六个参数，包含旋转，缩放，移动（平移）和倾斜功能。*/
```
