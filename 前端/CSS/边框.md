`box-shadow: [inset] [X軸] [Y軸] [模糊距離] [擴散距離] [顏色];`
```css
box-shadow: 10px 10px 5px #888888;
```

| **参数**          | **数值**    | **說明**                                    |
| --------------- | --------- | ----------------------------------------- |
| **水平偏移 (X軸)**   | `10px`    | 陰影向**右**移動 10px（若為負值，如 `-10px`，則向左移）      |
| **垂直偏移 (Y軸)**   | `10px`    | 陰影向**下**移動 10px（若為負值，如 `-10px`，則向上移）      |
| **模糊距離 (Blur)** | `5px`     | 陰影模糊的程度，數值越大越模糊，`0px` 為清晰硬邊               |
| **陰影顏色**        | `#888888` | 陰影的顏色（灰色），也支援 `rgba(0, 0, 0, 0.3)` 等透明度設定 |
