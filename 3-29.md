在写控件模板时
1. 首先是在样式中用setter指定类型为template，而不是其他的什么contenttemplate
2. 在setter 的值中写contro模板，因为是在写结构。
3. 然后在结构中放置自定义的组件
4. 如果要设置trigger，就设置在controltemplate的triggers中，当然也可以具体设置在自定义组件的style中，不过这样某些触发条件不能达成，所以大部分情况还是在控件模板的trigger中
5. 在这个trigger 如果想要对自定义组件进行属性设置，那么就要给自定义组件设置一个名字，用targetName来指定

EventTrigger 也是在trigger 中，用来控制动画的



`<AccessText` 是下划线，相当于按下alt后加一个键就能触发

```xml
<Button>
    <AccessText Text="_点击我"/>
</Button>
```

AccessKeyManager  用来 **“监听并拦截快捷键按下动作”** 的。
当按下快捷键时，有默认的动作，但是不想执行默认的动作就可以用这个给重写
```xml

<Border Background="LightGray" Padding="10"
        AccessKeyManager.AccessKeyPressed="Border_AccessKeyPressed">
    <AccessText Text="按下 Alt+C 触发自定义事件(_C)" />
</Border>
```

**ContentControl** 是一个“容器插槽”
通过VM的不同显示不同的内容
```xml
<ContentControl content={binding VM}
```


**DataTemplate**
1. 定义一个VM 
2. 在resources 中声明DataTemplate，将VM或者M绑定到数据模板上
```xml
<Window.Resources>
    <DataTemplate DataType="{x:Type local:User}">
	    这里面就和平常写组件一样，什么button text等，需要绑定就绑定到数据类型上的VM
    </DataTemplate>
</Window.Resources>
```
3. 然后就可以在contentcontrol中使用

listbox ,ItemsSource 绑定的是数据源，比如一个集合
ItemTemplate 接受的是一个`DataTemplate` ,可以在resource中写，也可以就在listbox中写
```xml
<ListBox ItemsSource="{Binding UserList}" ItemTemplate="{StaticResource MyUserTemplate}" />
```

datagrid 就是一张表格，不过是动态的，数据变，表格中的内容也变
1. 准备一个数据对象，比如 `ObservableCollection<T>`
2. 在界面上放置datagrid，并关联数据
```xml
<DataGrid ItemsSource="{Binding UserList}" />
```
3. 可以自动写列或者手动写列
```xml
<DataGrid ItemsSource="{Binding Users}" AutoGenerateColumns="True" />
```
手动写列
```xml
<DataGrid ItemsSource="{Binding Users}" AutoGenerateColumns="False">
    <DataGrid.Columns>
        <DataGridTextColumn Header="用户名" Binding="{Binding Name}" Width="*" />
        
        <DataGridTemplateColumn Header="权限状态">
            <DataGridTemplateColumn.CellTemplate>
                <DataTemplate>
                    <Ellipse Width="10" Height="10" 
                             Fill="{Binding IsAdmin, Converter={StaticResource AdminToColorConverter}}" />
                </DataTemplate>
            </DataGridTemplateColumn.CellTemplate>
        </DataGridTemplateColumn>
    </DataGrid.Columns>
</DataGrid>
```

wpf 引入字体文件
1. 创建一个Resources文件夹，里面创建一个Font文件夹，里面放置字体文件。如果要引入
2. 其中YourProjectName就是项目名，MyFont就是双击字体文件中，显示的字体名
```xml
<Application.Resources>
    <FontFamily x:Key="CustomFontFamily">/YourProjectName;component/Resources/Font/#MyFont</FontFamily>
</Application.Resources>
```
2. 设置全局字体
```xml
        <FontFamily x:Key="GlobalFont">/wpftest;component/Resources/Fonts/#Inter 28pt
        </FontFamily>
        <Style TargetType="TextBlock">
            <Setter Property="FontFamily" Value="{StaticResource GlobalFont}" />
        </Style>
        <Style TargetType="Control">
            <Setter Property="FontFamily" Value="{StaticResource GlobalFont}" />
        </Style>
```
