

# 运算符

## ??
如果左侧的表达式结果为 `null`，则返回右侧表达式的值；否则返回左侧表达式的值。
```dart
String name = lei ?? '默认' // 如果lei 为null则为‘默认’
```
## ??=
仅当变量当前的值为 `null` 时，才将右侧表达式的值赋给该变量。如果变量已有非空值，则保持不变。
```dart
message ??= '默认消息'; 如果message 为空就赋值 '默认消息'
```
## ?.
```dart
inal length = text?.length;// 如果text为null 那就赋值null,否则调用length
```

## ！
会抛出异常
```dart
final result = text!.toUpperCase();
```
## ??..
如果为空就跳过
```dart
list?..add(1)..remove(0);
```
### ...？
不为空就插入，否则就不插入
```dart 
`List<int>? numbers;` `final all = [1, 2, ...? numbers];`
```

# 复合数据
| **特征**   | **List (列表)**                        | **Set (集合)**                            |
| -------- | ------------------------------------ | --------------------------------------- |
| **定义符号** | 方括号 `[]`                             | 花括号 `{}` 或 `Set()`                      |
| **顺序**   | **有顺序 (Ordered)**。元素按插入顺序排列。         | **无顺序 (Unordered)**。元素没有固定的索引位置。        |
| **重复性**  | **允许重复元素**。                          | **不允许重复元素**。所有元素必须是唯一的。                 |
| **访问方式** | 通过 **索引 (Index)** 访问：`list[0]`       | 通过 **值** 检查是否存在：`set.contains('value')` |
| **常见用途** | 存储需要保持顺序或允许重复的数据，例如用户评论列表、购物车中的商品列表。 | 存储需要确保唯一性的数据，例如用户 ID 列表、标签列表。           |
