# 项目结构
#### 1. `pubspec.yaml` (核心配置文件)

这是 Dart 项目的**清单文件**，类似于 Rust 的 `Cargo.toml` 或 Node.js 的 `package.json`。它定义了项目的元数据和所有依赖关系。

```
name: my_dart_project        # 1. 项目名称
description: A sample command-line application.
version: 1.0.0               # 2. 版本号
# homepage: https://www.example.com

environment:
  sdk: '>=3.0.0 <4.0.0'      # 3. Dart SDK 兼容性约束

# ----------------- 依赖项 -----------------
dependencies:
  # 用于测试的包
  # path: ^1.8.3

# 开发依赖项 (仅用于测试、构建工具等，不包含在最终产品中)
dev_dependencies:
  lints: ^2.1.1
  test: ^1.24.0
```

#### 2. `bin/` 目录 (应用程序入口)
 该目录用于存放您的 Dart 应用程序的**可执行入口文件**。

#### 3. `lib/` 目录 (库文件/核心逻辑)
该目录用于存放 Dart 包的**核心逻辑代码**，供 `bin/` 目录下的可执行文件或其他项目导入使用。
