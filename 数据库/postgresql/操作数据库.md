`\l`列出数据库 或者`\l+`
`\c database` 连接其他数据库 `\c` 查看当前所在数据库

## 查询表
`\d person` `\d` 展示表

## 创建数据库
`create database xxx;`     `createdb xxx`

## 删除数据库
`drop database xxx;`


## 创建表
```sql
create table table_name(列名 数据类型 限制)
```

## 删除表
`drop table 名字`

# 查看表的权限
- `\dp`：此命令显示当前数据库中所有表的权限信息。
- `\dp 表名`：此命令显示指定表的权限信息。
