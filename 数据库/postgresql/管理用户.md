使用管理员登录到数据库

**用户（User）：**
- 是具有`LOGIN`属性的角色。
- 用于数据库身份验证和授权。
- 通过`CREATE ROLE ... WITH LOGIN`语句创建。
- 本质上，用户也是一种角色，只不过它具有登录能力。
**角色（Role）：**
- 可以看作是权限的容器。
- 用于组织和管理权限，简化权限分配和撤销。
- 可以作为用户组使用，方便管理一组用户的权限。
- 通过`CREATE ROLE`语句创建。
# 创建用户
`CREATE USER username WITH PASSWORD 'password';`
# 删除用户
```sql
DROP USER username;
```

# 创建角色
`CREATE ROLE read_write_role;` 名字自定义
## 带有登录的角色
```sql
CREATE ROLE username WITH LOGIN PASSWORD 'password';
```
##  **带有其他选项的角色**
替换上面的login
- `SUPERUSER`：授予超级用户权限，拥有对数据库的完全控制权（谨慎使用！）。
- `CREATEDB`：允许角色创建新的数据库。
- `CREATEROLE`：允许角色创建其他角色。
- `INHERIT`/`NOINHERIT`：控制角色是否继承其成员的权限。
- `VALID UNTIL 'timestamp'`：设置角色权限的过期时间。

# 修改用户权限
使用 `ALTER USER` 命令来修改用户的属性，例如更改密码或授予权限：

```sql
ALTER USER username WITH PASSWORD 'newpassword';
```
# 授予权限
要授予用户对数据库或表的访问权限，可以使用 `GRANT` 命令。例如，授予用户对某个数据库的连接权限：
```sql
GRANT CONNECT ON DATABASE dbname TO username;
```
1. GRANT read_write_role TO your_username;
		授予角色给用户
2. `GRANT CONNECT ON DATABASE your_database_name TO read_write_role;`
		授予权限给角色
3. `GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE your_table_name TO read_write_role;`授予对表的操作
4. `GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO read_write_role;` 所有表
## 模式权限
- **USAGE：**
    - 允许用户或角色访问模式中的对象，例如查询表、执行函数等。
- **CREATE：**
    - 允许用户或角色在模式中创建新的对象，例如表、视图、函数等。
#  撤销权限
```sql
REVOKE SELECT ON TABLE tablename FROM username;
```

## 查看所有角色信息
- 只有超级用户或具有 `pg_read_all_users` 权限的用户才能查看所有角色的信息。
- 普通用户可能只能看到他们自己拥有的或被授予的角色。

`pg_roles` 是一个系统目录，包含了关于所有角色的信息。
`SELECT rolname FROM pg_roles;`
如果想查看更多角色属性，可以添加其他列，例如：
```sql
SELECT rolname, rolsuper, rolcreaterole, rolcreatedb, rolcanlogin FROM pg_roles;
```

# 权限
- SELECT
- INSERT
- UPDATE
- DELETE
- TRUNCATE **清空表权限**
- REFERENCES **允许用户在其他表中引用这个表的主键**
- TRIGGER **允许用户在表上创建触发器（Trigger）**
- CREATE **允许用户创建表、视图、索引、函数等**。
- CONNECT **允许用户连接到数据库 但不一定能访问具体的表**
- TEMPORARY **允许用户创建临时表（`TEMP TABLE`）**，**临时表在会话结束后自动删除。**
- EXECUTE **允许用户执行存储过程（`STORED PROCEDURE`）或函数（`FUNCTION`）**
- USAGE **允许用户使用 `SCHEMA`（模式）、`SEQUENCE`（序列）、`TYPE`（自定义类型）**。

|**权限**|**作用**|**示例**|
|---|---|---|
|`SELECT`|允许用户查询数据|`GRANT SELECT ON users TO user1;`|
|`INSERT`|允许用户插入数据|`GRANT INSERT ON users TO user1;`|
|`UPDATE`|允许用户修改数据|`GRANT UPDATE ON users TO user1;`|
|`DELETE`|允许用户删除数据|`GRANT DELETE ON users TO user1;`|
|`TRUNCATE`|允许清空表数据|`GRANT TRUNCATE ON users TO user1;`|
|`REFERENCES`|允许创建外键|`GRANT REFERENCES ON users TO user1;`|
|`TRIGGER`|允许创建触发器|`GRANT TRIGGER ON users TO user1;`|
|`CREATE`|允许创建数据库对象|`GRANT CREATE ON DATABASE mydb TO user1;`|
|`CONNECT`|允许连接数据库|`GRANT CONNECT ON DATABASE mydb TO user1;`|
|`TEMPORARY`|允许创建临时表|`GRANT TEMPORARY ON DATABASE mydb TO user1;`|
|`EXECUTE`|允许执行存储过程|`GRANT EXECUTE ON FUNCTION my_func TO user1;`|
|`USAGE`|允许使用 Schema、Sequence、Type|`GRANT USAGE ON SCHEMA sales TO user1;`|

==**不同的权限可以应用到不同的数据库对象：**==

| **数据库对象**         | **可授予的权限**                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------------- |
| **表（TABLE）**      | `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE`, `REFERENCES`, `TRIGGER`, `ALL PRIVILEGES` |
| **视图（VIEW）**      | `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `ALL PRIVILEGES`                                      |
| **序列（SEQUENCE）**  | `SELECT`, `UPDATE`, `USAGE`, `ALL PRIVILEGES`                                                 |
| **模式（SCHEMA）**    | `CREATE`, `USAGE`, `ALL PRIVILEGES`                                                           |
| **数据库（DATABASE）** | `CREATE`, `CONNECT`, `TEMPORARY`, `ALL PRIVILEGES`                                            |
| **函数（FUNCTION）**  | `EXECUTE`, `ALL PRIVILEGES`                                                                   |
|                   |                                                                                               |


## 授予权限

```sql
GRANT privilege [, ...]
ON object [, ...]
TO { PUBLIC | GROUP group | username }
```
- privilege − 值可以为：SELECT，INSERT，UPDATE，DELETE， RULE，ALL。
- object − 要授予访问权限的对象名称。可能的对象有： table， view，sequence。
- PUBLIC − 表示所有用户。
- GROUP group − 为用户组授予权限。
- username − 要授予权限的用户名。PUBLIC 是代表所有用户的简短形式。
## 取消权限
```sql
REVOKE privilege [, ...]
ON object [, ...]
FROM { PUBLIC | GROUP groupname | username }
```


## 查询权限
### 查询当前数据库的所有模式

```sql
SELECT schema_name FROM information_schema.schemata;
```

### 查看某个表的权限
```sql
SELECT grantee, privilege_type FROM information_schema.role_table_grants 
WHERE table_name = 'users';

```
### 查看某个用户的数据库权限
```sql
SELECT datname AS database_name,
       pg_catalog.has_database_privilege('user1', datname, 'CONNECT') AS can_connect,
       pg_catalog.has_database_privilege('user1', datname, 'CREATE') AS can_create,
       pg_catalog.has_database_privilege('user1', datname, 'TEMPORARY') AS can_temp
FROM pg_database
WHERE datname = 'mydb';
```



| 查看用户对数据库的权限          | `SELECT * FROM information_schema.role_database_grants WHERE grantee = 'user1';`                       |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| 查看用户对特定表的权限          | `SELECT * FROM information_schema.role_table_grants WHERE table_name = 'users' AND grantee = 'user1';` |
| 查看用户对所有表的权限          | `SELECT * FROM information_schema.role_table_grants WHERE grantee = 'user1';`                          |
| 查看用户对 Schema 的权限     | `SELECT * FROM information_schema.role_schema_grants WHERE grantee = 'user1';`                         |
| 查看用户对序列（SEQUENCE）的权限 | `SELECT * FROM information_schema.role_sequence_grants WHERE grantee = 'user1';`                       |
| 查看用户是否是超级用户          | `SELECT rolname, rolsuper FROM pg_roles WHERE rolname = 'user1';`                                      |
