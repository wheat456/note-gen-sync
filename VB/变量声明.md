# Sub

- **按值传递** ：此方式下，参数是原值的一个副本，原始数据在传递过程中不会被改变，适用于不需要修改参数值的情况。
- **按引用传递** ：此方式下，传递的是参数的内存地址，这样在 `Sub` 过程中对参数的任何修改都会影响到原始数据。
```vb
Sub ModifyValue(ByVal myValue As Integer, ByRef myRefValue As String)    //byval值传递 byref 引用传递
myValue = myValue + 10    
myRefValue = myRefValue.ToUpper()
End Sub

ModifyValue(value, refValue)

```
