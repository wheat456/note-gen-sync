# 1. 控件类型选择器 (Type Selector)

```xml
<Style Selector="TextBlock">
    <Setter Property="Foreground" Value="Blue"/>
</Style>
```

# 2. 样式类选择器 (Class Selector)
```xml
<Style Selector="TextBlock.Header">
    <Setter Property="Foreground" Value="Blue"/>
</Style>
```

```xml
<TextBlock Classes="Header" Text="我是大标题" />
<TextBlock Text="我是普通正文" />
```


# 3. 名称选择器 (Name Selector)
```xml
<Style Selector="#LoginBtn">
    <Setter Property="Foreground" Value="Blue"/>
</Style>
```

# 语法
`:` 就代表是状态选择器
`.` 后面接的是`Class`
`空格` 代表什么中的什么。`<Style Selector="StackPanel Button">` `stackPanel`中的`button`
`<Style Selector="Button /template/ ContentPresenter">` 
`Button` 模板里的 `ContentPresenter`

| 类型  | 写法         | 例子                          |
| --- | ---------- | --------------------------- |
| 控件  | Button     | Button                      |
| 类   | .xxx       | Button.primary              |
| 名称  | `#xxx`     | Button#ok                   |
| 状态  | :xxx       | Button:pointerover          |
| 子孙  | 空格         | StackPanel Button           |
| 直接子 | >          | StackPanel > Button         |
| 模板  | /template/ | Button /template/ TextBlock |
| 属性  | [xxx=]     | Button[IsEnabled=true]      |

## 状态
只能跟在这几个的后面
-  `Button:pointerover`
- `.MyClass:pressed`Avalonia
- `#xxName:focus`Avalonia

# 类
`Selector=".MyClass"` 可以这样写

## 子孙
这些东西能产生关系，是因为在组件布局的关系，比如父组件有个类，子组件有个`#xxx`
子孙关系（空格 / >）**两边都可以写**：
- 控件类型
- 类 `.xxx`
- ID `#xxx`
- 伪类 `:xxx`

- **空格 = 所有后代**

    ```
    Panel Button
    ```
    Panel 里面**所有层级**的 Button 都生效
- **> = 直接子元素**

    ```
    Panel > Button
    ```
    只有 Panel **直接第一层**的 Button 生效
- **, = 多个选择器共用样式**
    
    ```
    Button, TextBox
    ```
    Button 和 TextBox 都生效
- **连写 = 同时满足**

    ```
    Button.MyClass#myId:pointerover
    ```
    类型 + 类 + ID + 伪类 同时匹配
