# 行为设计模式

## 责任链模式
1. 首先，构建一个处理系统，这个系统拥有第一个持有第一个处理者的引用，然后提供一种方法来构建一条责任链
```cs
Class ResSystem{
	// 第一个处理者
	Hander _handler1;
	ResSystem(){
	 _handler1=new Handler1()
	 // 设置第一个处理者的下一个处理者是谁
	 _handler1.setSuccessor(Handler2)
	 Handler2.setSuccessor(Handler3)
	 
	}
	
	// 处理函数
	
	void handle(){
		_handler1.handle();
	}
	
}
```
2. 创建处理者，拥有一个后继者字段
```cs
Class Hander1{
	// Handler是接口或基类的类型
	Handler _successor;
	
	// 如果本身处理不了就调用后继者的处理函数
	void handle(){
		
		
		// 如果处理不了就调用后继者
		
		// 如果没有后继者就直接返回
		
		//如果能处理就返回结果
	}
	
	// 设置后继者的方法
	void setSuccessor(){
	
	}
}

```

- 就是在`构建方法`中会返回`builder`本身
```cs

		// 这里有一些需要设置的字段
```

### 步骤构建者
1. 让builder 实现多个不同的接口比如A,B,C。A接口中返回B接口类型，B接口中返回C接口类型，最后一个接口实现build方法
2. 这样就让调用顺序固定
```cs
	class Builder:IA,IB，IC{
		// 这里有一些需要设置的字段
		---------------------省略----------
		// 这里是一些设置方法
		IB setName(){
		
		}
		IC setAge(){
		
		}
		builder retBuild(){
		
		}
		
		// 返回产品实例
		Product build(){
			// 这里的name,age builder当中的字段
			return new Product(name,age)
		}
		
	  interface IA{
		  IB setName(){
		  }
	  }
	  interface IB{
		  IC setAge(){
		  }
	  }
	  interface IC{
		  Builder retBuild(){
		  }
	  }
	
	}
	
	
```
