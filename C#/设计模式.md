# 行为设计模式

## 责任链模式
1. 首先，构建一个处理系统，这个系统拥有第一个持有第一个处理者的引用，然后提供一种方法来构建一条责任链
```cs
Class ResSystem{
	// 第一个处理者
	Hander _handler1;
	ResSystem(){
	 _handler1=new Handler1()
	 // 设置第一个处理者的下一个处理者是谁
	 _handler1.setSuccessor(Handler2)
	 Handler2.setSuccessor(Handler3)
	 
	}
	
	// 处理函数
	
	void handle(){
		_handler1.handle();
	}
	
}
```
2. 创建处理者，拥有一个后继者字段
```cs
Class Hander1{
	// Handler是接口或基类的类型
	Handler _successor;
	
	// 如果本身处理不了就调用后继者的处理函数
	void handle(){
		
		
		// 如果处理不了就调用后继者
		
		// 如果没有后继者就直接返回
		
		//如果能处理就返回结果
	}
	
	// 设置后继者的方法
	void setSuccessor(){
	
	}
}

```
