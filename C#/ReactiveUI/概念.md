在反应式编程中，可观察对象Observable就是**一个“会随时间不断推送值的数据流”**
来源为：

| 来源   | 示例                         |
| ---- | -------------------------- |
| 属性   | `WhenAnyValue`             |
| 命令   | `ReactiveCommand`          |
| 外部事件 | Timer / HTTP / FileWatcher |

`.Subscribe` 的作用是告诉程序：“当流中产生了一个新数据时，请执行这段代码。”
`.Select` 通常用于将 ViewModel 的原始数据转换成另一种数据
