
# 动态视图
```cs
	this.WhenActivated(disposable =>
        {
            // 将 ViewModel 的 Items 集合绑定到 ListBox 的 ItemsSource
            this.OneWayBind(ViewModel,
                vm => vm.Items,
                v => v.MyListBox.ItemsSource)
                .DisposeWith(disposable);
        });
```
视图模板中的的子项绑定，直接在xaml绑定字段
