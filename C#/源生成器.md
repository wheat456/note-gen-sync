# 相关概念
## 语法树（SyntaxTree）
就是一段有规则符号组成，没有实际意义比如public 就是public 没有什么其他的意思
```cs
public class xx{
}
```
## 符号 (Symbol)

带有元数据的一个语法树节点，比如 xx ,可以查到其是一个类，这个类的修饰符是什么
## 语义模型 （Semantic Model）

可以将语法树的节点（是一个块，比如是类，或是方法，或是条件判断，或是赋值语句），转换为符号

# 创建文件
建立一个源生成器文件,用`[Generator]` 标记
- 这个增量生成器只能==生成代码==不能修改
```cs
[Generator] 
public class MySourceGenerator : IIncrementalGenerator
```


# 创建属性
1. 新建立一个**属性**文件，命名为**xxxAttribute**
		比如**PersonAttribute:Attribute**
```cs
using System; [AttributeUsage(AttributeTargets.Class)] 
public class MyAutoGenAttribute : Attribute { }
```
2. 在里面直接**Attribute** 使用代码片段**生成模板**
	1. **AttributeTargets.All**
		1. 限定属性的作用类型
	2. **AllowMultiple = true/false**
		1. 作用：同一个地方，能不能贴多次这个标签？
	3. **Inherited = true/false**
		1. 子类会不会继承父类的标签？
	4. 位置参数`PositionalString`
		1. 属性中填入的，在类中可设置类型比如`string，int`，来限制参数的输入
		2. `[MyCode("params1")]`
		3. 就和函数参数一样，如果有多个，那么属性类中就定义多个
		4. 如果有可选参数，那么只需要在类中定义对应的属性，然后在`[]`中填入就可以，不需要在构造函数中写明类型
