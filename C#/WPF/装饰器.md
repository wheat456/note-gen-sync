Decorator 的职责不是布局多个元素，而是**包裹一个元素并改变它的表现或行为**

| 控件                 | 作用         | 为什么是 Decorator |
| ------------------ | ---------- | -------------- |
| `Border`           | 边框、圆角、背景   | 给子元素加外观        |
| `Viewbox`          | 缩放         | 改变子元素尺寸行为      |
| `ScrollViewer`     | 滚动         | 给子元素增加滚动能力     |
| `AdornerDecorator` | 支持 Adorner | 给子元素增加装饰层      |
| `Decorator`        | 最纯粹的装饰器    | 自定义用           |

| 类型                              | 核心用途                       | 渲染层级         |
| ------------------------------- | -------------------------- | ------------ |
| **Decorator**（如 Border/Viewbox） | 包装子元素，提供外围装饰（边框、缩放）        | 属于元素视觉树的一部分  |
| **AdornerDecorator**            | 提供装饰层（AdornerLayer），支持叠加装饰 | 独立于原视觉树，位于上层 |

# 自定义装饰器

> [!NOTE] 
> 在 `OnRender` 中编写的绘图代码通常位于子元素的**下方**（即背景层）
> 如果你希望装饰效果覆盖在子元素之上,建议使用 **Adorners（装饰层）**
> `OnRender` 仅仅影响**视觉表现**，不会影响布局。

1. 自定义一个类，继承`Decorator`,推荐以`Decorator`结尾
2. 重写`OnRender`方法
```cs
protected override void OnRender(DrawingContext drawingContext)
{
    // 1. 调用基类（通常为空，但重写习惯）
    base.OnRender(drawingContext);

    // 2. 获取当前装饰器的大小
    Rect rect = new Rect(0, 0, ActualWidth, ActualHeight);

    // 3. 执行绘图逻辑
    drawingContext.DrawRectangle(Brushes.LightBlue, new Pen(Brushes.Blue, 2), rect);
}
```
3. 包裹控件
```xml
<local:ShadowDecorator>
    <Button Content="有阴影的按钮"/>
</local:ShadowDecorator>
```



# AdornerDecorator

2. ```cs
   // 构造函数必须传入被装饰的元素（AdornedElement）
    public MyOverlayAdorner(UIElement adornedElement) : base(adornedElement)
    {
        // 确保装饰器不响应鼠标事件，否则会挡住下方按钮的点击
        IsHitTestVisible = false;
    }
