# 使用步骤

# 在`EventTrigger` 中
场景：比如鼠标点击等事件就触发动画
```xml
<EventTrigger RoutedEvent="MouseEnter">
    <BeginStoryboard>
        <Storyboard> </Storyboard>
    </BeginStoryboard>
</EventTrigger>
```


# 在`DataTrigger` 中
场景：当**数据**在不同状态时，触发不同的动画
需要写 `EnterActions`  和 `ExitActions`
```xml
<DataTrigger Binding="{Binding IsActive}" Value="True">
    <DataTrigger.EnterActions>
        <BeginStoryboard>
            <Storyboard> </Storyboard>
        </BeginStoryboard>
    </DataTrigger.EnterActions>
    <DataTrigger.ExitActions>
        </DataTrigger.ExitActions>
</DataTrigger>
```

#### 使用 Storyboard（推荐，支持 XAML 定义）

`Storyboard` 是一个容器，可以包含多个动画，并且是同时运行的

`doubleanimation`
该表数值的动画
- `Storyboard.TargetName`：目标元素名称
- `Storyboard.TargetProperty`：要动画的属性（支持路径，如 `(UIElement.Opacity)`）
- `From` / `To` / `By`：起始值、结束值、增量
- `Duration`：持续时间（格式：`时:分:秒.毫秒`）
- `AutoReverse`：是否自动反向播放
- `RepeatBehavior`：重复行为（如 `"3x"`、`"Forever"`）
