类型

| `DoubleAnimation`               | `double`    | 如`Opacity`、`Width`、`Height` |
| ------------------------------- | ----------- | --------------------------- |
| `ColorAnimation`                | `Color`     | 如`SolidColorBrush.Color`    |
| `PointAnimation`                | `Point`     | 如`EllipseGeometry.Center`   |
| `ThicknessAnimation`            | `Thickness` | 如`Margin`、`Padding`         |
| `ObjectAnimationUsingKeyFrames` | 任意类型        | 用于不支持插值的类型（如`Visibility`）   |

#### 使用 Storyboard（推荐，支持 XAML 定义）

`beginstoryboard`相当于**trigger**，代表执行动画
`Storyboard` 是一个容器，可以包含多个动画，并且是同时运行的

doubleanimation
该表数值的动画
- `Storyboard.TargetName`：目标元素名称
- `Storyboard.TargetProperty`：要动画的属性（支持路径，如 `(UIElement.Opacity)`）
- `From` / `To` / `By`：起始值、结束值、增量
- `Duration`：持续时间（格式：`时:分:秒.毫秒`）
- `AutoReverse`：是否自动反向播放
- `RepeatBehavior`：重复行为（如 `"3x"`、`"Forever"`）
