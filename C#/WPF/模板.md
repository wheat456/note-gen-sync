## 数据模板 DateTemplate
- 定义了数据对象如何呈现在 UI 元素中，比如在一个列表或网格中
- 主要关注如何把数据比如**Persons**,**Users**，用哪种控制模板来渲染
- ==简单来说，就是把一个类映射成一个UI具体表现==
- 数据模板只能放在 **ContentTemplate** 和 **ItemTemplate** 之中 
```
<ListBox ItemsSource="{Binding UsersList}">
    <ListBox.ItemTemplate>
        <DataTemplate>
        在这里写需要展示的组件
            </DataTemplate>
    </ListBox.ItemTemplate>
</ListBox>
```

##  内容模板 ContentTemplate
- `ContentTemplate` 的内部必须是一个 **`<DataTemplate>`**，而在 `DataTemplate` 里面，你可以放几乎任何视觉元素。
- `ContentTemplate` 可以定义在行内定义，因为`datatemplate` 需要绑定数据，所以绑定的是 `content` 中的
```xml
<Button content={Binding Person}>
    <Button.ContentTemplate>
        <DataTemplate>
        //这里面的数据就绑定到Person上
        </DataTemplate>
    </Button.ContentTemplate>
</Button>
```
- 也可以将`DateTemplate`在 `resources` 中定义。如果数据模板指定了类型那么控件就不需要指定内容模板，否则就需要手动指定静态资源
```xml
<Button Content="{Binding SomeUserObject}" ContentTemplate="{StaticResource MyUserTemplate}" />
```

```xml
<Window.Resources>
    <DataTemplate DataType="{x:Type local:User}">
        <StackPanel>
            <TextBlock Text="{Binding Name}" FontWeight="Bold"/>
            <TextBlock Text="{Binding Status}" />
        </StackPanel>
    </DataTemplate>
</Window.Resources>

<Button Content="{Binding SomeUserObject}" /> 
<ContentControl Content="{Binding AnotherUser}" />
```

## 控制模板 ControlTemplate
- 定义了现有控件（如 Button, TextBox）的视觉结构。
- `控制模板`是关于一个组件的**外观**
- ==简单来说，就是描写一个组件是有哪些组件共同组成的==
```xaml
<ControlTemplate TargetType="{x:Type Button}">
	<grid>
		<Ellipse/>
		<contentpresenter/> 控制内容显示的位置
	</grid>
    </ControlTemplate>
```
这个定义在**Window.Resources**中
### 步骤
在写控件模板时
1. 首先在样式（Style）指定类型target 比如button，在 **setter** 指定类型为**template** 
2. 在 **setter** 的 **Value** 中写 **ControlTemplate**，因为是在写结构。
3. 然后在结构中放置自定义的组件，比如`Border` 等
4. 如果要设置 **trigger** ，就设置在 **ControlTemplate** 的 **triggers** 中，当然也可以具体设置在自定义组件的style中，不过这样某些触发条件不能达成，所以大部分情况还是在控件模板的 **trigger** 中
5. 在这个 **trigger** 如果想要对自定义组件进行属性设置，那么就要给自定义组件比如`border`设置一个名字，用 **targetName** 来指定

## 视觉状态管理器
可以定义在UserControl / Window 和 **ControlTemplate** 中

1. 先写视觉状态组`<VisualStateManager.VisualStateGroups>`
2. 然后顶一个状态组，就像一个storyboard
3. 然后定义`VisualState` 
4. 在`VisualState`中只能定义storyboard，如果要实现setter那种效果也要用动画实现

- **视觉状态组**
	- 一组互斥的状态，比如`CommonStates` (一般状态，包括 `Normal`、`MouseOver`、`Pressed`)。
- **视觉状态**
    - 组中的一个具体状态，它包含一个 `Storyboard`，定义了进入这个状态时要播放的动画。
```
<grid>
 <VisualStateManager.VisualStateGroups>定义状态组
	 <VisualStateGroup x:Name="CommonStates"> 具体状态组
		 <VisualState x:Name="Pressed" > 具体状态
			 <Storyboard>
  
</grid>

```

|  **特性**  |         **Style (样式) 🎨**         | **ControlTemplate (控制模板) 📜**      |
| :------: | :-------------------------------: | ---------------------------------- |
|  **作用**  |           设置控件的**属性值**。           | 定义控件的**内部视觉结构**（外观）。               |
|  **内容**  |          包含 `Setter` 集合。          | 包含 XAML 视觉树（`Grid`、`Rectangle` 等）。 |
| **修改范围** | 颜色、字体、边距，以及... **`Template` 属性**。 | 形状、内部布局、状态动画。                      |
|  **比喻**  |           控件的**配置清单**。            | 控件的**蓝图/骨架**。                      |
|          |                                   |                                    |
