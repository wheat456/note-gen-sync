## 数据模板 DateTemplate
- 定义了数据对象如何呈现在 UI 元素中，比如在一个列表或网格中
- 主要关注如何把数据比如**Persons**,**Users**，用哪种控制模板来渲染
- ==简单来说，就是把一个类映射成一个UI具体表现==
```
<ListBox ItemsSource="{Binding UsersList}">
    <ListBox.ItemTemplate>
        <DataTemplate>
        在这里写需要展示的组件
            </DataTemplate>
    </ListBox.ItemTemplate>
</ListBox>
```


## 控制模板 ControlTemplate
- 定义了现有控件（如 Button, TextBox）的视觉结构。
- `控制模板`是关于一个组件的**外观**
- ==简单来说，就是描写一个组件是有哪些组件共同组成的==
```xaml
<ControlTemplate TargetType="{x:Type Button}">
	<grid>
		<Ellipse/>
		<contentpresenter/> 控制内容显示的位置
	</grid>
    </ControlTemplate>
```
这个定义在**Window.Resources**中

## 视觉状态管理器
可以定义在UserControl / Window 和 ControlTemplate中

1. 先写视觉状态组`<VisualStateManager.VisualStateGroups>`
2. 然后顶一个状态组，就像一个storyboard
3. 然后定义`VisualState` 
4. 在`VisualState`中只能定义storyboard，如果要实现setter那种效果也要用动画实现

- **视觉状态组**
	- 一组互斥的状态，比如`CommonStates` (一般状态，包括 `Normal`、`MouseOver`、`Pressed`)。
- **视觉状态**
    - 组中的一个具体状态，它包含一个 `Storyboard`，定义了进入这个状态时要播放的动画。
```
<grid>
 <VisualStateManager.VisualStateGroups>定义状态组
	 <VisualStateGroup x:Name="CommonStates"> 具体状态组
		 <VisualState x:Name="Pressed" > 具体状态
			 <Storyboard>
  
</grid>

```

|  **特性**  |         **Style (样式) 🎨**         | **ControlTemplate (控制模板) 📜**      |
| :------: | :-------------------------------: | ---------------------------------- |
|  **作用**  |           设置控件的**属性值**。           | 定义控件的**内部视觉结构**（外观）。               |
|  **内容**  |          包含 `Setter` 集合。          | 包含 XAML 视觉树（`Grid`、`Rectangle` 等）。 |
| **修改范围** | 颜色、字体、边距，以及... **`Template` 属性**。 | 形状、内部布局、状态动画。                      |
|  **比喻**  |           控件的**配置清单**。            | 控件的**蓝图/骨架**。                      |
|          |                                   |                                    |
