- `x:???`这个的意思是关键字，特殊用途，比如x:Name="你好" ，就是给这个组件对象起名，然后在代码中就可以方便使用


# 数据绑定

```xml
<TextBlock Text="{Binding Source={StaticResource myDataSource}, Path=Name}"/>
```

## 对象元素语法
```xml
	<TextBlock>
    <TextBlock.Text>
        <Binding Source="{StaticResource myDataSource}" Path="Name"/>
    </TextBlock.Text>
</TextBlock>
```
