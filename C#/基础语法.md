# 类
##  修饰符
- `internal`  是访问修饰符，用于限制类型（类、结构体等）或成员的可见性。被 `internal` 修饰的类，**只能在当前程序集（Assembly）内部被访问**，在程序集外部（如其他项目、其他 DLL）无法访问。
- `static` 修饰类时，表示该类是**静态类**，具有以下特点：
	- 不能被实例化（无法用 `new` 关键字创建对象）；
	- 只能包含静态成员（静态方法、静态字段、静态属性等）；
	- 不能被继承，也不能继承其他类（除了 `object`）；
	- 通常用于封装 “工具方法”“辅助函数” 或 “扩展方法” 等不依赖实例状态的功能。

## get/set
```c# 
class Person{
	private int age
	public int Age{ 
		get{
			return this.age
		}
		set{
			this.age=value //关键字 传入的值
		}
	}
	
	// 自动实现的属性
	// 编译器会生成一个隐藏的私有字段来存储数据 
	public int ProductId { get; set; }

}

//使用
person.Age(10)
```

## 索引器
```c# 
public int? this[string key]
    {
        get
        {
            // 当用户尝试读取值时执行
            if (data.ContainsKey(key))
            {
                return data[key]; // 返回对应的值
            }
            return null; // 如果键不存在，返回 null
        }
        set
        {
            // 当用户尝试设置值时执行
            if (value.HasValue)
            {
                data[key] = value.Value; // 存储非空的值
            }
            else
            {
                data.Remove(key); // 如果赋的值是 null，则移除该键
            }
        }
    }
```
