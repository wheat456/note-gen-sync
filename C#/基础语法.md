### 模式匹配
#### 类型匹配
当data的类型满足下面的类型时就进去，同时给该变量赋值
```cs
object data = 123;
switch (data)
{
    case int i:
        Console.WriteLine($"这是一个整数: {i}");
        break;
    case string s:
        Console.WriteLine($"这是一个字符串，长度为: {s.Length}");
        break;

```
#### 属性模式
其中person是一个类，Age是他的属性
```cs
var res = person switch
{
    { Age: >= 18, IsStudent: true } => "成年学生",
    { Age: < 18 } => "未成年人",
    _ => "其他"
};
```
#### 关系与逻辑模式
```cs
int score = 85;

        break;
}
```

# 函数
## 参数
| **修饰符**      | **名称** | **作用**                                 |
| ------------ | ------ | -------------------------------------- |
| **(None)**   | 值传递    | 默认方式。传递变量的副本，函数内修改不影响原件。               |
| **`ref`**    | 引用传递   | 传递变量的地址。函数内修改会**直接改变**外部变量。要求变量必须先初始化。 |
| **`out`**    | 输出参数   | 用于返回多个值。变量不需要初始化，但函数内部**必须**在返回前给它赋值。  |
| **`in`**     | 只读引用   | 传递地址以提高大型结构体（struct）的性能，但函数内**不能修改**它。 |
| **`params`** | 可变参数   | 允许传入数量不定的参数（本质是数组）。一个函数只能有一个且必须在最后。    |

lambda表达式，如果行多就在=>后面使用`{}`

|**情况**|**写法**|**示例**|
|---|---|---|
|**无参数**|`() => ...`|`() => Console.WriteLine("Hi")`|
|**一个参数**|`x => ...`|`x => x * 2` （括号可省略）|
|**多个参数**|`(x, y) => ...`|`(x, y) => x + y` （必须带括号）|
|**显式指定类型**|`(int x) => ...`|当编译器推导不出类型时使用|

##  修饰符
- `internal`  是访问修饰符，用于限制类型（类、结构体等）或成员的可见性。被 `internal` 修饰的类，**只能在当前程序集（Assembly）内部被访问**，在程序集外部（如其他项目、其他 DLL）无法访问。
- `static` 修饰类时，表示该类是**静态类**，具有以下特点：
	- 不能被实例化（无法用 `new` 关键字创建对象）；
	- 只能包含静态成员（静态方法、静态字段、静态属性等）；
	- 不能被继承，也不能继承其他类（除了 `object`）；
	- 通常用于封装 “工具方法”“辅助函数” 或 “扩展方法” 等不依赖实例状态的功能。
- `protect` 只能用于自身和子类

## 索引器
```c# 
public int? this[string key]
    {
        get
        {
            // 当用户尝试读取值时执行
            if (data.ContainsKey(key))
            {
                return data[key]; // 返回对应的值
            }
            return null; // 如果键不存在，返回 null
        }
        set
        {
            // 当用户尝试设置值时执行
            if (value.HasValue)
            {
                data[key] = value.Value; // 存储非空的值
            }
            else
            {
                data.Remove(key); // 如果赋的值是 null，则移除该键
            }
        }
    }
```

# 委托
## 定义
其中mydelegate是自定义名称，委托就是定义了一个函数签名
```cs
public delegate void MyDelegate(string message);
```
## 使用
```cs
MyDelegate del2 = ShowInConsole; //直接赋值
void ShowInConsole(string text) { Console.WriteLine("控制台显示：" + text); }
```
并且可以添加，然后调用委托时，就可以执行多个函数
```cs
MyDelegate multiDel = ShowInConsole; 
multiDel += ShowInLog; // 再加一个
```
## 回调
传递进来一个委托，然后执行，这个委托就相当于一个函数包，里面有许多函数
```cs
// 一个模拟下载的方法
public void DownloadFile(string url, MyDelegate onFinished)
{
    Console.WriteLine("正在下载: " + url);
    // ...下载逻辑...
    onFinished("下载成功！"); // 任务完成后执行回调
}

// 调用时：
DownloadFile("https://example.com/file.zip", ShowInConsole);
```

# 事件
- **发布者 (Publisher)：** 包含事件并负责触发它的类。
    
- **订阅者 (Subscriber)：** 注册并处理该事件的类。
    
- **委托 (Delegate)：** 事件的底层基础。它定义了事件处理程序必须遵循的“签名”（即参数和返回值类型）。
eventhandler是一个委托类型，这个事件定义在类中，然后外部只能订阅+-，不能调用事件。只能在类的内部调用
```cs
public event EventHandler ProcessFinished; 
```
