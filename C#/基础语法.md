# 函数
## 参数
| **修饰符**      | **名称** | **作用**                                 |
| ------------ | ------ | -------------------------------------- |
| **(None)**   | 值传递    | 默认方式。传递变量的副本，函数内修改不影响原件。               |
| **`ref`**    | 引用传递   | 传递变量的地址。函数内修改会**直接改变**外部变量。要求变量必须先初始化。 |
| **`out`**    | 输出参数   | 用于返回多个值。变量不需要初始化，但函数内部**必须**在返回前给它赋值。  |
| **`in`**     | 只读引用   | 传递地址以提高大型结构体（struct）的性能，但函数内**不能修改**它。 |
| **`params`** | 可变参数   | 允许传入数量不定的参数（本质是数组）。一个函数只能有一个且必须在最后。    |

lambda表达式，如果行多就在=>后面使用`{}`

|**情况**|**写法**|**示例**|
|---|---|---|
|**无参数**|`() => ...`|`() => Console.WriteLine("Hi")`|
|**一个参数**|`x => ...`|`x => x * 2` （括号可省略）|
|**多个参数**|`(x, y) => ...`|`(x, y) => x + y` （必须带括号）|
|**显式指定类型**|`(int x) => ...`|当编译器推导不出类型时使用|

##  修饰符
- `internal`  是访问修饰符，用于限制类型（类、结构体等）或成员的可见性。被 `internal` 修饰的类，**只能在当前程序集（Assembly）内部被访问**，在程序集外部（如其他项目、其他 DLL）无法访问。
- `static` 修饰类时，表示该类是**静态类**，具有以下特点：
	- 不能被实例化（无法用 `new` 关键字创建对象）；
	- 只能包含静态成员（静态方法、静态字段、静态属性等）；
	- 不能被继承，也不能继承其他类（除了 `object`）；
	- 通常用于封装 “工具方法”“辅助函数” 或 “扩展方法” 等不依赖实例状态的功能。

## 索引器
```c# 
public int? this[string key]
    {
        get
        {
            // 当用户尝试读取值时执行
            if (data.ContainsKey(key))
            {
                return data[key]; // 返回对应的值
            }
            return null; // 如果键不存在，返回 null
        }
        set
        {
            // 当用户尝试设置值时执行
            if (value.HasValue)
            {
                data[key] = value.Value; // 存储非空的值
            }
            else
            {
                data.Remove(key); // 如果赋的值是 null，则移除该键
            }
        }
    }
```

## 显示实现
一个类可以继承多个接口，某些接口需要显示实现才能调用
```c# 
interface A{
	void love();
}
interface B{
	void hate()；
}
class Person:A,B{
	void love(){
	}
	void A.hate(){
	}
}
A person = new Person();//这样才能看到A的love方法
//否则
Person peron= new Person(); //这样看不到A的love方法

```
