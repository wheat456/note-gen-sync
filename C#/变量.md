# 记录
不可变性
这是 Record 与 Class 最大的区别：
- **Class:** 比较的是**引用**（两个对象必须指向同一个内存地址才相等）。
-  **Record:** 比较的是**内容**（只要两个 Record 的所有属性值都一样，它们就被视为相等）。
- record是引用类型，但是struct是值类型
 ```cs
 public record User(string Name, int Age);
 ```
 默认不可变，想要修改就重新复制一份
 ```cs
 var user1 = new User("Alice", 25);
// 创建一个新对象，除了 Age 改为 26，其他属性和 user1 一样
var user2 = user1 with { Age = 26 };
 ```
