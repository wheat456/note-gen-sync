# 时钟极性

- 定义 “空闲时 SCK 的电平”
  * CPOL=0：空闲时 SCK 为**低电平**，通信时时钟从低变高（上升沿）、从高变低（下降沿）；
  * CPOL=1：空闲时 SCK 为**高电平**，通信时时钟从高变低（下降沿）、从低变高（上升沿）。


# 时钟相位

- 定义 “数据采样的时钟边沿”
  * CPHA=0：在 “时钟的第一个边沿”（CPOL=0 时是上升沿，CPOL=1 时是下降沿）采样数据；
  * CPHA=1：在 “时钟的第二个边沿”（CPOL=0 时是下降沿，CPOL=1 时是上升沿）采样数据。

```rust
    let spi_mode =Mode{
        polarity:spi::Polarity::IdleLow, // 极性 负责时钟
        phase: spi::Phase::CaptureOnFirstTransition //相位,负责采样
    };
```


| 信号线名称 | 英文全称                   | 作用说明                                                                     | 控制方           |
| ---------- | -------------------------- | ---------------------------------------------------------------------------- | ---------------- |
| SCK        | Serial Clock               | 串行时钟线，用于同步数据传输，每个时钟周期传输 1 位数据                      | 主设备（Master） |
| MOSI       | Master Output, Slave Input | 主设备输出、从设备输入线，主设备通过此线向从设备发送数据                     | 主设备           |
| MISO       | Master Input, Slave Output | 主设备输入、从设备输出线，从设备通过此线向主设备返回数据                     | 从设备           |
| CS/SS      | Chip Select / Slave Select | 片选线，主设备拉低某从设备的 CS 线，即可选中该设备通信（未选中时从设备高阻） | 主设备           |
