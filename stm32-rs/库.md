# cortex-m & cortex-m-rt



| 维度         | `cortex-m`                           | `cortex-m-rt`                        |
| ------------ | ------------------------------------ | ------------------------------------ |
| **核心功能** | 提供 Cortex-M 内核硬件的直接访问能力 | 提供程序启动、中断向量表等运行时基础 |
| **角色**     | 硬件抽象层（HAL）                    | 运行时（Runtime）                    |
| **依赖关系** | 可独立使用                           | 依赖`cortex-m`提供的底层支持         |
| **核心目标** | 安全访问内核外设（如 NVIC、SysTick） | 确保程序能正确启动并响应中断         |

- `cortex-m`：操作内核硬件的 “工具包”
  - `cortex-m` 库的核心作用是**抽象 Cortex-M 内核的硬件细节**，提供类型安全的 API 来访问内核外设（如 NVIC 中断控制器、SysTick 定时器等），避免直接操作裸寄存器的风险。
- `cortex-m-rt`：程序运行的 “基石”
- `cortex-m-rt` 库的核心作用是**提供 Cortex-M 程序的启动和运行环境**，负责从芯片上电到进入 `main` 函数前的所有初始化工作，以及中断处理的基础框架。
