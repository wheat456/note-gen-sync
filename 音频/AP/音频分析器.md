- Level : $V_{RMS}$
- Freq : 信号频率


# de (decoder) 检波响应速度
## 1. 基础概念
Det 是**检波积分 / 平均速率**，单位 `/s` = 每秒更新采样平均次数，控制仪器读数平滑快慢、响应快慢； 本质：仪器对波动信号做滑动平均滤波，数值越大，刷新越快、读数越抖；数值越小，平均时间越长、读数越稳。
1. **Auto** 仪器自动匹配测量功能选择响应速度：
- 测稳态正弦、RMS 电平、SNR：自动用低速平均（4/8/s），读数平滑稳定；
- 测瞬态、峰值、抖动、脉冲、扫频：自动切高速（64/128/256/s），捕捉快速变化。

2. **4/s、8/s、16/s、32/s、64/s、128/s、256/s** 数字 = 每秒进行多少次平均计算，对应**积分时间长短**：
- 低速：4/s → 平均时间最长（250ms），极强平滑，压制噪声抖动，适合**稳态电平、信噪比、底噪、失真**；
- 高速：256/s → 平均仅 3.9ms，响应极快，几乎无平滑，适合**瞬态信号、峰值、爆音、扫频曲线、冲击噪声**。

## 2. 快慢档位优缺点对比

### 低速档（4/s、8/s）

✅ 优点：读数稳定，随机噪声 / 纹波被平均抹平，dB 数值波动极小，读数好读； ❌ 缺点：信号快速变化时读数滞后，跟不上瞬态波动； 适用场景：功放底噪 SNR、THD 失真、稳态正弦电压、长期噪声监测。
### 高速档（128/s、256/s）
✅ 优点：实时跟随信号快速起伏，捕捉瞬时峰值、脉冲、动态变化； ❌ 缺点：读数剧烈跳动，微小噪声都会让数值飘； 适用场景：扫频频响、瞬态失真、冲击测试、峰值电平、喇叭动态冲击。
### 中间档（16/32/64/s）
折中平衡，常规普通音频测试通用，兼顾稳定与响应。
## 3. 实操选型建议

1. 测信噪比、底噪、THD、静态输出电压 → **4/s 或 Auto**
2. 做扫频频响曲线、连续扫频测试 → 64/128/s
3. 测瞬态冲击、开关机爆音、峰值功率 → 256/s
4. 日常综合测试不想手动调 → Auto（自动适配测量项）

## 1. RMS（标准均方根，音频行业默认）

### 计算公式
1. 取窗口内所有瞬时电压值
2. 全部平方 → 求和 → 求平均值 → 整体开根号
### 特性
- 对**完整周期信号能量加权平均**，完全匹配交流电等效发热功率；
- 正弦波、噪声、失真、信噪比、功放额定功率标准测量方式；
- 响应平缓，短暂瞬时尖峰不会拉高读数，只统计持续存在的噪声 / 信号能量。
### 适用场景
功放 SNR 信噪比、THD 失真、额定输出功率、稳态正弦电平、底噪测试。
## 2. Fast RMS（快速 RMS）
### 核心区别
普通 RMS 是**整段窗口全部采样点等权重平均**； Fast RMS 采用**指数滑动平均**，最新采集到的电压样本权重更高，旧样本权重快速衰减。

### 特性
- 响应速度比标准 RMS 快很多，能更快捕捉信号电平的突然变化；
- 不会像峰值那样只抓最高点，依然保留 RMS 能量逻辑；
- 读数会轻微抖动，介于标准 RMS 和峰值之间。
### 适用场景
扫频测试、动态电平变化、快速切换信号、实时监控音量波动。
## 3. Q-Peak（准峰值，Quasi-Peak）
### 底层逻辑
模拟人耳对短促脉冲噪声的感知特性，专门针对间歇性尖峰噪声：
1. 检测瞬时电压峰值；
2. 内置充放电时间常数：尖峰出现时读数快速上升，噪声消失后读数缓慢回落；
3. 短促、间歇性毛刺噪声会被明显放大读数（人耳对噼啪、爆音更敏感）。
### 关键用途
EMI 电磁噪声、开关电源毛刺、音频爆音、脉冲干扰、射频干扰测试； 国标噪声限值很多强制要求 Q-Peak 读数。
## 直观对比表

| 模式       | 计算逻辑       | 响应快慢    | 对瞬时尖峰敏感度    | 典型用途              |
| -------- | ---------- | ------- | ----------- | ----------------- |
| RMS      | 全窗口均等均方根   | 慢       | 低，只看持续能量    | SNR、THD、额定功率、稳态噪声 |
| Fast RMS | 指数加权滑动 RMS | 中快      | 中等，快速跟随电平变化 | 扫频、动态信号监测         |
| Q-Peak   | 准峰值充放电检波   | 上升快、回落慢 | 极高，突出脉冲毛刺   | 开关毛刺、爆音、EMI 干扰测试  |

# Bw
## 下限
## 1. < 10 Hz
- **-3dB 截止点：约 4.1Hz**，官方标注 `<10Hz` 代表**极低通阻**模式ManualsLib
- 滤波特性：仅大幅衰减 DC、0~4Hz 超低频漂移、麦克风 / 运放低频滚降、振动次声噪声，10Hz 及以上音频几乎无衰减
- **适用场景**：
    - 完整频响测试（20Hz~20kHz 全频段扫频）
    - 低频单元、低音炮、功放低频失真测量
    - 需要保留 10Hz 以下微弱低频信号的测试
## 2. 22 Hz（行业标准 IEC/ANSI 音频基准）
- **-3dB 截止 = 22.4Hz**，4 阶巴特沃斯标准音频高通
- 行业通用基准：模拟人耳低频下限、滤除 20Hz 以下次声波、电源低频抖动、机箱振动噪声
- **适用场景（最常用）**：
    - 耳机、音箱、功放常规 THD+N、信噪比 SNR 测试
    - 消费音频设备出厂标准化测试（国标 / 国际标准默认 22Hz HP）
    - 绝大多数 100Hz 以上中高频失真、互调失真测量
## 3. 100 Hz
- **-3dB 截止 = 100Hz**，更强低频抑制
- 滤除 50/60Hz 工频电源干扰、电源纹波、大音量低频共振噪声，彻底切掉 100Hz 以下所有分量
- **适用场景**：
    - 中高频设备：高音喇叭、耳机高频单元、射频音频模块
    - 电源噪声严重的恶劣测试环境（无屏蔽车间）
    - 仅测试 100Hz~20kHz 频段失真
## 4. 400 Hz
- **-3dB 截止 = 400Hz**，最强内置高通，极高低频衰减
- 直接屏蔽 400Hz 以下全部低频、工频谐波、机械震动噪声
- **适用场景**：
    - 中频 / 高频专用设备：话筒、数字音频模块、中频放大器
    - 高信噪比微小信号测试（麦克风底噪、微弱音频信号）
    - 只分析 400Hz 以上谐波失真，完全排除低频干扰
## 5. User HP（User High Pass 用户自定义高通）
- 自定义数字高通滤波器，最高支持 4 阶可调，可自由设定 0.1Hz~10kHz 任意 - 3dB 截止点、滤波器阶数
- 支持保存自定义滤波曲线，适配非标测试标准
- **适用场景**：
    - 特殊行业标准（汽车音响、医疗音频、专业广播设备自定义规范）
    - 需要精准定制低频截止的研发调试
    - 搭配加权滤波器（A 计权、CCIR）做复合滤波

## 上限
### 1. Fs/2
#### 含义
Fs = 当前硬件采样率，Fs/2 即**奈奎斯特频率**，软件不额外做高频截止，保留采样率以内全部频率。 举例：
- 采样率 48kHz → Fs/2=24kHz
- 采样率 96kHz → Fs/2=48kHz
#### 用途
1. 全带宽频响扫频、测试设备超高频延伸（耳机高频、数字功放、DAC）
2. 测量 20kHz 以上高频谐波、射频干扰、开关电源高频噪声
3. 研发阶段完整带宽分析，不限定上限
### 2. 20kHz LP
#### 含义
-3dB 截止点固定 20kHz，标准人耳听觉上限低通，高于 20kHz 信号大幅衰减。
#### 用途（量产测试最常用）
1. 国标 / 国际标准 THD+N、SNR 标准化测量（人耳听不到 20kHz 以上，滤除无关高频干扰）
2. 音箱、耳机、消费功放出厂检测，匹配音频 20Hz~20kHz 标准测量区间
3. 消除开关电源、数字电路超高频毛刺对失真读数的干扰
### 3. 15kHz LP
#### 含义
-3dB 截止 15kHz，更早截断高频。
#### 用途
1. 中频音频设备：车载收音机、语音对讲、广播喇叭、老年音箱（频响上限仅 15kHz）
2. 恶劣测试环境，高频电磁干扰严重，提前滤除 15kHz 以上杂波
3. 老式模拟磁带、电话音频设备指标测试
### 4. User LP（自定义低通）
#### 含义
用户自定义数字低通，自由设置截止频率、滤波器阶数，可保存自定义滤波曲线
#### 用途
1. 非标产品测试：汽车功放、医疗音频、工业语音模块
2. 复合滤波搭配自定义高通，自定义任意测量带宽
3. 专项高频抑制调试（如只测 1kHz~10kHz 区间失真）
# filr
## 1. None
无加权滤波，全频带平直响应，对所有频率信号同等放大测量。 适用：纯电压幅值、频响曲线、THD 总失真、直流 / 低频纹波、功放功率测试，不做听觉修正。
## 2. "A" Weighting（A 计权）
最通用人耳噪声加权，模拟人耳 40phon 低响度听觉曲线：压低低频、高频小幅衰减，重点突出 2–5kHz 人耳敏感频段。
- 标准：ANSI S1.42、IEC 61672
- 用途：音箱噪声、功放底噪、整机 SNR 信噪比、环境噪音测试（dB (A)）。

## 3. IEC468 Weighting（CCIR 468，广播噪声计权）
广播 / 音频设备专用噪声加权，专门针对调频广播、录音设备、磁带噪声设计。
- 特性：大幅抬升 10kHz~20kHz 高频噪声（人耳对高频嘶声更敏感），低频衰减比 A 计权更强。
- 用途：录音机、调音台、FM 收音机、广播设备信噪比、嘶声噪声测试。
## 4. "F" Weighting（F 计权）
高保真音频专用加权，针对磁带 / 黑胶唱机的粉红噪声、嘶声优化，介于 A 计权与 IEC468 之间。
- 用途：HiFi 音响、模拟磁带、黑胶设备噪声测试。
## 5. CCITT Weighting（ITU-T P.53，电信计权）
- 老式电话线路噪声加权，针对 300–3400Hz 语音带宽优化，抑制带外噪声。
- 用途：座机、交换机、语音通讯设备线路噪声测试，现在极少用于音响。
## 6. C-Message Weighting（北美电信 C 消息加权）
- 北美通信行业标准，专为电话语音信道噪声测量，带宽限制语音频段。
- 用途：北美程控交换机、VOIP 语音设备噪声测试，音频功放几乎不用。
## 7. User Weighting（自定义加权）
用户导入自定义频响曲线，可自定义任意频率加权 / 滤波曲线。
- 用途：特殊行业定制测试（汽车音频、专业声学、自定义滤波器标准）
## 快速选型对照表

| 测试场景           | 推荐加权              |
| -------------- | ----------------- |
| 功放 / 音箱信噪比、底噪  | A Weighting       |
| 广播设备、录音机、磁带噪声  | IEC468            |
| HiFi 黑胶、模拟音频设备 | F Weighting       |
| 电话 / 语音通信设备    | CCITT / C-Message |
| 频响、失真、功率、纯电压   | None              |
| 非标特殊声学测试       | User Weighting    |
# Reference
## 一、dBr A /dBr B（双通道电压参考基准）
### 1. 定义
A 通道输入参考电压、B 通道输入参考电压。 软件规则：**当前输入电压 = 你填的 mV 值 → 读数显示 0 dBr** 举你截图例子：`dBr A:400.0mV`
- 被测 A 通道刚好 400mV → 0dBr
- 被测 A 通道 800mV（翻倍）→ +6dBr
- 被测 A 通道 40mV（十分之一）→ -20dBr 双通道独立设置，方便左右声道增益不一致的功放 / 耳机测试。
### 2. 新手通用设置逻辑
1. **功放额定功率测试** 先算额定输出电压：P=U²/R，8Ω 8W 功放 U=√(8*8)=8Vrms 如果你测 8W@8Ω，就把 dBr 填 **8000mV(8V)**，此时额定输出就是 0dBr，方便看余量 / 失真。 你截图 Watts 栏正好是 8Ω，就是配套功放功率测试用。
2. **耳机 / 小信号 DAC** 常规标准参考 0dBFS=1V，dBr 填 1000mV；消费耳机标准 100mV 参考。
3. **标准化 THD 测试（最常用）** 行业通用参考：**400mV @1kHz**（就是你截图 A 通道 400mV），几乎所有音箱、功放出厂默认。
## 二、Freq: 1.000000 kHz（参考基准频率）
dBr 的 0dB 基准绑定这个频率：
- 你设置 400mV@1kHz = 0dBr；扫频到其他频率时，同 400mV 电压依然是 0dBr，用来做频响曲线基准（频响曲线 0dB 点就是 1kHz 对应参考电压）。 音频标准统一固定 **1kHz**，不用改。
## 三、V/FS:1.000 V（数字满刻度参考电压）
FS=Full Scale 数字满幅，只针对**数字设备（DAC、声卡、数字功放）**
- 含义：数字信号 0dBFS 对应的模拟输出电压是 1V。
- 比如 DAC 规格书写 0dBFS=2Vrms，这里就改成 2.000V；
- 纯模拟功放测试可不动，默认 1V。
## 四、Watts: 8.000 Ohms（功率换算负载阻抗）
作用：软件根据输入电压 + 该阻抗，自动计算输出功率 W、dBW。
- 测家用音箱功放：固定 8Ω；
- 车载喇叭：4Ω；
- 专业舞台功放：2Ω/4Ω； **只填负载喇叭阻抗，不填电压**。

## 五、dBm:600.0 Ohms（电平 dBm 阻抗基准）
dBm 定义：以 1mW 功率为 0dB 的分贝单位，必须绑定阻抗。
1. 600Ω：传统广播、调音台、平衡专业音频设备标准阻抗（行业老标准）；
2. 50Ω：射频测试；
3. 耳机 / 功放单端输出：一般不用 dBm，忽略即可。 如果你不做广播设备测试，这个参数不用修改。
