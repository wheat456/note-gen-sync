# 为什么需要FFT分析
1. **直观看到失真谐波** 纯 1kHz 标准正弦波理论上只有 1kHz 一根谱线；功放 / 声卡失真时会多出 2kHz、3kHz、4kHz… 谐波尖峰，FFT 能直接看见谐波数量、幅度，用来计算 THD 总谐波失真。
2. **分离噪声与信号** 底噪、50/60Hz 工频干扰、开关电源高频杂波会在频谱上形成连续噪声底，FFT 可量化噪声电平，算出 SNR 信噪比。
3. **定位干扰来源** 频谱上特定频率尖峰对应对应干扰源：50Hz/100Hz = 市电干扰，100kHz+= 开关电源干扰，高频离散尖峰 = 数字时钟抖动。
4. **量化互调失真 IMD、时钟抖动 Jitter** 数字音频设备专用，分解出时钟抖动产生的边带杂波。
5. **频响曲线底层数据来源** 扫频测试本质是逐频点 FFT 采集幅度，FFT 是频响、失真指标的底层计算工具

# input
## 1. Analog（模拟输入，90% 模拟功放 / 音箱测试默认）
### 含义
通道 A 读取 ATS-2 硬件**模拟 BNC 输入口**的模拟电压信号，处理连续模拟音频波形。
### 使用场景
1. 模拟功放、无源音箱、耳机、运放电路、模拟前级测试；
2. 测 THD、频响、噪声、失真，常规消费音频量产测试；
3. 搭配你前面设置的 HP/LP 滤波器、dBr 电压参考一起使用。
### 配套硬件
被测设备输出接 ATS-2 后方 Analog Input A BNC 接口


## 2. Digital（数字输入，DAC / 声卡 / 数字功放专用）
### 含义
通道 A 读取 ATS-2 硬件**数字音频输入**（AES/SPDIF 同轴 / 光纤数字流），直接解析数字采样数据，不经过模拟前端 ADC。
### 使用场景
1. 解码器 DAC、USB 声卡、数字功放、蓝牙音频模块数字输出测试；
2. 直接读取数字 0dBFS 满刻度信号，无模拟前端损耗，测纯数字失真；
3. 分析数字音频的量化噪声、数字滤波纹波。
### 注意
选 Digital 后，前面`V/FS`数字满幅基准生效，电压 dBr 参考不再主导读数。


## 3. ChA Analog / ChB Jitter (UI) 模拟 A 通道 + B 通道抖动（单位 UI）
### 拆分功能
- ChA Analog：A 通道依旧采集模拟音频信号（被测设备模拟输出）；
- ChB Jitter：B 通道锁定数字音频时钟，专门测量**时钟抖动**，读数单位 UI（Unit Interval，单位周期，数字抖动行业标准单位）。
### UI 定义
UI = 数字采样时钟 1 个完整周期，例如 48kHz 采样时钟 1UI≈20.833us；用来衡量时钟相对标准周期的偏移。
### 使用场景
DAC、蓝牙音频、数字功放、USB 声卡**抖动 + 模拟失真同步测试**：一边看模拟输出谐波（A 通道 FFT），一边同步读取数字时钟抖动值（B 通道）。
## 4. ChA Analog / ChB Jitter (s) 模拟 A 通道 + B 通道抖动（单位秒）
### 和上一项唯一区别：抖动单位
- ChA Analog：不变，模拟音频频谱；
- ChB Jitter：同样测时钟抖动，但数值单位为**秒 (s)/ 纳秒 (ns)**，不用换算 UI，直观读出时间偏移量。

### 适用人群

研发调试电路、硬件工程师，需要直观知道时钟偏移多少纳秒；量产产线一般用 UI 单位（行业标准）。

## 选项共用前提条件

1. 被测设备同时输出两路信号：一路模拟音频进 A 口，一路数字时钟 / SPDIF 数字信号进 B 数字输入；
2. 仅针对**数字音频设备**（DAC、数字功放、蓝牙模块），纯模拟功放、音箱不要选这两项。
## 快速选用表格

| 选项                          | 适用设备              | 测试目的                  |
| --------------------------- | ----------------- | --------------------- |
| Analog                      | 模拟功放、音箱、耳机、运放     | THD、SNR、频响、噪声（日常测试首选） |
| Digital                     | DAC、声卡、SPDIF 数字设备 | 纯数字信号失真、量化噪声          |
| ChA Analog / ChB Jitter(UI) | DAC / 数字功放量产测试    | 同步测模拟失真 + 标准单位抖动      |
| ChA Analog / ChB Jitter(s)  | 硬件研发调试数字音频电路      | 同步测模拟频谱 + 抖动时间 ns 数值  |

# Peak Monitor FFS 峰值监控读数
FFS = Full Scale FS，**数字满刻度分贝（dBFS）**
dBFS 是数字音频专属单位：
- 0 dBFS = 数字信号最大不失真幅度（满幅）
- 所有正常音频信号都为**负数**（-X dBFS），离 0 越近信号越大；低于 - 90dBFS 基本属于噪声

##  核心作用（新手必懂）

### ① 防削波（Clip）失真
- 读数靠近 `0 dBFS`（比如 -0.5~-1dBFS）：信号快顶到数字上限，会产生硬削波，THD 严重恶化；
- 测试标准推荐预留**-6dB ~ -12dBFS**工作区间（你 A 通道 - 9.769dBFS 刚好在标准安全区间）；
- 读数 > 0（正数 FFS）= 严重削波，测试数据直接作废。
### ② 双通道幅度对比
快速看左右声道 / AB 通道输出电平差异： 本例 A 通道比 B 通道信号大：`16.01 - 9.769 = 6.24dB`，左右声道存在 6dB 左右增益差。
### ③ 搭配模拟 / 数字输入模式
- Input=Digital（测 DAC 数字流）：读数为真实数字 dBFS；
- Input=Analog（测模拟功放）：软件把采集到的模拟电压换算成等效 dBFS，对照前面 `V/FS` 1V 满幅基准计算。


# FFT点数

FFT 数字 =**单次傅里叶变换采集的采样点总量**，只能是 2 的幂次，直接决定两个关键指标：**频率分辨率**、**单次采集时长**。 公式：
1. 频率分辨率 Δf = 采样率 Fs ÷ FFT 点数 N
2. 单次窗口时长 T = N ÷ Fs
举个常用场景：ATS 默认采样率 48kHz
- N=8192，Δf=48000/8192=**5.859375Hz**，单次窗口时长≈0.17s
- N=1024，Δf=48000/1024=**46.875Hz**，单次窗口时长≈0.021s
**分辨率**越小，**频谱线条**越细，能分开两个挨得很近的频率；分辨率大，相邻频率会糊成一团。 比如区分 50Hz 市电和 60Hz 干扰：N=1024（46Hz 分辨率）完全分不开；N=8192（5.8Hz）能清晰区分。
## 点数大小带来的优缺点对比
### 小点数（256 / 512 / 1024 / 2048）
✅ 优点：刷新速度极快，频谱实时滑动流畅，适合**实时观察动态信号**（快速扫频、瞬态失真、喇叭冲击噪声）
❌ 缺点：频率分辨率差，低频频谱糊在一起，微弱谐波、低电平噪声无法分辨，THD 读数波动大 适用：快速调试、看瞬态波形、高频粗测
### 中点数（4096 / 8192，音频测试标准值）
✅ 平衡刷新速度与分辨率，48kHz 采样下 5~11Hz 分辨率，足够分离音频谐波、50/60Hz 工频干扰，产线标准化 THD+N、SNR 测试首选（截图选中 8192 就是行业通用）
❌ 刷新变慢一点，肉眼几乎无感 适用：音箱、功放、DAC 常规量产测试，90% 音频测量场景
### 大点数（16384 / 32768）
✅ 极高频率分辨率（48kHz 下≈1.46Hz），能分离极近的谐波、微小抖动边带、微弱电源杂波，噪声底读数更平滑稳定 
❌ 单次采集时间很长，频谱刷新卡顿，单次测量耗时翻倍 适用：研发精密分析、Jitter 抖动测试、超低失真 HiFi 设备、微弱噪声底噪分析


# Acquire
## 1. Track FFT
### 含义
**自动同步跟随信号发生器的输出采样率**，无需手动填写固定采样率：
1. 你信号源输出 48kHz 数字信号 → 仪器自动 48k 采样；输出 1kHz 低频正弦，自动匹配最优低采样率。
2. FFT 计算上限自动锁定 Fs/2，和前面 LP 低通滤波器联动。
### 优点
- 不用手动改采样率，切换测试信号 / 数字音频时自动适配，量产测试最省心；
- 避免采样率设置错导致混叠失真、频谱读数异常。
### 适用场景
绝大多数常规测试：功放 THD、DAC、音箱频响、噪声自动测试脚本。
## 2. 固定采样率档位（800 ~ 256k）
手动强制仪器以固定速率采集波形，不受信号源控制，分档位用途：

| 采样率          | 奈奎斯特上限 (Fs/2) | 适用场景                                   |
| ------------ | ------------- | -------------------------------------- |
| 800Hz        | 400Hz         | 只测低频、电源 50Hz 工频干扰、超低频低音炮，降低采样节省算力      |
| 1.5k/2.5k/5k | 750Hz~2.5kHz  | 语音设备、对讲机、中频音频，屏蔽高频杂波                   |
| 10k/19k      | 5kHz~9.5kHz   | 老式电话、广播中频设备，上限低于 20kHz                 |
| 24k          | 12kHz         | 简易音频模块，带宽要求不高                          |
| 36k          | 18kHz         | 普通消费耳机、小音箱，接近人耳带宽                      |
| 72k          | 36kHz         | 标准 48k 音频兼容、通用 20kHz 全频测试（最常用固定档）      |
| 144k/256k    | 72kHz/128kHz  | HiFi DAC、数字功放、高频抖动 Jitter、超高频 EMI 噪声分析 |
### 手动固定采样率的优缺点
✅ 优势：强制锁定带宽，杜绝高频混叠；高频研发需要超宽频谱时强制高采样率。
❌ 缺点：信号源采样率和仪器采样率不匹配时，会出现频谱栅栏效应、读数抖动；切换信号要手动改档，量产不方便

# window
FFT 只截取**一段有限时间波形**做计算，如果这段波形首尾电压不连续（正弦波没刚好完整周期截断），会产生**频谱泄漏**：单根纯正弦信号，频谱会向两侧扩散出虚假杂波，失真、噪声读数完全不准。 窗函数的作用：给截取波形两端做衰减，平滑首尾跳变，抑制频谱泄漏；但不同窗函数有 trade-off（取舍）：**主瓣宽度（频率分辨力）** vs **旁瓣抑制（泄漏抑制能力）**
### 1. None（矩形窗 / 无窗，你当前选中）

- 特性：波形不做任何衰减，两端 100% 保留原始幅度
    - 优点：主瓣最窄，**频率分辨力最强**，幅度测量绝对精准
    - 缺点：旁瓣衰减极差（仅 - 13dB），频谱泄漏极其严重，非整周期信号会出现巨大虚假杂波
- 适用场景： 信号频率**严格对齐 FFT 频点中心**（标准整周期正弦扫频、锁定 1kHz 标准信号）；只适合研发精准幅度校准，**量产 THD 测试严禁使用**。

### None, move to bin center

软件自动微调采集时长，强制把输入信号频率对齐 FFT 频点中心，减少矩形窗泄漏，仅自动化脚本校准专用。
### 2. Hann（汉宁窗）
- 特性：两端平滑衰减，旁瓣 - 31dB，平衡分辨力与泄漏抑制，音频最通用基础窗
- 适用：常规频响曲线、普通 THD+N、噪声观测，90% 基础音频测试通用选择。
### 3. Hamming（汉明窗）
和 Hann 接近，旁瓣抑制 - 43dB，抑制泄漏略强于 Hann，但主瓣更宽一点；多用于射频、微弱谐波检测，音频用得少。
### 4. Blackman-Harris（布莱克曼 - 哈里斯窗）
- 特性：极高旁瓣抑制（-74dB~-92dB），泄漏压制能力极强，微弱谐波、底噪不会被主信号掩盖；代价是主瓣很宽，分辨力下降，相邻近频率会糊在一起。
- 适用：HiFi 超低失真 THD 测试、电源微弱工频杂波、小谐波失真测量（测 THD+N 行业首选）。
### 5. Flat-Top（平顶窗）
- 特性：全频段幅度平坦，**测信号电平最精准**，旁瓣抑制中等
- 适用：精确测量单频信号电压幅度、增益校准；不适合测 THD（主瓣过宽，谐波分辨差）。
### 6. Gaussian（高斯窗）
波形按高斯曲线衰减，过渡平滑，旁瓣衰减中等；多用于瞬态信号、脉冲波形分析，常规音频几乎不用。
### 7. Rife-Vincent 4 / Rife-Vincent 5（4 阶 / 5 阶里夫文森特窗）
- 顶级抑制泄漏窗：5 阶 RV 旁瓣抑制可达 - 150dB，几乎彻底消除频谱泄漏，能分辨比主信号低 100dB 以上的微小谐波；主瓣宽度很大，频率分辨力最弱。
- 适用：高端 HiFi、专业音频实验室、极低失真运放 / 解码器精密 THD 测试；产线不用（频谱刷新慢、计算量大）。
### 8. Equiripple（等波纹窗）
多用于滤波器设计、射频测试，音频频谱分析极少使用，跳过即可。
## 音频测试选型速查表

| 测试项目                  | 推荐窗函数                  | 理由                 |
| --------------------- | ---------------------- | ------------------ |
| 量产功放 / 耳机标准 THD+N、SNR | Blackman-Harris        | 强抑制泄漏，微小谐波不漏判，读数稳定 |

# 消除直流偏执
### 1. DC Coupled（直流耦合，不做任何直流抵消）
- 含义：仪器 ADC 完整采集波形全部信号，包含直流电压 + 交流音频信号，不做任何减法处理。
- 优缺点 ✅ 能完整测量电路输出的直流偏移值； ❌ 运放、功放自带静态 DC 偏移会在频谱 0Hz 处出现巨大尖峰，0Hz 旁低频噪声读数失真，THD+N 结果不准。
- 使用场景：只在专门测量输出直流漂移、静态电位时选用；**常规音频失真测试不要选**。
### 2. Subtract Avg（减去平均值，均值抵消直流）
- 原理：软件自动计算当前一整段 FFT 波形所有采样点的电压平均值，再把平均值从每一个采样点全部减掉，彻底消除直流分量。
- 优缺点 ✅ 精准消除任意大小的 DC 偏移，不改变交流音频波形； ❌ 波形包含完整周期信号时效果完美；若波形截断为非整周期，平均值计算会有微小误差。
- 使用场景：绝大多数标准 THD、SNR、频响测试，通用首选。
### 3. Sub 1/2 pk-pk（减去半峰峰值，截图当前选中）
- 原理：先算出波形峰峰值（最大值−最小值），取中点电压 `(Max+Min)/2`，用中点电压抵消直流偏移。等价于把波形上下平移，让正负峰值对称围绕 0V。
- 优缺点 ✅ 对单频正弦波抵消效果最优，不受采集周期影响，1kHz 标准正弦测试行业常用； ❌ 复杂多音信号、非对称失真波形会引入微小误差。
- 使用场景：标准单频 1kHz 正弦信号 THD 测试、功放额定失真量产检测（你截图当前模式就是这个用途）
