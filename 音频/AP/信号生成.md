
# 信号选择
## Sine

### 1. Normal（标准模式，默认）

- 行为：ChA、ChB 输出**同相位**的相同波形，无相位差、无调制，左右声道同步。
- 用途：绝大多数常规测试，增益、THD、频响、信噪比、单声道设备测试。
- 特点：两通道信号完全对齐，无相位偏移。

### 2. Var Phase（Variable Phase 可变相位模式）

- 行为：可自定义 ChA 与 ChB 之间的相位差（0°~360° 自由设置），双通道同频、不同相位输出。
- 核心用途：
    1. 测功放、耳机、音箱**相位响应 / 相位偏移**；
    2. 平衡差分电路、XLR 线路共模抑制比 CMRR 测试；
    3. 立体声扬声器相位匹配、声学干涉测试；
    4. 验证运放、DAC 通道间相位一致性。
- 典型场景：设置 180° 反相，直接测试差分输入设备。

### 3. Stereo（立体声反相标准模式）

- 行为：固定 ChA 与 ChB 相位差 180°（左右声道反相），行业标准立体声差分输出。
- 用途：
    1. 立体声功放、耳机、音箱**声道分离度 / 串扰**测试；
    2. 平衡输出、BTL 桥接功放性能测试；
    3. 检查设备左右声道相位是否接反。

### 4. Dual（双独立频率模式）

- 行为：ChA、ChB 可以输出**完全不同频率**的正弦波，不再共用上方 Frequency 参数。
- 用途：
    1. 双通道独立信号激励，多音并行测试；
    2. 自定义双通道复合激励，自定义 IMD 互调测试；
    3. 左右声道分开扫频、独立频响测试。

### 5. Shaped Burst（成型猝发脉冲波）

- 行为：波形不是连续输出，而是**带平滑包络的断续脉冲信号**（上升 / 下降沿缓升缓降，无陡峭开关冲击），避免信号启停产生瞬态冲击失真。
- 用途：
    1. 功放动态余量、瞬态峰值功率测试；
    2. 扬声器单元冲击、振膜疲劳测试；
    3. 避免连续信号长时间大功率烧毁被测件；
    4. 瞬态失真、过载恢复特性测试。

### 6. EQ（内置均衡预失真输出模式）

- 行为：发生器输出信号叠加预设 EQ 滤波曲线，信号先经过均衡再输出到 ChA/ChB。
- 和界面下方`EQ Curve`按钮区别：这个模式是**波形层全局 EQ 开关**，一键启用预均衡，无需手动载入曲线。
- 用途：模拟听音房间频响、耳机补偿、模拟录音设备频响特性，带均衡的失真 / 频响测试。

## IMD

IMD（互调失真）测试采用**高低频双正弦叠加信号**，用来检测音频设备同时存在两个频率时，非线性产生额外差频 / 和频失真（单音 THD 无法测出这类失真）。 当前界面是行业通用的 **SMPTE/DIN 双音 IMD 标准**，分两种幅值比例：4:1、1:1。
### 1. SMPTE/DIN 4:1

#### 参数定义（界面可见）

- IM-Freq（低频）：80 Hz（低音信号）
- High Freq（高频）：3000 Hz（高音信号）
- 幅值比例：**低频 80Hz 电平：高频 3kHz 电平 = 4 : 1** 例如低频 4Vrms，高频仅 1Vrms，低频能量远大于高频。
#### 测试标准来源

SMPTE RP120、DIN 45403 影音 / 功放通用 IMD 标准。
#### 适用场景

1. 功率放大器、音箱、耳机（模拟音乐：低音能量更强）；
2. 影音设备、录音通道、广播设备；
3. 最常用的互调失真测试，贴合真实音乐能量分布。
#### 原理说明

大功率低频信号驱动器件进入非线性区，叠加小幅高频，更容易暴露大动态下的调制失真，是行业默认标准。

### 2. SMPTE/DIN 1:1

#### 参数定义

同样 80Hz + 3kHz 双音，但**高低频输出幅值相等（1:1）**。

#### 适用场景

1. 前级运放、DAC、声卡、低电平信号链路（小信号、高低频能量均衡场景）；
2. 精密音频前置设备、测量仪器线性度验证；
3. 对比测试：区分 “大信号过载互调” 与 “小信号固有非线性”。

### 界面另外两个参数补充

1. **High Freq** 双音里的高频分量，默认 3kHz，可自定义修改。
2. **IM-Freq** 双音里的低频分量，默认 80Hz，标准固定值，一般不改动。

### 4:1 与 1:1 核心区别总结

|模式|能量配比|测试对象|测试侧重点|
|---|---|---|---|
|4:1|低频 4 份，高频 1 份|功放、扬声器、功率负载设备|大动态、大功率下的互调失真（最贴近音乐）|
|1:1|高低频能量相同|DAC、运放、声卡、前级小信号电路|小信号线性失真、前置电路固有调制问题|

## Square
陡峭边沿、固定占空比矩形波，富含高频谐波。
- 用途：测系统**瞬态响应、上升 / 下降沿、相位偏移、带宽、振铃、过冲、阻尼特性**；快速判断功放 / 运放是否自激、滤波相移大小

## Noise
子菜单内置粉红噪声 Pink Noise、白噪声 White Noise 两类：
- 白噪声：全频能量平坦，适合快速扫频、信噪比基底测量；
- 粉红噪声：低频能量更高，贴合人耳听觉特性，音箱 / 扬声器频响、声学房间测试标准信号；
- 用途：声学测试、信噪比 SNR、噪声底噪、均衡曲线校准。

## Arb Wfm 自定义任意波形（Arbitrary Waveform）
可导入外部.wav/ 波形文件，或软件绘制自定义波形载入发生器输出。
- 用途：播放音乐片段、脉冲信号、多音复合波形、模拟真实音源，做实听负载测试、复杂激励测试


## Special

### 1. Polarity（极性反相模式，当前选中）

#### 信号逻辑
ChA 输出原始波形，**ChB 自动输出 180° 反向波形**（极性翻转），两通道波形完全镜像反相。
#### 适用场景

1. **BTL 桥接功放测试**：BTL 架构左右声道天然反相驱动喇叭，该模式直接匹配 BTL 输入信号；
2. **差分平衡电路、XLR 平衡线路 CMRR 共模抑制比测试**；
3. 检测音频设备声道极性是否接反、扬声器相位对错；
4. 立体声串扰分离度测试，利用反相信号放大声道间干扰。
### 2. Pass Thru（直通同相模式）

#### 信号逻辑

ChA、ChB 输出完全相同、同相位的波形，无任何极性翻转，信号直通复制到双通道。
#### 适用场景

1. 普通双声道同步激励，左右声道同相信号测试；
2. 单端 RCA 非平衡功放、声卡、DAC 常规失真 / 频响测试；
3. 不需要差分 / 桥接激励的通用测量。




# Configuration
## 1. Bal XLR（Balanced XLR，当前选中）

### 电气结构
标准**差分平衡输出**，XLR 三针完整差分： Pin2 = 热端 (+)、Pin3 = 冷端 (-)、Pin1 = 屏蔽地；ChA/ChB 各自独立差分对。 仪器内部生成**幅度相等、相位 180° 反相**的正负信号，叠加输出。
### 配套参数
界面右侧 Z-Out（200Ω/40Ω）为平衡差分输出阻抗。
### 适用场景

- 专业功放、调音台、录音设备、舞台音频设备（全部平衡 XLR 输入）
- 需要抗工频干扰、长线缆测试场景
- CMRR 共模抑制比、平衡线路失真、BTL 桥接功放测试
### 优势
极强抗干扰，长距离传输无噪声，行业标准专业音频接口。
## 2. UnBal BNC/XLR（Unbalanced 单端输出）

### 电气结构

单端非平衡输出：

- 接 XLR：仅 Pin2 输出信号，Pin3、Pin1 短接接地；
- 接 BNC：中心芯 = 信号，外壳 = 地。 输出只有单路信号，无差分冷端。

### 适用场景

- 消费级设备：RCA 声卡、民用 DAC、桌面耳机功放、车载音响
- 示波器、单端测试仪器（BNC 直连）
- 短距离、低干扰桌面测试

### 特点

结构简单，但线缆易拾取工频噪声，不适合长线。

## 3. CMTST XLR（Common Mode Test XLR 共模测试专用模式）

### 电气结构

XLR 差分针脚**Pin2 与 Pin3 短接在一起**，信号同时送入冷热端，仅 Pin1 为屏蔽地。 此时输出**共模电压**，无差分信号。
### 唯一用途

专门测试设备**CMRR 共模抑制比**：

1. 给被测平衡输入端施加共模干扰信号；
2. 测量设备对共模噪声的抑制能力；
3. 音频设备、专业接口电路抗干扰指标合规测试。


# Reference 基准

### 1. Freq: 1.00000 kHz（基准参考频率）

- 功能：功率、电压分贝换算的基准频点，仅用于公式计算，不控制输出信号。
- 实操：测全频响、失真一般锁 1kHz；做低频专项测试可改为 50/100Hz。
- 不修改此值，不会改变发生器输出波形。

### 2. Watts: 8.000 Ohms（功率计算参考负载阻抗）

- 含义：计算输出功率时，仪器默认用**8Ω 扬声器负载**做功率换算。
- 原理：\(P=V_{rms}^2 / R\)，当前 ChA 1Vrms、8Ω 负载，算出理论功率。
- 可修改：测 4Ω 音箱填 4，测 16Ω 音箱填 16，数值会自动刷新对应瓦数。

### 3. dBr: 387.3 mV（相对分贝参考电压）

1. dBr = decibel relative，**相对参考电平**
2. 定义：所有 dB 读数（失真、信噪比、串扰）都以这个电压作为 0dB 基准。
3. 当前 387.3mV = 0dBr，被测件输出低于该电压就显示负 dB，高于则正 dB。
4. 用途：行业标准参考基准，统一失真、SNR、频响的分贝标尺。下拉可切换 Vrms/dBu/dBV 单位。
### 4. dBm: 600.0 Ohms（dBm 功率基准负载）
1. dBm 定义：1mW 功率落在指定电阻上为 0dBm，广播 / 电信标准负载 600Ω。
2. 600Ω 是传统模拟音频线路标准阻抗，测广播设备、电话音频、专业线路电平必用。
3. 修改欧姆值，同一输出电压会算出不同 dBm 读数。
