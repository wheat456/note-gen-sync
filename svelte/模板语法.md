# each

```ts
<h1>Shopping list</h1>
<ul>
	{#each items as item, index} //index是索引
		<li>{item.name} x {item.qty}</li>
	{/each}
</ul>
```

## 结构
```ts
<script>
  let users = $state([
    { id: 1, name: '张三' },
    { id: 2, name: '李四' }
  ]);
</script>

{#each users as { id, name }}
  <div>{id} - {name}</div>
{/each}
```

## key
```ts
{#each users as user (user.id)}
  <div>{user.name}</div>
{/each}
```
## 
`{#each expression as name}...{:else}...{/each}`
每个块还可以有一个 `{:else}` 子句，如果列表为空，则会渲染该子句
```ts
{#each todos as todo}
	<p>{todo.text}</p>
{:else}
	<p>No tasks today!</p>
{/each}
```


# snippet
可以将片段理解为函数
render就渲染函数
```ts
{#snippet item(name)}
  <div>{name}</div>
{/snippet}

{@render item("test")}
```


# attachment
- **首次挂载：跑一次**
- **依赖的 state 变：先清理、再重跑**
- **最终卸载：再清理一次**
```ts
<script>
  let text = $state('A');

  function useDom(el) {
    // 本轮主逻辑
    el.innerText = text;
    console.log('运行', text);

    // 本轮专属的清理函数（闭包，锁住当前 text 值）
    return () => console.log('清理', text);
  }
</script>
<div {@attach useDom}></div>
<button on:click={() => text = 'B'}>切换</button>
```
