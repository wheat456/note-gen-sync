# load 函数文件
## 服务端
```ts
//src/routes/your-route/+page.server.js
export async function load({ params, fetch, cookies }){

}
```

## 客户端
客户端和服务端都会运行
```ts
//src/routes/your-route/+page.js or layout.js
export async function load({ params, fetch, cookies }){

}
```

在页面中，用`let {data} = $props()` 拿到的数据就是从load函数中返回的

# +error 
子页面有就用子页面的，子页面没有就用上层的
如果在load器件出错，那么就会定向到这个页面


# 参数路由
## 单参数
文件命名 /blog/\[id]/+page.svelte
```ts
import { page } from '$app/state';
    
    // Svelte 5 的响应式写法：直接通过 page.params 拿到文件夹里定义的 [id]
    let articleId = $derived(page.params.id);
```

## 多重参数

```
src/routes/
└── shop/
    └── [category]/         <-- 分类参数
        └── [item]/         <-- 商品参数
            └── +page.svelte
```

```ts
<script>
    import { page } from '$app/state';
    
    let category = $derived(page.params.category);
    let item = $derived(page.params.item);
</script>

<p>当前分类：{category}</p>
<p>当前商品：{item}</p>
```
